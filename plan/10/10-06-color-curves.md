# 10-06 调色曲线

## 目标

为 `CAMERA` / `ADJUST` 片段的 10 条调色曲线提供图形编辑：

- 曲线是片段级 value-only `STRUCT`，不是关键帧；
- 曲线点只写 `[[x,y], ...]`；
- 曲线强度仍由属性/效果面板的 10 个 `*_strength` 通道控制；
- 编辑器只编辑曲线形状，不采样画面、不烘焙最终颜色。

## 曲线清单

| 字段 | 含义 | 对应强度 |
|---|---|---|
| `rgb_curve` | RGB 复合曲线 | `curve_strength` |
| `r_curve` | R 通道曲线 | `r_curve_strength` |
| `g_curve` | G 通道曲线 | `g_curve_strength` |
| `b_curve` | B 通道曲线 | `b_curve_strength` |
| `hv_h_curve` | Hue → Hue | `hv_h_strength` |
| `hv_s_curve` | Hue → Saturation | `hv_s_strength` |
| `hv_l_curve` | Hue → Lightness | `hv_l_strength` |
| `lv_s_curve` | Lightness → Saturation | `lv_s_strength` |
| `sv_s_curve` | Saturation → Saturation | `sv_s_strength` |
| `sv_l_curve` | Saturation → Lightness | `sv_l_strength` |

`CAMERA` 与 `ADJUST` 都有这 10 条；`ADJUST` 多出的 `lut` 不属于曲线，不放进曲线抽屉。

## 数据形状

```json
{
  "rgb_curve": [[0, 0], [0.25, 0.18], [0.75, 0.82], [1, 1]],
  "r_curve": [[0, 0], [1, 1]]
}
```

规则：

- 每条曲线是点数组，至少 2 点；
- 每点是 `[x, y]`，两个数都是 0–1；
- `x` 严格递增，不能相等、不能倒序；
- `y` 只要求 0–1，不要求单调；曲线可以下凹、上凸、S 形；
- 端点不强制在 `0` / `1`；区间外按端点值钳制；
- 运行时用 PCHIP 采样成 256 点查找表；编辑器图形按同一形状示意；
- 曲线本身没有关键帧，曲线强度才有关键帧；
- 空值/null 表示“无曲线”，该曲线步不生效；强度仍可保留。

## 曲线抽屉

`curves` 抽屉注册为 `color.curves`，只在当前选中 `CAMERA` / `ADJUST` 片段时可用。

```text
[RGB] [R] [G] [B] | [H→H] [H→S] [H→L] [L→S] [S→S] [S→L]
┌──────────────────────────────┐
│ 1 ┤            ●             │
│   │        ●                 │
│ 0 ┤ ●                        │
│   └──────────────────────────│
│     0        0.5        1     │
└──────────────────────────────┘
[加控制点] [删除点] [线性基准] [清除曲线] [复制 JSON]
强度：1.00 · 无关键帧（在属性/效果面板编辑）
```

- 顶部 10 个页签，按上表顺序；
- 图形横轴/纵轴都是 0–1，画 0.25 网格；
- 当前点显示坐标；hover 显示 `x,y`；
- 右下显示“运行采样 256 点，区间外钳制”；
- 不显示曲线强度滑杆，只显示强度和帧数摘要；点击摘要跳到属性/效果面板对应行。

### 没有选中片段

- 显示“选择一个 CAMERA 或 ADJUST 片段”；
- 不显示空图，不创建曲线；
- 不把抽屉状态写进文档。

### 片段没有曲线字段

- 显示“该片段没有调色曲线字段”；
- 不自动创建 `rgb_curve`；
- 作者点“线性基准”才写入第一条曲线。

## 点编辑

### 加点

- 点击“加控制点”在图形中央添加，或在曲线上双击添加；
- 新点的 `x` 取点击位置，`y` 取点击位置；
- 若 `x` 与相邻点太近，插入到相邻点中间；不自动排序、不越过相邻点；
- 新点加入后立即成为当前点；
- 一次加点是一个 commit。

### 拖点

- 横向拖动改变 `x`，纵向拖动改变 `y`；
- `x` 被相邻点夹住，不能越过前一点或后一点；
- `y` 限制在 0–1；
- 拖动过程实时显示坐标，释放时 commit；
- 拖动不改变其他点顺序；
- 不提供整条曲线自由平移。

### 删除点

- 选中点后点“删除点”；
- 少于 2 点时禁用删除；
- 删除一个点后，剩余点保持原顺序；
- 删除端点后，区间外仍按新的端点值钳制；
- 一次删除是一个 commit。

### 线性基准

- 写入 `[[0,0],[1,1]]`；
- 用于快速恢复“无色调偏移”的基准形状；
- 不删除曲线强度，不重置强度值。

### 清除曲线

- 把该曲线写为 null/空；
- 曲线步不生效；强度值保留，显示“曲线未定义”；
- 需要确认，一次撤销可恢复。

### 复制 JSON

- 复制当前曲线的 `[[x,y],...]`；
- 只复制，不写入剪贴板历史；
- 不提供“从 JSON 粘贴”到未知结构；需要粘贴时走完整校验后再提交。

## 图形与运行时

- 图形只画曲线形状，不叠加游戏画面、不采样素材；
- 运行时用 PCHIP 采样 256 点；图形不要求逐像素一致，只要求控制点一致；
- 区间外按第一个/最后一个点钳制，不抛错、不跳变；
- 曲线点顺序就是数据顺序，编辑器不重排、不排序；
- 曲线是 value-only，切播放头不会改变曲线形状。

## 校验

| 检查 | 级别 | 处理 |
|---|---|---|
| 少于 2 点 | block | 红框；拒绝提交 |
| `x` 相等或倒序 | block | 标出冲突点；拒绝提交 |
| `x` / `y` 超出 0–1 | block | 标出越界点；拒绝提交 |
| 非有限值 | block | 拒绝提交 |
| 控制点超过 256 | warn | 提示采样精度；不阻止提交 |
| 曲线字段类型不是数组 | block | 显示“曲线数据格式错误”；不猜测 |
| 强度有值、曲线为空 | info | 摘要行“曲线未定义，强度不生效” |

- 校验失败时保留上次合法曲线，不把非法点写进文档；
- 拖动中的临时点不写文档，释放时才校验/提交；
- 撤销/重做按曲线整体快照恢复，不逐点回放。

## 验收标准

1. 选中 `ADJUST`，打开 `curves` 抽屉：10 个页签全部存在，默认选中 `rgb_curve`。
2. `rgb_curve` 为空：显示“未定义”，不自动创建；点“线性基准”后写入 `[[0,0],[1,1]]`。
3. 双击图形加点：新点坐标在 0–1，顺序正确；一次撤销删除该点。
4. 拖动中间点越过右邻点：被夹住，不能越过；`x` 仍严格递增。
5. 拖动 `y` 到 1.2：显示越界，释放后不提交；`y` 回到 0–1。
6. 删除到只剩 2 点：删除按钮禁用；不能删到 1 点。
7. 清除曲线：确认后曲线为空；强度值保留；摘要显示“曲线未定义”。
8. `r_curve` 与 `g_curve` 独立编辑：切页签不串数据；切回原页签形状保持。
9. 曲线强度有帧：摘要显示“2 帧”，点击跳到效果面板对应行；抽屉内不出现强度滑杆。
10. 曲线 `x` 倒序的脚本打开：显示格式错误，保留上次合法形状；不把倒序点写回。
11. 保存重开：10 条曲线控制点原样恢复；曲线点没有变成关键帧。
12. `CAMERA` 与 `ADJUST` 各选一次：曲线抽屉跟随当前片段；没有 LUT/混合字段混入。
