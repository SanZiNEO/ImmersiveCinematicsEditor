# 10-06 · 调色曲线

> 状态：未实现
> 范围：`CAMERA` 与 `ADJUST` 共有的 10 条调色曲线的控制点编辑、图形示意与校验
> 关联：10-04 字段面、10-05 窄组与控件、10-09 媒体检查

## 一、摘要

为 10 条调色曲线提供图形编辑。曲线是片段级的 value-only 数据，形状由一串控制点描述，本身不是关键帧；真正能打关键帧的是每条曲线对应的强度通道。编辑器只编辑曲线形状，不采样画面、不烘焙最终颜色，也不让曲线点混进时间轴。

## 二、为什么做

### 2.1 问题

曲线数据是点数组，手写 JSON 几乎不可行：要保证横坐标严格递增、纵坐标在范围内、端点顺序正确，还要理解「区间外按端点钳制」。没有图形编辑，作者只能靠猜和反复试。另一个风险是把曲线点和关键帧混为一谈——看到曲线就以为要打帧，或者反过来在效果面板里找曲线形状。这会让动画系统多出一层本不该存在的概念。

### 2.2 目标

- 10 条曲线各有一个页签，能看出哪条已定义、哪条为空。
- 控制点可加、可拖、可删，横坐标始终严格递增，纵坐标始终在范围内。
- 曲线与它的强度通道关系可见：形状在这里改，强度在属性面板或效果面板改。
- 非法数据（点太少、横坐标倒序、越界）不写入文档，保留上次合法形状。
- 曲线点不产生关键帧，切播放头不改变曲线形状。

### 2.3 非目标

- 不把曲线点做成关键帧，也不让曲线随时间变化。
- 不做像素级预览，不采样素材，不渲染最终画面。
- 不提供「从任意 JSON 粘贴」的自由入口。
- 不在曲线抽屉里放强度滑杆。

## 三、方案

曲线抽屉只在选中 `CAMERA` 或 `ADJUST` 片段时可用。顶部是 10 个页签，按固定顺序排列：RGB 复合、R、G、B，然后 Hue→Hue、Hue→饱和度、Hue→亮度、亮度→饱和度、饱和度→饱和度、饱和度→亮度。图形横纵轴都是归一化区间，画四分之一网格；当前点显示坐标，悬停显示数值。

操作有四类：加点、拖点、删点、清除。加点可在图形中央或曲线上双击插入，插入后立即成为当前点；拖点横向改横坐标、纵向改纵坐标，横坐标被左右邻点夹住，不能越过；删点在少于两点时禁用；清除把曲线写空并需要确认。另有两个辅助动作：「线性基准」写入一条无偏移的对角线，「复制 JSON」把当前点数组复制出去。

右下角常驻一行说明：运行时按曲线形状采样成查找表，区间外按端点值钳制。旁边显示这条曲线的强度摘要和帧数，点摘要跳到属性面板或效果面板的对应行——抽屉里不放强度滑杆。

没有选中片段时显示提示，不显示空图；片段没有曲线字段时也不自动创建曲线，作者点「线性基准」才写入第一条。

## 四、技术细节

### 4.1 核心模型

一条曲线是一串点，每点由横纵两个归一化数值构成。横坐标必须严格递增，纵坐标只要求在范围内、不要求单调——曲线可以下凹、上凸、呈 S 形。端点不强制落在 0 和 1，区间外按端点值钳制。空值表示「无曲线」，该曲线步不生效，但强度值仍然保留。

### 4.2 契约

- 每条曲线至少两点。
- 每点两个数都在 0–1；横坐标严格递增，不能相等或倒序。
- 曲线定义本身没有关键帧；只有对应的强度通道可动画。
- 运行时按同一形状采样成 256 点查找表；编辑器图形不要求逐像素一致，只要求控制点一致。
- 点顺序就是数据顺序，编辑器不重排、不排序。
- 校验失败时保留上次合法曲线，不把非法点写进文档；拖动中的临时点不写文档，释放时才校验并提交。
- 撤销与重做按曲线整体快照恢复，不逐点回放。

### 4.3 数据形态

曲线清单与强度通道一一对应：

| 曲线 | 含义 | 强度通道 |
|---|---|---|
| `rgb_curve` | RGB 复合 | `curve_strength` |
| `r_curve` / `g_curve` / `b_curve` | 单通道 | `r_curve_strength` / `g_curve_strength` / `b_curve_strength` |
| `hv_h_curve` | Hue → Hue | `hv_h_strength` |
| `hv_s_curve` | Hue → 饱和度 | `hv_s_strength` |
| `hv_l_curve` | Hue → 亮度 | `hv_l_strength` |
| `lv_s_curve` | 亮度 → 饱和度 | `lv_s_strength` |
| `sv_s_curve` | 饱和度 → 饱和度 | `sv_s_strength` |
| `sv_l_curve` | 饱和度 → 亮度 | `sv_l_strength` |

每条曲线是一组二维点；空值表示未定义。`ADJUST` 的 LUT 字段不属于曲线，不进抽屉。

### 4.4 边界

- 抽屉状态（当前页签、当前点）不写入文档。
- 少于两点、横坐标相等或倒序、任一坐标越界、非有限值、字段类型不是数组，都是拒绝提交的阻断级问题。
- 控制点超过 256 个只提示采样精度，不阻止提交。
- 强度有值但曲线为空时只提示「曲线未定义，强度不生效」，不自动建曲线。
- 图形只画形状，不叠加画面、不采样素材。

## 五、为什么不选别的

| 备选方案 | 做法 | 代价 | 为什么没选 |
|---|---|---|---|
| 只提供 JSON 文本框 | 手写点数组 | 实现最简单 | 横坐标递增与范围约束全靠人保证，错误率高 |
| 把曲线点做成关键帧 | 曲线随时间变化 | 概念统一 | 脚本结构上曲线是 value-only，做成关键帧会越出字段面 |
| 自动排序控制点 | 拖过邻点时重排 | 拖动更「顺」 | 会静默改变数据顺序，撤销语义也变得不可预测 |
| 曲线抽屉里同时放强度滑杆 | 一处改完形状与强度 | 少跳转 | 强度是可动画通道，与属性/效果面板的通道路由冲突 |

**本方案的缺点**：

- 形状与强度分处两个面板，调一条曲线要来回切。
- 图形与运行时采样不完全一致，极密控制点下视觉差异需要靠说明理解。
- 清除曲线保留强度值，会出现「有强度没曲线」的状态，需要靠提示解释。

**验收要点**

- 选中 `ADJUST` 打开曲线抽屉时 10 个页签齐全，默认选中 RGB 复合曲线。
- 曲线为空时显示「未定义」且不自动创建；点「线性基准」后写入一条对角线。
- 双击加点后坐标在范围内、顺序正确，一次撤销可删除该点。
- 拖动中间点不能越过右邻点，横坐标保持严格递增。
- 纵坐标拖到范围外时显示越界，释放后不提交。
- 只剩两点时删除按钮禁用，不能删到一点。
- 清除曲线需确认，清除后强度值保留、摘要显示「曲线未定义」。
- 不同页签的数据互不串，切换后形状保持。
- 强度有帧时摘要显示帧数，点击跳到对应面板行，抽屉内不出现强度滑杆。
- 打开横坐标倒序的脚本时显示格式错误，保留上次合法形状，不回写非法点。
- 保存重开后 10 条曲线控制点原样恢复，且没有变成关键帧。
- 在 `CAMERA` 与 `ADJUST` 之间切换时抽屉跟随当前片段，不混入 LUT 或混合字段。
