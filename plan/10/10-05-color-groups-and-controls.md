# 10-05 调色窄组与控件

## 目标

把 57/59 个调色通道按功能窄组排进属性面板，避免出现一个几十行的“调色”大组；每个通道都有明确的数值控件、默认值、范围和重置行为。

只做显示与编辑，不改公式、不重排 19 步操作栈、不把通道合成一个“总强度”。

## 分组

| 组 | 字段数 | 默认展开 | 控件形态 |
|---|---|---|---|
| 基础校色 | 6 | 是 | 6 行滑杆 + 数字 |
| HSL | 4 | 否 | 4 行滑杆 + 数字 |
| 白平衡 | 2 | 否 | 2 行滑杆 + 数字 |
| 通道系数 | 3 | 否 | RGB 三行 |
| 通道混合 | 9 | 否 | 3×3 参数矩阵 |
| 曲线强度 | 4 | 否 | 4 行 0–1 滑杆 |
| Lift/Gamma/Gain | 9 | 否 | 三组 RGB 三元组 |
| LUT 强度 | 1（仅 ADJUST） | 否 | 0–1 滑杆 |
| Hue 曲线强度 | 6 | 否 | 6 行 0–1 滑杆 |
| 六色带 | 12 | 否 | 六行色带，每行 Hue/Sat |
| 风格化 | 2 | 否 | 2 行 0–1 滑杆 |
| 层级混合 | 1（仅 ADJUST） | 否 | 0–1 滑杆 |

- 组头显示字段数、默认值摘要、issue 点；
- 组折叠状态按 `clipKey + groupId` 存 session，不写文档；
- 默认只展开“基础校色”；其余折叠，作者点开再看；
- 组头 issue 不自动展开组，不强行切到另一面板。

## 数值控件

所有调色通道共用 06 的值控件规范：

- 滑杆 + 数字输入同排；拖滑杆更新数字，输入数字更新滑杆；
- 数字框允许负数、允许超出范围输入，提交时才校验；
- 步长 0.01；`exposure` 步长 0.05；
- 双击数值恢复默认；行尾有“重置”按钮；
- 默认值位置画一条竖线；
- 值等于默认值时行显示“默认”弱标记，不隐藏；
- 提交前校验 `min/max`，越界显示红框并拒绝写入；不静默夹取；
- 非有限值（NaN/Infinity）拒绝提交。

### 默认值

| 组 | 默认 |
|---|---|
| 基础校色 / HSL / 白平衡 / 通道系数 / 通道混合 / Lift/Gamma/Gain / 六色带 | 0 |
| 曲线强度 / Hue 曲线强度 / LUT 强度 / 层级混合 | 1 |
| 风格化 | 0 |

### 重置

- 单行重置：无关键帧时把值写回默认；有关键帧时不直接清帧，先提示“清除该通道全部关键帧并恢复默认”，确认后一次 commit。
- 组重置：只重置本组通道；同样按“有关键帧是否清帧”处理；一次 commit，一次撤销可回。
- 不提供“全部调色重置”一键清空，避免误删整段调色。

## 分组控件

### 基础校色

`exposure` / `contrast` / `highlights` / `shadows` / `whites` / `blacks`：

- `exposure` 范围 -5–5，默认 0；
- 其余 -1–1，默认 0；
- 每行显示“负值 / 0 / 正值”端点标签；
- 不提供自动曝光、自动对比度按钮。

### HSL

`hue` / `saturation` / `vibrance` / `lightness`：

- 范围 -1–1，默认 0；
- `hue` 行用色相条背景示意，但控件值仍是数值；
- `saturation` / `vibrance` / `lightness` 不合并成一个“饱和度”控件。

### 白平衡

`temperature` / `tint`：

- 范围 -1–1，默认 0；
- `temperature` 左冷右暖，`tint` 左绿右品红；
- 只做端点文字/色条示意，不用取色器改脚本值。

### 通道系数

`red` / `green` / `blue`：

- 范围 -1–1，默认 0；
- 三行按 R/G/B 顺序，行首色点；
- 不提供“锁定三通道”开关；需要一致值时逐行输入或组重置。

### 通道混合

9 个 `mix_*`：

```text
输出通道 \ 输入     R      G      B
R                  [0]    [0]    [0]
G                  [0]    [0]    [0]
B                  [0]    [0]    [0]
```

- 这是“单位阵 + 参数矩阵”；单元格是偏移量，默认 0，表示不改变；
- 不要把对角线默认写成 1；对角线 1 是“参数 +1”，不是单位阵；
- 单元格范围 -1–1；数字输入 + 方向键；
- 行/列头显示 R/G/B；hover 显示完整字段名；
- 右侧有“单位阵”按钮：把所有 9 个参数写回 0；
- 不提供矩阵转置/反相，避免越过现有公式。

### 曲线强度

`curve_strength` / `r_curve_strength` / `g_curve_strength` / `b_curve_strength`：

- 0–1，默认 1；
- 行尾显示“曲线未定义”弱标记，当对应曲线为空；
- 强度为 0 时行显示“该曲线步关闭”；
- 强度不控制曲线形状，只控混合量。

### Lift/Gamma/Gain

9 个 `lift_*` / `gamma_*` / `gain_*`：

- 三组，每组 R/G/B；
- 范围 -1–1，默认 0；
- 每组显示三行，行首色点；
- 组内提供“三通道同值”开关：打开后改一个通道，另外两个跟随；关闭后独立；
- 不把 Lift/Gamma/Gain 合成一个“亮度”滑杆。

### LUT 强度

`lut_strength`：

- 仅 `ADJUST`；
- 0–1，默认 1；
- 未选 LUT 时显示“未选择 LUT，强度不生效”，控件仍可编辑但置灰；
- 不提供 LUT 预览缩略图。

### Hue 曲线强度

6 个 `hv_h_strength` / `hv_s_strength` / `hv_l_strength` / `lv_s_strength` / `sv_s_strength` / `sv_l_strength`：

- 0–1，默认 1；
- 按“Hue→Hue / Hue→Sat / Hue→Light / Light→Sat / Sat→Sat / Sat→Light”的顺序；
- 每行显示曲线缩写和对应曲线是否已定义；
- 强度 0 表示该步关闭，不删除曲线。

### 六色带

12 个 `hue_red` / `sat_red` … `hue_magenta` / `sat_magenta`：

```text
[红]      Hue [-]  Sat [-]
[黄]      Hue [-]  Sat [-]
[绿]      Hue [-]  Sat [-]
[青]      Hue [-]  Sat [-]
[蓝]      Hue [-]  Sat [-]
[品红]    Hue [-]  Sat [-]
```

- 每行一个色带标识 + 两个数值；
- 范围 -1–1，默认 0；
- 色带标识只用固定色点，不用取色器；
- 六行顺序固定：红、黄、绿、青、蓝、品红；
- 不提供“色带联动”或“全色相旋转”按钮。

### 风格化

`grayscale` / `invert`：

- 0–1，默认 0；
- 0 表示不启用，1 表示全量；
- 两个独立滑杆，不合并成“风格强度”。

### 层级混合

`blend_amount`：

- 仅 `ADJUST`；
- 0–1，默认 1；
- 0 表示本层不参与混合，1 表示全量；
- 与 `blend_mode` 的枚举控件分开：`blend_mode` 在 LUT/混合组，`blend_amount` 是数值行。

## 有帧与无帧

- 无关键帧的通道：属性面板显示数值控件和“开时钟”；
- 有 `keyframes.length > 0` 的通道：属性面板不再显示值控件，只显示“在效果面板编辑”摘要和当前采样值；
- 有帧通道的组头保留 issue 点；
- 效果面板按 06 的节点/曲线编辑，不在这里重复实现；
- 曲线定义、`lut`、`lut_input_gamma`、`blend_mode` 永远不进效果面板。

## 本地校验

| 检查 | 级别 | 处理 |
|---|---|---|
| 数值越界 | block | 行红框，拒绝提交 |
| 非有限值 | block | 拒绝提交 |
| `lut_input_gamma<=0` | block | LUT 组红框 |
| `curve_strength` 有值但曲线为空 | info | 显示“曲线未定义，强度不生效” |
| `lut_strength` 有值但 `lut` 为空 | info | 显示“未选择 LUT，强度不生效” |
| `blend_amount` 有值但 `blend_mode` 缺失 | info | 按默认 `normal` 显示 |
| 组内字段缺失 | info | 按默认值显示，不伪造对象 |

## 验收标准

1. 选中 `ADJUST`：12 个组按顺序出现，只有“基础校色”默认展开。
2. 选中 `CAMERA`：没有 LUT 强度和层级混合组；其余 10 组一致。
3. `exposure` 输入 6：红框、拒绝提交；输入 -5 可提交；默认值竖线在 0。
4. `contrast` 输入 -0.35：滑杆和数字同步；双击恢复 0；一次撤销回到 -0.35。
5. 通道混合 9 格默认全 0；点“单位阵”全部回 0；对角线不显示 1。
6. 六色带显示红/黄/绿/青/蓝/品红六行；改 `hue_red` 不影响 `sat_red`。
7. Lift/Gamma/Gain 打开“三通道同值”，改 `lift_r` 后 `lift_g`/`lift_b` 跟随；关闭后独立。
8. `curve_strength` 无曲线：显示“曲线未定义，强度不生效”；强度 0 再显示“该曲线步关闭”。
9. `lut_strength` 无 LUT：控件置灰并提示；选 LUT 后恢复可用。
10. `blend_amount` 有帧：属性面板只显示摘要，效果面板出现节点；`blend_mode` 仍在属性面板。
11. 组重置只重置本组；有帧通道弹确认；一次撤销恢复整组。
12. 保存重开：分组折叠状态不写文档；所有通道值、默认值、LUT/混合值原样恢复。
