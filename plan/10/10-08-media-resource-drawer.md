# 10-08 媒体资源抽屉

## 目标

填充 04 预留的 `resources` 抽屉，让作者能看到脚本可用的本地资源，并把选中文件填进当前媒体字段。

抽屉是只读的：

- 不上传、不删除、不改名、不写文件；
- 不做缩略图、不读文件大小、不预览内容；
- 不把资源列表当成运行时解码结果。

## 源码事实

`ResourceFileService.list(kind, dir)`：

- 资源根：`<游戏目录>/immersive_cinematics/resource/`；
- `kind`：`lang` / `image` / `audio` / `all`，空 = `all`；
- `dir`：资源根下的可选子目录；空 = 整棵树；`lang` 空时默认 `lang`；
- 路径安全：拒绝绝对路径、盘符、UNC、`..` 逃逸；
- 深度上限 5；
- 条数上限 2000；达到上限后停止列举；
- 非 `lang` 返回 `{kind, dir, files[]}`，`files` 是相对资源根的路径，统一 `/`；
- `lang` 返回 `{kind, dir, languages[], entries[]}`，`entries` 是 key 并集 + 各语言译文；
- 不返回文件大小、缩略图、总条数、截断标记；
- 本服务不写文件。

扩展名过滤：

- `kind=image` 只列 `png/gif`；
- `kind=audio` 只列 `ogg/wav`；
- `kind=all` 列全部文件；
- 视频、LUT、语言 JSON 需要 `kind=all` 后在客户端分类。

## 分类

抽屉按文件用途分组，分组只影响显示，不改文件路径：

| 分类 | 扩展名 | 可用于 |
|---|---|---|
| 图片 | `png` / `gif` | `OVERLAY` image `path` |
| 视频 | `mp4` / `webm` / `mkv` | `OVERLAY` image `path`（视频层同字段） |
| 音频 | `ogg` / `wav` / `mp3` / `aac` / `flac` / `m4a` / `opus` / `wma` / `oga` / `ogx` | `AUDIO` `sound`（`source=file`） |
| LUT | `cube` | `ADJUST` `lut` |
| 语言 | `lang/*.json` | `@lang:` 键查看；不填媒体字段 |
| 其他 | 其余扩展名 | 只读；可复制路径 |

- 分类由客户端按扩展名计算，不依赖 `kind=image/audio` 的窄过滤；
- 语言分类的“浏览”只显示 JSON 路径；“语言”页签调用 `kind=lang` 展示 key/语言矩阵；
- 不把 `.json` 当图片/音频/LUT 填进字段。

## 抽屉结构

`resources` 抽屉有两个页签：

```text
┌ 资源 ───────────────────────────────┐
│ [浏览] [检查]        [刷新]          │
│ 搜索 [________]  类型 [全部 ▼]       │
│ 目录  resource/ > audio/ > ...       │
│ ┌─────────────────────────────────┐ │
│ │ audio/theme.ogg     音频  3 引用 │ │
│ │ lut/teal.cube       LUT   1 引用 │ │
│ │ image/title.png     图片  未引用 │ │
│ └─────────────────────────────────┘ │
│ 选中：audio/theme.ogg               │
│ [复制路径] [填入当前字段] [定位引用] │
└─────────────────────────────────────┘
```

- 顶部：浏览 / 检查页签、刷新；
- 第二行：搜索、类型过滤；
- 目录面包屑：从 `resource/` 开始，点击回上层；
- 列表：路径、类型、引用数；
- 底部：选中文件操作。

### 浏览页签

- 搜索按路径子串匹配，大小写不敏感；
- 类型过滤：全部 / 图片 / 视频 / 音频 / LUT / 语言 / 其他；
- “只看未引用”开关；
- 列表按路径升序，文件夹和文件同一列表，路径列显示相对路径；
- 单击选中，双击只选中并聚焦，不直接改字段；
- 空目录显示“此目录没有文件”，不显示空白列表；
- 加载中显示骨架/“正在读取资源”；
- 请求失败显示错误条 + 重试；保留上一次成功列表，不把旧列表当成新结果。

### 语言页签

- 调用 `resource.list(kind=lang)`；
- 显示语言代码列 + key 行；
- 只读查看某 key 在各语言是否有值；
- 不提供新增/删除/编辑译文；译文文件由作者直接维护；
- 不把语言 key 填进 `path` / `sound` / `lut`。

## 选中与填入

### 当前媒体目标

抽屉从当前选择推导 `activeMediaTarget`：

| 当前选择 | 目标字段 | 可填类型 |
|---|---|---|
| `OVERLAY` image 片段，焦点在 `path` | `path` | 图片 / 视频 |
| `AUDIO` 片段，焦点在 `sound`，`source=file` | `sound` | 音频 |
| `ADJUST` 片段，焦点在 `lut` | `lut` | LUT |
| 其他选择/无焦点 | 无目标 | 按钮禁用 |

- 只有焦点在媒体字段上才出现目标；选中片段但焦点在别的字段时，不默认把文件填到 `path`；
- 目标字段与文件类型不兼容时，“填入当前字段”禁用并说明原因；
- 填入是显式按钮，不因单击/双击自动改脚本；
- 填入写相对路径，不写绝对路径、不写 `resource/` 前缀；
- 填入后字段进入 dirty 状态，按正常保存/推送流程。

### 复制路径

- 复制相对资源路径；
- 不复制文件内容、不复制文件 URL；
- 路径保持 `/` 分隔，不带首尾空格。

### 定位引用

- 扫描当前文档：
  - `OVERLAY` image `path`；
  - `AUDIO` `sound`（仅 `source=file`）；
  - `ADJUST` `lut`；
- 按 clipKey + objectPath 列出引用位置；
- 点击引用：选中片段，打开属性面板，滚到对应字段；
- 不修改文档、不改变播放头；
- 同一文件被多条片段引用时全部列出；
- 未引用文件显示“未引用”，不自动删除。

## 引用扫描边界

- `source=minecraft` 的 `sound` 不是文件，不参与资源引用扫描；
- `subtitle` 的 `@lang:` 只引用语言 key，不引用文件路径；
- `OVERLAY` `path` 在 image/video 层都可能出现；不按扩展名反推层类型；
- 未知对象里的同名 `path` 不当媒体引用；只扫描已登记字段；
- 扫描只读文档，不写缓存到文档，不改变选择。

## 资源列表上限

- `files.length >= 2000` 时显示“资源列表达到 2000 条上限，可能未列全”；
- 这是上限提示，不是“已截断”事实；接口没有 `truncated` 标记；
- 达到上限时：
  - 浏览仍可用；
  - “缺失引用”检查不能把未列出的文件直接判为不存在；
  - 提示作者缩小目录或直接用 `dir` 过滤；
- `MAX_DEPTH=5` 是服务端深度上限；超过深度的文件不会出现在列表，同样不判为不存在。

## 刷新与错误

| 情况 | 显示 | 行为 |
|---|---|---|
| 首次加载 | 加载态 | 不显示“无资源” |
| 请求成功、0 文件 | 空状态 | 显示当前目录无文件 |
| 请求失败 | 错误条 + 重试 | 保留上一次成功结果；不清空选择 |
| `dir` 越界 | 错误条 | 回到资源根；不继续请求越界路径 |
| `kind` 非法 | 错误条 | 不发送该 kind |
| 达到 2000 条 | 黄条 | 提示可能未列全 |
| 刷新中 | 顶部进度 | 不阻塞编辑，不丢当前选择 |

- 刷新不清空搜索/类型过滤；
- 刷新后当前选中文件仍存在则保持选中；不存在则清空选中并提示；
- 错误不写成文档 issue；资源抽屉错误是 UI 状态。

## 明确不做

- 上传资源；
- 删除/重命名/移动资源；
- 写 `resource/` 文件；
- 读取文件大小、分辨率、时长、缩略图；
- 播放音频/视频预览；
- 扫描资源文件内容；
- 建立资源数据库或索引缓存到脚本；
- 把 `resource.list` 结果写进文档。

## 验收标准

1. 打开 `resources` 抽屉：默认 `kind=all`，显示资源根下文件；目录面包屑从 `resource/` 开始。
2. 类型过滤“图片”：只剩 `png/gif`；切“音频”：只剩音频白名单扩展名；切“LUT”：只剩 `.cube`。
3. 搜索 `theme`：路径包含 `theme` 的文件保留；清空搜索恢复全量。
4. 选中 `audio/theme.ogg`，当前焦点在 `AUDIO` `sound`（`source=file`）：填入按钮可用；点击后字段写入 `audio/theme.ogg`。
5. 选中 `.cube`，当前焦点在 `OVERLAY path`：填入按钮禁用，提示“LUT 只能填入 ADJUST lut”。
6. 选中图片，当前焦点在 `ADJUST lut`：填入按钮禁用。
7. 选中文件，当前焦点不在媒体字段：填入按钮禁用；不默认改 `path`。
8. 点“定位引用”：列出引用该文件的片段/字段；点击后选中片段并滚到字段，不改文档。
9. `source=minecraft` 的 `sound` 不出现在文件引用列表；`@lang:` key 不出现在媒体引用列表。
10. 请求失败：错误条出现，旧列表保留；重试成功后恢复；选中不丢。
11. 返回 2000 条：显示“可能未列全”黄条；不把未列出文件标成“缺失”。
12. 语言页签：显示语言代码和 key 矩阵；没有编辑/删除按钮。
13. 保存重开：抽屉不写文档；资源列表、搜索、选中状态不进入脚本。
