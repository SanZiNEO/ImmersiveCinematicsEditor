# 13.02 — WebUI 真实游戏工作流冒烟

## 目标、前置、引用

13.01通过、03外部宿主链路可用。本轮只运行Electron WebUI，分别连接Forge/Fabric主模组；不启动AUI附属编辑器。依据J:webui/WebEditorApi.handle（31–88）、PreviewProtocol/PreviewStreamer、media/capture/CaptureHub及其迁入editor.webui后的实际实现；预览必须来自游戏。界面职责按[片段效果控件工作区](../shared/effect-controls-workspace.md)验收：主时间轴只编排片段，`clip.effects`统一效果控件与`selection.properties`快捷属性可同时可见。

## 输入输出与必跑步骤

输入黄金脚本、真实游戏环境/资源、WebUI生产或明确开发构建；输出逐步骤操作/结果/日志或画面来源、失败责任类与复验记录。

1. 启动游戏与WebUI，实际认证→schema/项目→文件夹关系图→悬停摘要→打开脚本。无旧左栏/整脚本源码列。分别验证布局拖动、文件夹移动、真实依赖维护；失败不只在图上假成功。
2. 主时间轴创建/移动/裁切/分割片段；选中含大量属性的片段，确认轨道高度不变、无属性节点/对象展开/关键帧汇总，片段只承担编排。在`clip.effects`同时展开位置与朝向（x/yaw不同时间各有节点、y为常量），确认左右行对齐、切换选中行不隐藏其他组；用局部标尺seek并对照全局播放头，双向映射正确且两个视口缩放互不重置；在`selection.properties`改同一目标值，确认两面板与标准文档同步。加入路径/镜头/转场、图像视频字幕/遮幅、音频、调色、事件；把有限片段5秒外的节点定位、编辑、撤销并拖回，主时间轴片段仍为5秒。真实预览检查；小窗停靠、IME数值/文本输入、节点拖动与片段拖动/停靠不互抢。保存、关文档、重载不丢语义与两面板停靠/局部视口状态。
3. 真游戏触发、事实查询、规则挂起释放/分支出口、循环和命令权限分别验证；编辑器预览不发送禁止的服务端命令。飞控退出按授权对象写回，取消无修改。
4. 有编码器H264与无编码器RGBA两路径都显示同一游戏真实画面，保留HUD/lane/调色，不捕获编辑器UI。没有帧/解码错误显示明确占位，不切假演示。
5. 播放/暂停/seek/工作区A–B、游戏暂停、窗口/DPI变化、换维度/世界、断连重连、关闭/总开关重复切换。全局播放头与效果控件局部seek经同一映射；旧会话帧不污染新会话，关闭只释放本端点拥有资源。
6. 保存失败、坏脚本、缺资源、无有效画面、认证错误与异常退出，均可定位、保留未保存数据、游戏正常，无残留输入/编码进程/订阅。效果控件/快捷属性的取消、非法值与提交失败保留原文档，不串写另一个对象或片段。

## 验收与完成定义

WebUI→Forge与WebUI→Fabric全部适用场景真实完成；失败退回原轮复验，不mock、不删功能。新界面合同必须在两通路都真实通过：主时间轴无属性节点/对象展开；效果控件多组多属性同时可见且行对齐；局部/全局标尺映射正确；两面板同值命令同步；轴外帧在效果控件定位编辑且不拉宽主轴；小窗停靠/IME/节点拖动/撤销/保存不互抢。没有AUI运行/GPU进程内帧/附属模组验收前置，它们仅14迁移。输出真实结果而不是“步骤完整”；未运行明确未执行。
