# 05-03 节点卡片、悬停与打开

## 目标

把图上的每个脚本节点做成一份可读摘要：卡片显示身份/时长/轨道/触发器/状态；悬停显示完整依赖与问题；单击高亮上下游；双击/Enter/浮层按钮打开脚本。节点不是编辑器，不提供轨道、片段、关键帧、依赖写操作。

## 节点卡片

固定尺寸 `196×64`（沿用 `graphLayout.NODE_W/H`）；内容分三层：

```text
NodeCard
  NodeHead     name（省略中间，tooltip 全名） + 状态徽标
  NodePath     path（省略中间，tooltip 全路径）
  NodeMeta     duration / infinite + track chips + trigger count
```

字段规则：

| 区域 | 内容 | 约束 |
|---|---|---|
| 名称 | `node.name`，空则 `scriptId`，再空则文件名 | 最多 1 行，省略号；不换行撑高 |
| 状态徽标 | `invalid`、`inCycle`、`isolated` 三选一优先：invalid > cycle > isolated | 不用纯颜色；带 `!`/`环`/`孤` 字符与 tooltip |
| 路径 | `node.path` | 相对 `scripts`；不显示绝对路径 |
| 时长 | `infinite ? "无限" : duration.toFixed(1)+"s"` | `duration=0` 且 `infinite=false` 显示 `0.0s`，不显示 `∞` |
| 轨道 | 最多 3 个 `type×clips` chip，超出 `+N` | 不显示对象/关键帧数量 |
| 触发器 | `triggers.length` 个，显示 `trigger` 图标/文字 | 不显示 requires 明细；明细在悬停 |

卡片状态：

- `valid=false`：左边框 `error`、右上 `!`；点击仍可选中/打开，但 tooltip 显示错误。
- `inCycle=true`：右上 `环`，虚线边框；不阻止打开。
- `isolated=true`：右上 `孤`，低饱和；不隐藏。
- `selected`：2px `selection-outline`；`up/down`：上下游高亮色；`dim`：过滤/选中无关时降不透明度，不隐藏（除非“只看匹配”）。
- 卡片内不出现按钮、输入框、菜单；所有动作在 tooltip/右键/键盘。

## 悬停摘要

- 进入节点 250ms 后显示；离开 150ms 后隐藏；移动时跟随但夹在画布内，不遮节点本身。
- 浮层宽度 360px；最大高度 `min(520, 画布高-24)`，超出滚动；不因内容多而撑破画布。
- 悬停只读，不进入文档页、不建脏文档、不触发未保存保护。
- 节点卡片继续用 `script.graph` 摘要；悬停时按需通过现有只读读脚本通道取当前脚本的 `meta.triggers`，缓存触发器摘要。缓存按 `path + 文件版本/刷新版本` 失效；`script.graph.invalidated` 后丢弃。
- 读取失败：退回节点已有摘要（类型、可重复、前置），条件区显示“读取失败，条件暂不可用”，不伪造条件。
- 内容顺序：

```text
名称
path · id=<scriptId 或 "缺失">
作者 / 维度 / 优先级（有则显示）
时长：有限/无限
轨道：type×clips 全部
说明：description（@lang 解析后的文本）
问题：node.error（红）

触发器（N）
  1. location · 单次 · delay 1.5s
     条件：
       全部满足
         ├ 位于 主世界 · 球形 (10,64,20) r=5
         └ 生物群系 = minecraft:taiga
     前置：
         ├ script_played → chapter1（已解析）
         └ script_started → chapter2（缺失）

  2. any · 可重复 · 连续
     条件：
       任一满足
         ├ advancement = story/enter
         └ 玩家登录
     前置：
         无

上游引用：requires.length 个
[定位到触发器] [打开脚本] [复制路径]
```

规则：

- 列出当前脚本**全部**触发器，不按数量截断、不只显示前三个、不折叠成“+N”。
- 每个触发器完整展开条件树；`all_of` 显示“全部满足”，`any` 显示“任一满足”，递归缩进。
- 叶子条件用固定中文摘要，与 11-04 共用同一套格式化规则。
- 触发器头行显示 `type`、单次/可重复、`delay`、`on_enter`、`exit_buffer`、`continuity` 概要；没有的不占位。
- `requires` 挂在对应触发器下面，显示 `type → 目标脚本`；前置不汇总到触发器外层。
- 前置状态：`已解析` / `缺失` / `自引用` / `重复 id` / `自定义前置，只读`。
- 没有条件：显示“无场景条件”；没有前置：显示“无前置”。
- 未知条件类型：显示 `未知条件 type` + 原始字段，只读，不猜。
- 内容多时卡片内部滚动；不把触发器或条件截断。
- 卡片不出现输入框、下拉、删除按钮。
- 触发器块可聚焦；聚焦/点击某块把它设为“当前触发器”，底部“定位到触发器”对该块生效；未选时按钮 disabled，提示“先选择一个触发器”。
- 底部按钮“打开脚本”“复制路径”可用键盘聚焦；`Esc` 关闭浮层并回到节点。

## 选中与上下游

- 单击节点：选中；再击同一节点取消；`Esc` 清选中。
- 选中后双向 BFS：
  - `up`：沿入边，所有前置脚本；
  - `down`：沿出边，所有依赖方；
  - 自身不算 up/down；环内节点仍在 up/down 集合中，但用 `inCycle` 标记。
- 边状态：两端都在 up/down 或选中 → 对应高亮；其余 dim；过滤叠加时，不匹配的节点 dim；`onlyMatches` 才 hidden。
- 选中不改变过滤条件；过滤不自动选中第一个匹配；空结果不选中。
- 选中状态只存图视图 session，不进文档、不进撤销、不写盘。

## 打开脚本

### 入口

- 双击节点。
- 节点聚焦后 `Enter`。
- 悬停浮层“打开脚本”按钮。
- 右键菜单“打开脚本”。

### 流程

1. 取 `node.path`；`scriptId` 只用于显示，不作为打开参数。
2. 如果 `state.currentPath === node.path` 且文档已打开 → 只切到 `document` 页并聚焦文档，不重新 `script.load`，不丢未保存修改。
3. 如果有其他脏文档 → 走 04-04 的 `UnsavedGuard`：保存/放弃/取消；取消留在图页。
4. 调 03 的 `openDoc(path)`（内部 `script.load`）；成功 → `PageRouter.navigate('document', {docId})`；失败 → 留在图页，错误条显示原因，节点保持选中。
5. 打开成功后，03 按现有规则选中第一个 CAMERA 片段；05 不另选触发器、不自动播放。
6. 焦点：进入文档页后聚焦文档顶栏/主时间轴，按 04-10 的焦点顺序；返回图页时回到原节点。

### 失败与边界

- 断连：打开按钮 disabled，tooltip 显示“未连接模组”；本地脚本仍可通过项目页“打开脚本文件”入口打开。
- 文件被外部删除：`script.load` 失败 → 图节点标 `invalid`，错误条“脚本已不存在，刷新图”；不清空整张图。
- 打开中重复点击：同一 path 的请求合并；只接受最后一次结果；不并发打开两个文档。
- 打开失败不自动切到别的脚本，不自动关闭当前文档。
- 节点 path 含非法字符/越界：后端拒绝；图显示 warning，不尝试打开。

## 定位到触发器

悬停浮层底部的“定位到触发器”是独立入口，不是“打开脚本”的替代：

1. 必须先在悬停卡里选中一个触发器块；未选时按钮 disabled，不默认取第一个。
2. 取 `node.path`；如果 `state.currentPath === node.path` 且文档已打开 → 只切到 `document` 页并打开 `behavior` 抽屉，不重新 `script.load`，不丢未保存修改。
3. 如果有其他脏文档 → 走 04-04 的 `UnsavedGuard`：保存/放弃/取消；取消留在图页。
4. 否则调 03 的 `openDoc(path)`；打开后切到 `behavior` 抽屉，把行为页切到该触发器，选中它并展开详情。
5. 触发器解析顺序：`id` 唯一命中时用 `id`；没有 `id` 或 `id` 重复时用声明下标 `type#下标`；两者都对不上 → 错误条“脚本已变化，未找到该触发器”，不伪造选中。
6. 不自动播放、不自动 seek、不自动改触发器字段。
7. 焦点进入行为页触发器详情；返回图页时回到原节点。

“打开脚本”仍然只打开文档，不选触发器；03 按现有规则选中第一个 CAMERA 片段。

## 键盘与可访问性

- 图节点采用 roving tabindex：画布内只有一个节点 `tabindex=0`，方向键移动到几何最近的节点；`Home/End` 到首/末节点；`Enter` 打开；`Space` 选中；`Esc` 清选中。
- 节点 `aria-label`：`脚本 <name>，<path>，<duration>，<trigger count> 个触发器`；无效节点加“有问题”。
- 悬停浮层用 `role="tooltip"` + `aria-describedby` 关联节点，不用 `role="dialog"`；键盘聚焦节点时也显示浮层（不依赖 hover）。
- 浮层内容可滚动、可聚焦：`Tab` 进入触发器块 → 方向键/`Tab` 切换块 → `Enter` 设为当前触发器 → 再 `Tab` 到“定位到触发器/打开脚本/复制路径”。
- 焦点环 2px `focus` token；不 `outline:none` 无替代。
- 过滤输入框、文件夹菜单、移动确认框打开时，节点快捷键不触发。
- 图内 `Delete` 不删脚本；`Backspace` 不导航（避免误退）。

## 验收标准

- 正常节点卡片：名称/路径/时长/3 个轨道 chip/触发器数量正确；不显示对象或关键帧数量。
- 无限节点：显示“无限”，不显示 `0.0s` 或 `∞` 混用；`duration<0` 的既有节点也标无限。
- 坏脚本节点：`!` + error 色；悬停显示具体错误；双击仍打开（打开后由 03 显示 block 问题），不因坏节点禁用整图。
- 环内节点：`环` 标记；上下游高亮仍正确；不因为环导致 BFS 死循环。
- 悬停 250ms 出现；移开 150ms 消失；浮层不遮当前节点；内容多时内部滚动。
- 悬停列出全部触发器；每个触发器完整条件树与前置可见；`all_of`/`any` 递归缩进；不截断、不折叠成“+N”。
- 触发器头行：单次/可重复、delay、on_enter、exit_buffer、continuity 有则显示；没有的不占位。
- 自定义前置：显示“自定义前置，只读”，不显示“缺失”，不提供编辑按钮。
- 缺失目标：显示“缺失”；不把缺失节点画成边；可定位/打开目标（若存在）。
- 自引用/重复 id：显示对应状态，不显示“已解析”。
- 读取脚本失败：退回节点摘要；条件区显示“读取失败，条件暂不可用”；不编默认条件。
- 未选触发器时“定位到触发器”disabled；选中后打开文档并选中该触发器，不播放、不 seek。
- 定位时脚本已变化：按 id/声明下标解析；找不到显示“脚本已变化，未找到该触发器”，不伪造选中。
- 已打开同一脚本：定位只切页并选中，不重新加载、不丢未保存修改。
- 其他脏文档：定位先走 UnsavedGuard；取消留在图页。
- 单击选中 → 上下游高亮；再击取消；Esc 清选中；过滤叠加不隐藏匹配节点（除非只看匹配）。
- 双击打开 → 进入 `document` 页；脏文档先弹三选一；取消留在图页。
- 已打开同一脚本：不重新加载、不丢未保存修改；只切页。
- 打开失败：留在图页、节点仍选中、错误可见；不白屏、不自动切其他脚本。
- 键盘：Tab 进图 → 方向键换节点 → Enter 打开 → Esc 回图；焦点环可见；不依赖鼠标。
- `grep 整页切换`：图组件 0 命中；图入口由 `PageRouter`/面板路由决定。
- `grep 关键帧`：图组件 0 命中。

## 节点交互范围

- 节点卡片只读显示摘要；轨道/片段/关键帧编辑在主轴，依赖维护走 05-07 对话框。
- 节点重命名/删除走图菜单与项目入口；卡片内不放内联重命名/删除。
- 触发器 identity 在诊断/维护浮层显示，默认不铺在卡片上。
- 双击/Enter 只打开文档；不自动播放、不自动 seek 到某触发器。
- 字段缺失显示“未填写”，不编默认作者/描述。
- 选中只存图视图 session；不写 `state.selection`。
