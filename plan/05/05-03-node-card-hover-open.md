# 05-03 节点卡片、悬停与图上改前置

## 目标

把图上的每个节点做成一份可读摘要，并把「悬停 → 看触发器设定 → 改前置关系」这条主线打通：卡片显示身份/时长/触发器数；悬停展示该脚本**全部触发器**的类型、重复性、条件摘要与前置列表；前置行上直接提供「换目标 / 删除」，底部提供「加前置」。悬停里不改触发器本身。

## 节点卡片

固定尺寸 `196×64`（沿用 `graphLayout.NODE_W/H`）；三层：

```text
NodeCard
  NodeHead     name（省略中间，tooltip 全名） + 状态徽标
  NodePath     path（省略中间，tooltip 全路径）
  NodeMeta     duration / infinite + 前置数 + 触发器数
```

字段规则：

| 区域 | 内容 | 约束 |
|---|---|---|
| 名称 | `node.name`，空则 `scriptId`，再空则文件名 | 最多 1 行，省略号；不换行撑高 |
| 状态徽标 | `invalid`、`inCycle`、`isolated` 三选一优先：invalid > cycle > isolated | 不用纯颜色；带 `!`/`环`/`孤` 字符与 tooltip |
| 路径 | `node.path` | 相对 `scripts`；不显示绝对路径 |
| 时长 | `infinite ? "无限" : duration.toFixed(1)+"s"` | `duration=0` 且 `infinite=false` 显示 `0.0s` |
| 前置 | `requiresTargets.length` + 出边数 | 显示「前置 N / 依赖方 M」，不列目标名 |
| 触发器 | `triggers.length` 个 | 不列明细；明细在悬停 |

卡片状态：

- `valid=false`：左边框 `--error`、右上 `!`；仍可选中/打开。
- `inCycle=true`：右上 `环`，虚线边框；不阻止打开。
- `isolated=true`：右上 `孤`，低饱和；不隐藏。
- `selected`：2px `--selection-outline`；`up/down`：上下游高亮色；`dim`：过滤无关时降不透明度（「只看匹配/只显异常」才隐藏）。
- 卡片内不出现按钮、输入框、菜单；所有动作在悬停卡片/右键/键盘。

## 悬停卡片

### 触发与尺寸

- 进入节点 250ms 后显示；离开 150ms 后隐藏；跟随指针但夹在画布内，不遮当前节点。
- 宽度 420px；最大高度 `min(560, 画布高-24)`，超出内部滚动；不撑破画布。
- `role="tooltip"`，与节点 `aria-describedby` 关联；键盘聚焦节点时也显示（不依赖 hover）。
- 悬停本身不建脏文档、不触发未保存保护、不写盘。

### 内容结构

```text
名称 · path · id=<scriptId 或 "缺失">
作者 / 维度 / 优先级（有则显示）
时长：有限/无限 · 前置 N 条 / 依赖方 M 个
问题：node.error（红）

触发器（N）
  1. location · 单次 · delay 1.5s
     条件：位于 主世界 · 球形 (10,64,20) r=5；生物群系 = taiga
     前置：
       [0] script_played → chapter1        [已解析] [换目标] [删除]
       [1] script_started → chapter2       [缺失]   [换目标] [删除]
       [2] weather=rain（自定义）           [只读]
      + 加前置

  2. any · 可重复 · 连续
     条件：任一满足 —— advancement = story/enter；玩家登录
     前置：无
      + 加前置

[打开脚本] [复制路径]
```

规则：

- 列出**全部**触发器，不截断、不折叠成「+N」。
- 条件只显示摘要（一层）：`all_of` → 「全部满足」、`any` → 「任一满足」，子条件用「；」连接；超过 3 个子条件时显示前 3 个 + 「等 N 项」。完整条件树在编辑器页看，不在悬停里递归展开（悬停是速览，不是编辑器）。
- 条件摘要来自 `script.graph` 的轻量摘要；若索引未带摘要，悬停时通过只读读脚本通道取一次并缓存（缓存按 `path + graphVersion` 失效）。读取失败显示「读取失败，条件暂不可用」，不伪造。
- 触发器头行：`type`、单次/可重复、`delay`（>0 才显示）、`continuity` 概要（有才显示）。
- 前置行显示：`[index] type → 目标`；状态徽标：`已解析` / `缺失` / `自引用` / `重复 id` / `自定义前置，只读`。
- 前置行操作：
  - `换目标`、`删除`：仅 `editable=true` 时出现；点击后打开 05-07 的 `DependencyEditor`（预填该条）。
  - 自定义前置：无操作，只有「只读」。
  - 目标缺失 / 重复 id：`换目标` 可用（改成有效目标），`删除` 可用。
- 每个触发器底部有「+ 加前置」：打开 `DependencyEditor`（预填该触发器），默认追加到末尾。
- 底部按钮：「打开脚本」「复制路径」；触发器块可聚焦，`Enter` 在该块打开「+ 加前置」。
- 悬停卡片里**不出现**：加/删触发器、改触发器类型、改条件、改 delay/repeatable/continuity。这些只在编辑器页。
- `Esc` 关闭悬停卡片并回到节点。

## 图上改前置的入口与边界

这是本页唯一的写操作，规则一句话：**只改这条 `requires` 条目，只写依赖方这一个脚本文件**。

| 操作 | 入口 | 结果 |
|---|---|---|
| 加一条前置 | 触发器块底部「+ 加前置」 | 该触发器 `requires` 末尾追加 `{type, data:{script}}` |
| 换目标 | 前置行「换目标」 | 只替换该条的 `type`/`data.script`，数组顺序与其他条目不变 |
| 删一条 | 前置行「删除」（二次确认） | 删除该条；数组为空时删掉 `requires` 键 |

约束：

- 只允许内置三种类型（`script_played` / `script_started` / `script_completed`）；自定义前置只读。
- 目标必须是存在且 `meta.id` 唯一的脚本；不能是当前脚本自己（自引用）。
- 当前脚本必须已有 `meta.id`；没有时提示「先设置脚本 id」，不给改（否则无法被别人引用）。
- 一次只改一条；没有「批量替换」「拖动排序」。
- 写完不乐观更新：以服务端返回的该触发器 `requirements` 为准局部更新图；失败保留原样并把错误显示在悬停卡片/状态区。
- 与编辑器页改同一个 `requires`：同一份文档命令、同一套校验、同一套撤销。

## 选中与上下游

- 单击节点：选中；再击取消；`Esc` 清选中。
- 选中后双向 BFS（防环重复访问）：`up` = 所有上游前置，`down` = 所有下游依赖方；自身不算。
- 边状态：相关边加粗 + 箭头可见；无关 dim；过滤叠加时不匹配节点 dim，「只看匹配」才 hidden。
- 悬停只高亮一阶邻接；选中才递归。
- 选中状态只存图视图 session，不进文档、不进撤销、不写盘。

## 打开脚本 / 定位到触发器

### 打开脚本

- 入口：双击节点、节点聚焦 `Enter`、悬停卡片「打开脚本」、右键「打开脚本」。
- 流程：
  1. 取 `node.path`（`scriptId` 只用于显示）。
  2. 已是当前文档 → 只切到编辑器页并聚焦，不重新 `script.load`，不丢未保存修改。
  3. 有其他脏文档 → 走 04-04 `UnsavedGuard`（保存/放弃/取消）；取消留在脚本页。
  4. 调 03 `openDoc(path)`；成功 → `PageRouter.navigate('document')`；失败留在脚本页，错误条显示原因，节点保持选中。
  5. 打开后由 03 选中第一个 CAMERA 片段；05 不另选触发器、不自动播放。
- 打开失败不自动切别的脚本，不自动关当前文档。

### 定位到触发器

- 悬停卡片里触发器块右侧「定位」（或选中块后按 `Enter` 再选「定位」）：必须**先选中该触发器块**，不默认取第一个。
- 流程与打开脚本一致，进入编辑器页后打开行为/触发器面板并选中该触发器（`behavior` 抽屉）。
- 触发器解析：`id` 唯一命中 → 用 id；否则 `type#下标`；都对不上 → 错误条「脚本已变化，未找到该触发器」，不伪造选中。
- 不自动播放、不自动 seek、不改触发器字段。

## 键盘与可访问性

- 节点 roving tabindex（见 05-02）。
- 悬停卡片可聚焦：`Tab` 进入触发器块 → 方向键切换块 → `Enter` 打开该块的「+ 加前置」→ `Tab` 到前置行操作/底部按钮。
- 前置行的「换目标/删除」是按钮，`aria-label` 带目标名与索引，例如「替换第 2 条前置（chapter2）」。
- 焦点环 2px `--focus`；不 `outline:none` 无替代。
- 悬停卡片打开时，图快捷键不触发（`Delete`/方向键归卡片）。

## 验收标准

- 正常节点：名称/路径/时长/前置数/触发器数正确；不显示轨道对象或关键帧数量。
- 无限节点显示「无限」；`duration<0` 的既有节点也标无限。
- 坏脚本节点：`!` + error 色；悬停显示具体错误；双击仍打开（打开后由 03 显示 block 问题）。
- 环内节点：`环` 标记；上下游高亮正确；BFS 不死循环。
- 悬停 250ms 出现、移开 150ms 消失；不遮当前节点；内容多时内部滚动。
- 悬停列出全部触发器；每个触发器显示 type/重复性/delay/条件摘要/前置列表；不递归展开条件树。
- `all_of` 显示「全部满足」、`any` 显示「任一满足」；超过 3 个子条件显示「等 N 项」。
- 自定义前置显示「自定义前置，只读」，无「换目标/删除」；不显示「缺失」。
- 缺失目标显示「缺失」，仍可「换目标/删除」。
- 自引用/重复 id 显示对应状态，不显示「已解析」。
- 加一条 `script_started → b`：该触发器 `requires` 多一条；其他触发器/字段不变；图多一条边（B→A）；撤销一次全部回退。
- 换目标：数组顺序不变，只改该条；图边目标更新；其他边不受影响。
- 删唯一一条：`requires` 键删除；图边消失；节点无悬空桩。
- 删自定义前置：操作不可用（只读），文件不变。
- 目标不存在/重复 id：`target_missing` / `target_duplicate`；不写盘；悬停卡片保留并显示错误。
- 自引用：`self_reference`；不写盘。
- 当前脚本无 `meta.id`：不给加前置，提示「先设置脚本 id」。
- 指纹过期（另一窗口改了同一触发器）：`stale_requires`；返回当前列表；不覆盖。
- 已打开同一脚本且文档脏：拒绝图上写入并提示「先保存/放弃当前修改」；不覆盖内存。
- 写入成功后当前文档未脏：内存同步、`dirty=false`、不重载、不重置撤销栈。
- 打开同一脚本：只切页不重载；其他脏文档先走 `UnsavedGuard`。
- 定位到触发器：选中的触发器被选中；脚本已变化时显示明确错误，不伪造。
- 键盘：Tab 进图 → 方向键换节点 → Enter 开悬停 → Tab 到前置行 → Enter 换目标；全键盘可完成加/删/换。
- `grep window.prompt`：图组件 0 命中。
- `grep 关键帧`：图组件 0 命中。

## 交互边界

- 节点卡片只读摘要；轨道/片段/关键帧编辑在编辑器页。
- 悬停里只改前置，不改触发器本身（类型/条件/delay/repeatable/continuity）。
- 前置编辑走显式 `DependencyEditor`（05-07），不做拖线建边、不做拖动排序。
- 触发器 identity 在悬停里以小字显示，默认不铺在卡片上。
- 字段缺失显示「未填写」，不编默认作者/描述。
- 选中只存图视图 session；不写 `state.selection`。
