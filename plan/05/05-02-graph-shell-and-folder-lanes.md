# 05-02 脚本页与无限画布

## 目标

把 `project.main` 做成脚本页的唯一入口：一张可平移缩放的无限画布，上面是脚本前置关系图。加载、错误、空态、工具栏、分组、搜索过滤都在这里；图只负责「看结构 + 改前置」，不编辑轨道、片段、关键帧、触发器内容。

## 页面归属

- 页面：`project`（脚本页）。应用启动默认进这一页。
- 面板：`core.script-graph` 的 `ScriptGraphPanel`，panelId `script.graph`，defaultSlot `project.main`。
- 面板只从 `PanelContext` 取 `commands/services/status/theme/i18n`；不接受外壳传的尺寸/路由 props。
- **不再有启动器主体**：最近项目、打开脚本、打开文件夹移到顶栏（04-04 的页面顶栏入口）；脚本页主体就是图。
- 首次进入且没有任何脚本时，图区显示真实空态（见下），不显示假节点、不显示统计。

## 组件结构

```text
ScriptGraphPanel
  GraphToolbar          // 刷新 / 搜索 / 过滤 / 缩放 / 适配 / 分组开关 / 新建脚本
  GraphBanner           // 加载 / 错误 / 空态 / 断连 / 截断
  GraphCanvas           // 无限画布：接收 pointer/wheel，管理 pan/zoom
    GraphWorld          // 世界坐标容器（transform: translate+scale）
      GraphLane         // 可选：按目录分组的分组带（不是泳道 CRUD）
      GraphEdges        // SVG：有向边 + 箭头 + 悬空桩
      NodeCard          // 05-03
    GraphLegend         // 图例：内置前置三种类型、自定义只读、异常标记
  DependencyEditor      // 05-07：图上改一条前置
  GraphContextMenu      // 节点右键：打开脚本 / 改前置 / 复制路径 / 聚焦上下游
```

- `GraphCanvas` 只画与手势，不读写文件；所有变更走 `commands` / `services`。
- 布局与几何是纯函数，放 `src/graph/`（`computeLayout`、`hitTest`、`viewportTransform`），组件只消费。
- 不引入第三方图库。

## 无限画布

| 交互 | 行为 |
|---|---|
| 拖空白处 | 平移（`tx/ty`）；拖动阈值 4px，小于阈值视为点击空白 → 清选中 |
| 中键拖动 / 空格+拖动 | 平移（不抢占节点拖动） |
| 滚轮 | 缩放，指针锚定（缩放中心不跑）；0.15–2.5 夹取 |
| 工具栏 −/+ | 缩放 1.2 倍步进，画布中心锚定 |
| 适配 `0` | 只对当前可见节点计算包围盒；过滤隐藏/折叠分组不计入 |
| 双击空白 | 适配 |
| 键盘方向键 | 平移 40px（图聚焦时） |

规则：

- 世界坐标与屏幕坐标分开；节点位置存世界坐标（05-04），`tx/ty/scale` 是视图状态。
- 缩放不改变节点尺寸的语义（节点在世界坐标里固定 196×64，随 scale 缩放显示）；文字在 scale < 0.5 时隐藏次要行，只留名称。
- 画布无边界，不出现滚动条；`overflow: hidden`。
- 拖动/缩放期间不触发节点点击、不抢全局快捷键；输入框聚焦时不响应图快捷键。
- 连续手势只在内存更新 transform；松手后 debounce 写视图状态（05-04），不每一帧写盘。

## 布局

默认布局是**确定性分层**，不是随机力导向：

1. 计算每个节点的「层级」：无前置 = 第 0 层；有前置 = `max(前置层级) + 1`；环上的节点统一放到「环层」（取环内最深层级），并标 `inCycle`。
2. 同层节点按目录分组依次排列；分组内按 `name` 字典序，保证两次打开位置一致。
3. 层间距 180px，同层节点间距 60px；节点 196×64。
4. 手摆覆盖（05-04）优先于自动布局：有 `overrides[path]` 就用它，没有才用计算结果。
5. 布局不做动画过渡（`prefers-reduced-motion` 下也没有）；刷新后节点不跳位，除非结构变化导致层级变化。

为什么分层而不是力导向：前置关系是 DAG（环是异常），分层能一眼看出「谁是上游、谁是下游、链条多长」；力导向在几十个节点后就开始互相遮挡，且每次刷新位置不同。

## 按目录分组

- 分组是**视觉分组**，不是目录管理：同一目录的节点在布局里相邻，并在世界坐标里画一条可折叠的分组带（标题 = 目录名，tooltip = 完整路径 + 脚本数）。
- 分组开关关掉时，所有节点按层级铺开，不画分组带。
- 折叠分组只隐藏该组节点（视图 session 状态，不写盘）；被隐藏节点的边不画，但**悬停上下游高亮时会把折叠组里的相关节点临时展开**（只读，不改折叠状态）。
- 不提供目录新建/重命名/删除，不提供拖脚本进目录；目录由外部文件管理。

## 工具栏

| 控件 | 行为 |
|---|---|
| 刷新 | 发 `script.graph`，保留当前选中/视图/过滤；显示「正在扫描」；失败保留旧图并标「已过期」 |
| 搜索 | 匹配 `name/path/scriptId/trigger.type`；输入 150ms 防抖；纯前端过滤，不请求服务端 |
| 触发器过滤 | 值来自当前 `nodes[].triggers[].type`，排序去重；选中后只显示含该类型触发器的节点 |
| 只显异常 | 只看 `invalid / dangling / self_reference / duplicate_id / cycle` 的节点/边 |
| 分组开关 | 显示/隐藏按目录分组带 |
| 缩放 −/+ | 见上表 |
| 适配 | 见上表 |
| 新建脚本 | 走 03 `file.newDoc`；成功后刷新图并选中新节点；路径冲突让作者改名，不覆盖 |
| 统计 | `nodeCount / edgeCount / invalidCount / warningCount`；截断时加「已截断」标记 |

- 空结果显式空态：「没有匹配的脚本」，并提供「清除过滤」；不显示假节点。
- 提示文案：「拖拽平移 · 滚轮缩放 · 单击高亮上下游 · 双击打开脚本 · 悬停看触发器设定」；不写假快捷键。

## 加载 / 错误 / 空态

| 状态 | 呈现 |
|---|---|
| 首次加载 | 骨架屏 + 「正在扫描脚本」；不显示 0 节点 |
| 空项目 | 真实空态：`scripts` 下没有脚本；按钮「新建脚本」「打开脚本文件」；不画假节点 |
| 断连 | 「未连接模组：启动游戏内 WebUI 服务后可查看脚本关系」；保留上一次成功的图并标「已过期」；本地脚本仍可从顶栏打开 |
| 扫描失败 | 错误条 + 原因 + 重试；保留上一次成功的图 |
| 部分坏脚本 | 图正常显示；坏节点标红；warnings 入口显示数量；不弹全屏错误 |
| 截断 | 顶部条「脚本过多，已截断到 800 节点 / 2000 边」；统计显示真实计数；不假装完整 |
| 布局损坏 | 05-04 回退自动布局，状态区提示「图布局已恢复默认」；不丢用户脚本 |
| 插件缺失 | `PanelHost` 的缺失占位；不把图组件换成假数据 |

## 选中与上下游

- 单击节点：选中；再击同一节点取消；`Esc` 清选中；点击空白清选中。
- 选中后双向 BFS：
  - `up`：沿入边（被依赖方向），所有上游前置；
  - `down`：沿出边，所有下游依赖方；
  - 自身不在 up/down 集合里；环内节点用 `inCycle` 标记，BFS 要防重复访问。
- 高亮规则：选中节点 2px `selection-outline`；上游用 `--c1`、下游用 `--c2`；相关边加粗并显示方向箭头；无关节点/边 dim 到 0.35，但**不隐藏**（除非开了「只看匹配/只显异常」）。
- 悬停单个节点时只高亮它的一阶邻接（不递归）；选中才递归。
- 选中状态只存图视图 session，不进文档、不进撤销、不写盘。

## 键盘与可访问性

- 图聚焦时：方向键平移；`+/-` 缩放；`0` 适配；`Esc` 清选中；`Enter` 打开选中节点；`Space` 选中/取消。
- 节点用 roving tabindex：画布内只有一个节点 `tabindex=0`，方向键移到几何最近的节点；`Home/End` 到首/末。
- 节点 `aria-label`：`脚本 <name>，<path>，<N> 个触发器，<M> 条前置`。
- 右键菜单可用 `Shift+F10` 打开，菜单项可 Tab/方向键选择。
- 焦点环 2px `--focus`，不用 `outline:none` 无替代。
- 图内 `Delete` 不删脚本；`Backspace` 不导航。

## 验收标准

- 启动应用直接进脚本页：`.script-graph-panel` 可见；没有启动器卡片；顶栏有「新建脚本 / 打开脚本」入口。
- 空 `scripts`：真实空态文案 + 两个按钮；不显示假节点、不显示 0 统计。
- 10 个脚本、A 依赖 B/C、B 依赖 D：默认布局里 D 在最左层、C 次之、B 在 D 右侧、A 在最右；同层按目录分组。
- 拖动空白平移 200px，坐标变化；滚轮缩放后指针下的节点不跳走；`0` 适配后全部可见。
- 缩放 0.15/2.5 被夹住，不出现负尺寸或空白翻转。
- 搜索 `boss`：只保留匹配节点与相关边；清除过滤恢复。
- 「只显异常」：只剩 invalid/dangling/self_reference/duplicate_id/cycle 相关节点；其他 dim/隐藏按规则。
- 分组开关：关闭后分组带消失，节点按层级铺开；折叠分组后组内节点隐藏，边不画。
- 选中 A：上游 B/C、下游（若有）高亮；再击 A 取消；`Esc` 清空。
- A↔B 环：两节点标 `inCycle`，BFS 不死循环，选中 A 时 B 出现在 up 且不重复。
- 断连：图保留并标「已过期」，刷新按钮给出原因；不白屏。
- 截断 900 节点：顶部条提示，统计显示真实 900；只渲染 800。
- `grep window.prompt`：图组件 0 命中。
- `grep 第三方图库`：0 命中（不引入新依赖）。

## 画布边界

- 图内只显示节点与边；轨道、片段、关键帧、触发器内容编辑在编辑器页（05-09～05-12）。
- 图上唯一的写操作是「改一条前置」（05-07）；其他写操作（改 id、删脚本、建脚本）走各自入口。
- 不做依赖图的路径查找、环检测报告、DOT/SVG/PNG 导出。
- 不做目录 CRUD、不做脚本拖入目录。
- 布局用纯函数 + 手摆覆盖；不引入第三方图库，不做动画。
