# 05-10 主轴视图与轨道/片段

## 目标

把主时间轴做成只编排片段的工作区视图：文档里的轨道（内置七型 + 已注册第三方型）、轨道头、片段块、左右裁切手柄、工具栏、右键菜单、空态/超长滚动。轨道按文档顺序渲染，不是永远七行；空文档给添加入口。片段块高度固定，不因对象/属性数量变化；不画关键帧菱形、不画对象行、不画属性节点。

## 组件

```text
TimelinePanel                  // core.timeline 面板，panelId timeline.main
  TimelineToolbar
  TimelineViewport
    TimelineRuler              // 05-12
    TrackHeaderColumn          // 固定左侧，横向滚动时不动
      TrackHeader × N
    TrackScrollArea            // 横向滚动容器
      TrackRow × N
        ClipBlock[]
        ClipEdgeHandle
    PlayheadLine
  TimelineContextMenu
```

- `TimelinePanel` 注册 `core.timeline`；defaultSlot `timeline.main`；04-02 的 `document.bottom` 放它；高度由 04 布局夹 160–560，默认窗口 0.34。
- `TrackHeaderColumn` 与 `TrackScrollArea` 共享纵向滚动；横向滚动只作用于轨道区，轨道头固定。
- 组件只从 `PanelContext` 取 `commands/services/selection/docRevision`；不直接读写 store 的 `tracks`，所有变更走 03 `EditorCommand`。
- `TimelinePanel` 是唯一主时间轴组件；关键帧相关子组件不在主轴挂载。

## 轨道

轨道来自 `doc.timeline.tracks`，按文档数组顺序从上到下渲染；内置七型 + 已注册第三方型，不强行补出七行。

| 内置 type | 显示名 | 说明 |
|---|---|---|
| `CAMERA` | 镜头 | 镜头片段；主轴只显示片段 |
| `LETTERBOX` | 遮幅 | 最多一条；显示为单条带 |
| `AUDIO` | 音频 | 片段块显示时长/循环 |
| `EVENT` | 事件 | 片段块显示事件类型数量 |
| `MOD_EVENT` | 模组事件 | 同上 |
| `OVERLAY` | 叠加层 | 字幕/叠加 |
| `ADJUST` | 调色 | 调整片段；不画关键帧曲线 |

- 第三方轨道 `modid:xxx` 只按已注册 schema 显示类型名/色；未注册显示 `未知轨道（type）`，不猜字段。
- 轨道 id：`trackId = track.type + "#" + trackIndex`；不以数组下标做选择身份。
- 轨道头：
  - 左：类型色条 + 显示名（双击进入内联重命名）+ clip 数；
  - 右：眼睛/锁/喇叭三按钮（可见/锁定/静音）+ `+` 添加片段；
  - 按钮 `aria-pressed`；不写文档，只改 session `trackView`；重命名走 `timeline.renameTrack` 文档命令。
- 轨道行高度 52px；面板高度 <240px 时切紧凑档 34px；片段块高 40px（紧凑档 28px），垂直居中；`ADJUST` 行同高，不因曲线变高。
- 轨道头高 28px；横向滚动时固定；纵向滚动时与轨道行同步。
- 空轨道显示一条 1px 基线 + “空轨道” + `+` 添加片段；不是可点击的假片段。
- 文档没有轨道：显示“还没有轨道” + “添加轨道”；不自动补七轨。
- 添加轨道：轨道区底部/工具栏“添加轨道”，下拉列出 02 `TrackSchemas` 的内置七型 + 已注册第三方型；`LETTERBOX` 已存在时禁用；`ADJUST` 必须在列表里。
- 删除轨道：只允许空轨道（无片段）；右键轨道头“删除轨道”，二次确认；非空拒绝并提示先删/移片段。
- 轨道排序：轨道头上下拖动/右键“上移/下移”，提交 `timeline.reorderTracks`；一次拖动一条命令；不改变片段时间。
- 轨道可见/锁定/静音只影响会话；重命名/增删/排序是文档命令，走 03 `EditorCommand`。
- 轨道重命名：双击轨道头进入内联输入；`Enter` 提交、`Esc` 取消；空名/重名拒绝；不用 `window.prompt`。
- 轨道头键盘：`Tab` 进入轨道头列，上下键换行；`Space` 切可见、`L` 切锁定、`M` 切静音；按钮有 `aria-pressed`，不依赖鼠标。
- 轨道头焦点在轨道头列时，`L/M/Space` 由轨道头消费并阻止命令层；片段焦点时 `L` 才是切换片段循环。
- 轨道类型不因重命名改变；显示名与 `type` 分开，第三方轨道名只读，不允许改成内置名。

## 片段块

`ClipBlock` 固定 40px 高，内容：

```text
[类型色条] 名称/ID（省略）        [∞/循环/警告徽标]
            start – end（1 位小数）
```

- 宽度 = `max(24px, clip.duration*pps)`；无限片段画到当前显示末端，右端渐隐 + `∞`，不画固定结束手柄。
- 宽度 <60px 不画时间文本；宽度 <40px 只画类型色条 + 状态徽标；标签省略，不撑高。
- 名称：`clip.label` / `clip.name` / `clip.id` / “未命名片段”；最多 1 行省略；tooltip 全名。
- 时间：`start` 与 `end`；循环片段显示 `×N`；无限显示 `∞`；不显示总时长。
- 徽标：
  - `warn`：该片段有本地/服务端 block/warn；
  - `loop`：`loop=true`；
  - `infinite`：`duration<0` 或 `loop_count<0`；
  - `ref`：被 `paths/rules/exit` 引用（03 引用完整性）；只显示图标，不展开。
- 不显示：对象数量、属性数量、关键帧数量、关键帧菱形、对象行、属性节点、曲线缩略图。
- 100+ 属性的片段块与 0 属性片段块同高；属性数量不参与块高。
- 重叠：同一轨道两个片段时间重叠 → 两块都画，后开始者在上层；重叠区用斜纹/半透明标记；不自动错层、不自动裁剪。
- 选中：2px `selection` 边框；多选每个都有；主选区加左侧 3px 主色条。
- hover：显示左右 8px 手柄；手柄视觉 4px；离开/未选中隐藏。
- 拖动 ghost：半透明副本跟随指针；原块保留；松手才提交；`Esc` 取消。
- 片段块 `tabindex=0`，`aria-label`：`片段 <name>，<start> 到 <end>，<track>`；方向键在片段间移动焦点。

## 工具栏

| 控件 | 行为 |
|---|---|
| 选择/刀片 | 选择工具（拖动/裁切）与刀片工具（点击片段分割）；`B` 切换，`Esc` 回选择 |
| 新建片段 | 当前轨道末尾追加 5s 片段；字段默认可构造才启用，否则按 05-11 列出缺失字段；无轨道时禁用并提示先加轨道 |
| 新建轨道 | 打开轨道类型下拉；已存在 `LETTERBOX` 时该项禁用 |
| 缩放 −/+ | 5–500 px/s；指针锚定；显示当前值 |
| 适配 | 按 `displayRange` 适配可视宽度；无限内容只适配已知有限末端 |
| 吸附开关 | 开/关；`Alt` 临时关闭；状态存 session |
| 播放头 | 显示当前时间；点击跳转；输入框可键入秒 |
| 添加标记 | 在播放头加 session marker；不写文档标记字段（05-12） |
| 选择信息 | `已选 N 个片段 · 主选 <name>`；无选择显示“未选择” |
| 空态按钮 | 无轨道时“添加轨道”；有轨道无片段时“添加片段/粘贴片段”；不伪造片段 |

- 图标用内联 SVG + `aria-label`，不引入图标库。
- 按钮 disabled 时给原因 tooltip，不只灰掉。
- 工具栏不出现脚本列表、JSON、校验入口。
- 刀片工具：点击片段内部（距端点 >0.01s）分割；点击端点 2px 内不分割并提示；分割仍走 05-11 的 `timeline.splitClip` 与引用预检。

## 右键菜单

菜单项（按选中态启用）：

```text
打开脚本
在此添加片段
剪切片段        Mod+X
复制片段        Mod+C
粘贴片段        Mod+V
在播放头分割    Mod+K
刀片分割（当前点击位置）
复制一份        Mod+D
切换循环        L
删除片段        Delete
波纹删除        Shift+Delete

轨道头右键：
重命名轨道
删除轨道（仅空轨）
上移 / 下移
```

- 菜单用统一 `ContextMenu` 组件；`Shift+F10` 或菜单键打开；方向键/Tab 选择；`Enter` 执行；`Esc` 关闭。
- 菜单项显示快捷键右对齐；disabled 显示原因（锁定轨道/无限片段/被引用禁止分割/空轨才能删）。
- 不出现 `window.prompt` 重命名；轨道重命名用轨道头内联输入。
- 右键空白轨道：显示“在此添加片段”“粘贴片段”“添加轨道”；不显示删除。
- 右键标尺：显示“循环入/循环出/清除 A-B/缩放到全部”；循环入/出写 `timeline.loop_*`，不是 UI 预览范围。

## 横向/纵向滚动

- 轨道区横向滚动：`scrollLeft` 同步 `TimelineScale.scrollLeft`；标尺随动；轨道头不动。
- 纵向滚动：总高 `28 + N*52`（紧凑档 `28 + N*34`）；面板 160px 时纵向滚动，轨道头列与轨道区同步。
- `scroll` 用 `requestAnimationFrame` 节流；不每次事件重排。
- 触控板双指横向滚动 = 时间轴滚动；`Ctrl+滚轮` = 缩放；普通滚轮 = 纵向滚动。
- 视口裁剪：每个 `TrackRow` 只渲染与可视时间窗 ±1 屏相交的片段块；不可见片段不挂 DOM，不按属性行虚拟化。
- 不做虚拟滚动库；视口裁剪是自写的最小窗口化。
- 拖拽片段到视口边缘 24px 内自动滚动；速度与距离成比例；松手停止。
- 拖动片段/框选/拖动裁切手柄期间，标尺点击不改变播放头（避免边拖边 seek）；松手后恢复。
- 无水平滚动条时也保留 8px 底部留白；不出现内容被裁。

## 主题与尺寸

- 轨道色/片段色/选择/警告/无限条纹全部走 04-07 主题 token；组件内不写死 hex。
- 每型轨道有独立 token；`ADJUST` 色相必须与 `CAMERA` 明显不同，不能撞色；第三方轨道按 type 稳定 hash 取色，不随机。
- 轨道头/行/片段块使用 `--surface-1/2/3`、`--border`、`--text`、`--text-muted`、`--accent`、`--warning`、`--error`。
- 字号：轨道头 12px、片段块 11px、时间 10px；缩放不改变字号。
- 高对比主题下边框/选中仍可见；不靠颜色单独传达状态（徽标带字符/图形）。
- 最小面板宽度 320px；窄于 480px 时工具栏折叠为图标 + tooltip，不换行溢出。

## 验收标准

- 文档有 3 条轨道就显示 3 行；文档没有轨道显示“还没有轨道 + 添加轨道”；不强行补七行。
- 添加轨道下拉含七型 + 已注册第三方型；`ADJUST` 在列表；已存在 `LETTERBOX` 时该项 disabled。
- 添加片段：当前轨道末尾出现 5s 片段（字段默认可构造）；无轨道/无默认必填字段时“新建片段”disabled 并提示；不产生空片段。
- 轨道重命名：双击轨道头进入内联输入；`Enter` 提交、`Esc` 取消；空名/重名拒绝；无 `window.prompt`。
- 轨道排序：拖动/上移下移后顺序变、片段时间不变；一次拖动一次撤销。
- 轨道头键盘：`Tab` 进列，上下换行；`Space`/`L`/`M` 切显隐/锁定/静音；焦点环可见。
- 删除空轨道成功；非空轨道拒绝并提示；删到 0 轨时显示“还没有轨道 + 添加轨道”，不强制保留一条空轨。
- 刀片工具：点击片段中部 4s 分割；点击端点 2px 内不分割；`Esc` 回选择工具。
- 100+ 属性的片段块高度 = 40px；0 属性同样 40px；不出现对象行/关键帧菱形/属性数量。
- 无限片段：画到显示末端、右端渐隐 + `∞`；没有固定结束手柄；不显示 `Infinity`。
- 循环片段：显示 `×N`；宽度按 `duration` 而不是 `duration*loop_count`（块只表示单次片段，循环次数是徽标）。
- 同一轨道重叠：两块都可见、重叠区有标记；不自动裁剪/错层。
- 选中 3 个：3 个 selection 边框 + 主选条；工具栏“已选 3 个”。
- 点击片段左 6px：显示左裁切手柄；hover 才显示；未选中不显示。
- 右键菜单：`Shift+F10` 可开；方向键选择；`Enter` 执行；`Esc` 关闭；无 `window.prompt`。
- 锁定轨道：菜单“删除/裁切/移动”disabled 并显示原因；选中仍可。
- 隐藏轨道：行消失，纵向总高变化；不保留空白 52px。
- 面板 160px：纵向滚动可用，轨道头固定；面板 560px：3 轨全见，无纵向滚动。
- 缩放 5–500：片段块宽度/标尺同步；轨道头宽度不变；不出现负宽度；片段最小宽 24px。
- `grep keyframes`：主轴视图 0 命中；`grep window.prompt`：0 命中。
- `TimelinePanel` 为唯一入口；`npm run build` 通过。

## 主轴显示约束

- 主轴只画轨道与片段；关键帧菱形、对象行、属性节点、曲线缩略图不进入主轴。
- 片段块高度只由轨道行高决定，属性数量不参与。
- 重叠只显示，不改片段时间、不写转场参数。
- 轨道操作按单轨执行。
- 字幕/叠加只显示片段块。
- 时间窗外的片段不挂 DOM；不引入第三方虚拟滚动库。
- 新建片段统一走 05-11 的 `timeline.addClip` 字段默认规则。
- 输入统一用 04 组件；不使用 `window.prompt/alert/confirm`。
- 轨道可见/锁定/静音属于 session；重命名/增删/排序写文档。
