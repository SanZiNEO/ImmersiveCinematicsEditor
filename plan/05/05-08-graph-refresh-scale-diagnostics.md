# 05-08 图刷新与规模降级

## 目标

脚本变了，脚本页要知道「该刷新了」，但不能每次保存都跳视图、不能每次编辑都全量重扫。脚本多的项目要能降级显示，统计与 warnings 要诚实，不假装完整。刷新只做全量快照，不做未定义的增量补丁。

## 失效广播

服务端：

```text
script.graph.invalidated {
  version: number,
  kind: "save" | "delete" | "new" | "refactor" | "requires",
  paths?: string[]
}
```

- `save`：`script.save` 成功后广播该 path。
- `delete`：`script.delete` 成功后广播。
- `new`：新建脚本落盘后广播。
- `refactor`：`script.refs.apply` 成功后广播全部受影响 path。
- `requires`：`script.requires.mutate` 成功后广播依赖方 path。
- `version` 在广播前自增；前端只比较版本，不持久化。
- 不广播 `layout`（图布局与脚本数据无关，不触发重扫）。

## 前端刷新策略

| 情况 | 行为 |
|---|---|
| 收到 `invalidated` 且版本更新 | 标「已过期」；1s debounce 后自动刷新（手势进行中则延后到手势结束） |
| 正在拖动/缩放/编辑前置 | 不打断；手势结束后再刷 |
| 图不可见（在编辑器页） | 只记版本，回到脚本页时再刷 |
| 断连 | 不发请求；标「已过期」；恢复连接后刷一次 |
| 手动刷新 | 立即发 `script.graph`，保留 view/选中/过滤 |
| 刷新中 | 顶部细进度条；不遮图、不重置布局 |

刷新后的状态恢复：

- `view`（scale/tx/ty）由 05-04 的 `graph-layout.json` 保持，不因刷新重置。
- 选中：按 `path` 恢复；节点已不存在则清选中（不猜新目标）。
- 过滤条件：保留。
- 折叠分组：保留。
- 手摆坐标：保留（布局文件独立于索引）。

## 规模降级

| 节点数 | 策略 |
|---|---|
| ≤ 200 | 全量渲染节点、边、标签 |
| 201–800 | 视口裁剪：只渲染视口内 + 50px 边距的节点/边；节点文字在 scale < 0.5 时只留名称 |
| > 800 | 后端截断到 800 节点 / 2000 边；顶部条显示「脚本过多，已截断」+ 真实计数；不提供「加载全部」（会卡死） |

- 边裁剪：两端都在可见集合才渲染；悬空桩同理。
- 分组带在裁剪时按可见节点范围绘制，不画空白带。
- 悬停/选中高亮在裁剪下仍工作：命中测试只看可见节点；上下游高亮会把视口外的相关节点**临时标记**（不渲染），状态区提示「N 个相关节点在视口外」。
- 截断只影响显示，不影响诊断计数与 `stats`（都是真实值）。

## 统计与诊断

- `stats`：`nodeCount / edgeCount / invalidCount / warningCount / warningsTruncated / scanMillis`。
- 顶部统计条：`N 脚本 · M 前置 · K 异常`；截断时加「已截断」。
- warnings 上限 200 条，按 `kind` 分组；`warningCount` 是截断前的真实总数。
- 诊断列表只读（05-05），不做批量修复。

## 性能预算（验收口径）

- 200 节点 / 500 边：首屏渲染 < 300ms（本机冷启动后第二次打开）。
- 拖动/缩放：≥ 50fps（不出现明显掉帧）；拖动中不做布局重算，只改 transform。
- 悬停卡片：250ms 出现；条件摘要已缓存时不发请求。
- 刷新 200 节点：请求到渲染完成 < 500ms。
- 一次性渲染 800 节点时必须走裁剪；不允许把 800 个 DOM 节点全部塞进画布。

## 断连与错误

- 断连：顶部条「未连接模组」；保留旧图并标「已过期」；刷新按钮给出原因；不自动重试（避免刷屏），连接恢复时自动刷一次。
- 刷新失败：保留旧图 + 标「已过期」+ 错误原因；不清空。
- 服务端返回坏数据（缺字段）：该节点标 `invalid`，其余照常渲染；不整图崩溃。
- `unchanged=true`：直接复用当前数据，不重排、不清选中。

## 验收标准

- 编辑器页保存脚本后回到脚本页：收到失效 → 1s 内自动刷新；`view`、选中、过滤、折叠都不变。
- 保存时不跳视图：刷新前后 `scale/tx/ty` 相同。
- 连续保存 5 次：只发 1 次刷新请求（1s debounce 合并）。
- 断连时保存：不刷新、不白屏；恢复连接后自动刷一次。
- `unchanged=true`：不重排、不清选中、不闪。
- 250 节点：走视口裁剪；滚动/平移时节点进出视口正常渲染。
- 900 节点：后端截断到 800；顶部条显示真实 900；诊断计数也按真实值。
- 800 节点下拖动空白：≥ 50fps；不出现整图重排。
- 刷新时选中节点被删除：清选中，不跳到别的节点；状态区说明。
- 坏节点混在正常节点里：只该节点标红，其余正常。
- `grep patch`：没有未定义的增量补丁消息（只有全量 `script.graph`）。
- `grep 自动重试`：断连时不无限重试。

## 边界

- 不做增量 patch、不做局部 diff 协议。
- 不做「后台常驻扫描」；只在失效/手动/恢复连接时扫。
- 不做图数据的持久化缓存（每次刷新重新取）；只持久化布局与视图。
- 不因为刷新而保存脚本、不改脚本内容、不进文档撤销栈。
