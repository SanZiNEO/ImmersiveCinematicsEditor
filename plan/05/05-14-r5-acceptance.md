# 05-14 05 闭环验收

## 目标

用一条真实链路验收 05：脚本页看图 → 悬停看触发器设定 → 图上改一条前置 → 进编辑器页改触发器 → 保存 → 回脚本页 → 图已更新。再补脚本页/编辑器页各自的矩阵、性能与失败路径。每项都要能指向操作、预期、实际证据；失败项保留，不改写成通过。

## 主闭环（必须逐条走完）

| # | 操作 | 预期 | 证据 |
|---|---|---|---|
| C1 | 启动应用 | 直接进脚本页；图可见；无启动器卡片 | 截图；`.script-graph-panel` 存在 |
| C2 | 悬停脚本 A | 显示 A 的全部触发器：type/重复性/条件摘要/前置列表；前置行有「换目标/删除」 | 截图；DOM 文本含 A 的触发器数量 |
| C3 | 在 A 的触发器上加 `script_started → B` | 写入成功；A 的 `requires` 多一条；图多一条 B→A 的边 | 脚本 diff；图边数 +1 |
| C4 | 撤销一次 | 前置条与边同时回退 | 脚本恢复；图边数 -1 |
| C5 | 双击 A 进编辑器页 | 打开 A；顶栏显示文档名/ID；预览/主轴/双宿主就位 | 截图；`document` 页布局四区 |
| C6 | 在编辑器页把该前置改成 `script_completed → C` | 走同一条命令；与图上看到的一致 | 脚本 diff；图边目标变 C |
| C7 | 保存（等服务端回执） | 脏标记清；文件落盘；图收到失效 | 文件 sha256 变化；状态区不再显示脏 |
| C8 | 回脚本页 | 图已刷新；A 的边指向 C；view/选中保持 | 截图；边端点正确 |
| C9 | 在图上删掉 C→A | 删除该条；`requires` 键若无剩余则消失；边消失 | 脚本 diff；图边数 -1 |
| C10 | 关掉游戏 WebUI 再操作 | 图标「已过期」；改前置被拒绝并说明原因；不白屏、不假装成功 | 状态条文本；无写盘 |
