# 路径集合与面板

> 状态：未实现
> 范围：脚本级 `paths[]` 的条目模型、端点约束、引用完整性、重复与重叠，以及独立面板
> 关联：02 字段目录、03 文档模型、04 布局树、05 面板槽位、07-06 几何表单、07-08 时间映射

## 一、摘要

`paths[]` 是脚本顶层数组，和 `clips[]` 并列：一条路径声明「某个片段的某段时间里，某几个轴按某种几何走」。它是模组既有的数据格式，编辑器要做的是给它一个完整的编辑闭环——新建、端点下拉、几何与时间、引用完整性、重复与重叠判定，以及一个独立的脚本级面板。当前状态：未实现。

## 二、为什么做

### 2.1 问题

- 路径条目有六个必填部分（`id`、目标片段、起止时间、axes、几何、可选 timing），手写 JSON 很容易漏字段或写出不被注册表接受的类型。
- 起止时间不是自由数字，必须命中目标片段位置节点的关键帧时间，而且两端必须相邻。作者记不住节点时间，也不该记。
- 删除或插入一个位置关键帧，可能让已有路径的端点不再成立。现在没有任何拦截，路径会静默失效。
- 同一片段同一起止点可以建多条路径，运行期按起点更晚者优先。这个覆盖关系如果不可见，作者会以为「两条路径都会生效」。
- 路径是脚本级概念，塞进片段的效果面板会让「这是谁的属性」变模糊。

### 2.2 目标

- 作者从节点时间下拉里选端点，不能手输；A 与 B 必须相邻。
- 删/插/移动位置节点、删片段、改片段 id 时，路径引用要么被同步维护，要么被拦住并给出处理选项。
- 重复端点对被本地拦下；部分重叠合法但要在界面上标出来。
- 路径面板独立存在，不属于 `clip.effects`，不依赖当前选中片段。

### 2.3 非目标

- 不把路径塞进 `timeline` 或 `clip`。
- 不在主时间轴上画路径行、端点或覆盖条。
- 不自动合并、不自动裁剪重叠路径。
- 不自动改路径端点：端点失效一律走「阻止 + 让作者决定」。

## 三、方案

面板默认停靠在 `document.drawer`，可拖到任意合法 slot；不要求选中片段，列表始终显示整份脚本的 `paths[]`。条目编辑器在面板内部，宽时列表与表单左右分栏，窄时上下堆叠。关闭面板不丢草稿，草稿按路径 id 存在面板会话里，重开恢复。

列表每行显示 id、目标片段、时间区间、axes、几何类型、timing 类型和问题数。单击选中该路径；双击把目标片段设为当前片段并把播放头移到起点；右键可重命名、复制、删除、定位目标片段、定位起点/终点。顶部有新建、按片段筛选、按 id 搜索、只看有问题。

新建流程是四步：选目标片段（下拉只列 CAMERA 片段，没有 `id` 的片段禁用并旁挂「设置片段 id」入口）、选起点 A（下拉来自 `position.x/y/z` 的关键帧时间并集，最后一项不能当 A）、终点 B 自动锁为 A 的下一个节点、确认默认值（`id=p_<n>`、axes 三轴、geometry 为 `line`、timing 省略）。一次提交生成一条路径并选中它。

端点约束是这个面板的核心。端点时间只来自 `position.x/y/z` 三个字段的关键帧时间并集——不看 `value`、不看 `motion_*`、不看路径自身。去重按精确时间，写盘时用 `1e-4` 容差匹配到节点原值。节点数少于 2 时新建禁用，已有路径显示「位置节点不足」。端点不接受自由输入，粘贴、手输、拖动都只能选节点。选中端点时通过共享选择定位到对应片段的效果面板行，返回路径面板仍保留当前路径。

引用完整性有五个入口，都走「扫描 → 阻止 → 提供处理选项」：删位置节点前扫描端点；在路径区间内插位置节点前扫描相邻性；移动端点或区间内节点前重算命中与相邻；删片段前扫描 `paths[].clip`；改片段 id 时在同一提交里同步 `paths[].clip`。前三者提供的选项是「先删除这些路径并继续 / 取消」，删除与帧操作写在同一个 `commit`，一次撤销全回退。片段改 id 是唯一自动同步的操作，因为语义唯一；新 id 与已有片段冲突时阻止改名。路径自己的 `id` 不随片段改名。

## 四、技术细节

### 4.1 核心模型

一条路径条目是 `{id, clip, from, to, axes, geometry, timing?}`。`id` 脚本内唯一，匹配 `^[A-Za-z][A-Za-z0-9_.-]{1,63}$`，默认 `p_<n>` 全局计数；`clip` 是目标片段 id，必须存在且非空；`from`/`to` 是片段局部秒且 `from < to`，两者必须命中目标片段的位置节点并互为相邻；`axes` 至少一项，顺序无关，缺省三轴，编辑器写显式数组；`geometry` 必填，`type` 来自 `curveTypes`，`line` 是 `linear` 的别名；`timing` 可省略，省略等于 `linear`，显式时只接受 `linear` 或 `keyframes`。

### 4.2 契约

`axes` 决定路径覆盖哪些轴：取消一项时，该轴继续用 `position` 的普通采样值，路径只覆盖勾选轴。保存写显式数组，不丢作者选择；解析顺序无关，显示按 `x,y,z` 归一化。

重复与重叠规则：同一片段、同一起止端点对只能有一条路径；部分重叠合法（`0→3` 与 `1→4` 可以共存）；完全包含但不相同也合法，运行期按起点更晚者优先；起点相同时来源列表靠前者胜，编辑器按 `paths[]` 顺序显示优先级。新建与保存时检测完全重复并本地拦下，部分重叠行标注「与 p_x 重叠，起点更晚者生效」。

诊断是本地即时显示、保存前再跑 `script.validate` 以服务端结果为准。错误行展开显示字段与修复入口，不压成一条 toast。问题分类覆盖：目标片段缺失或没有 id、`from >= to`、端点不在节点并集、端点不相邻、端点对重复、axes 为空、geometry 缺失或不被注册表接受、timing 非法。

### 4.3 数据形态

```json
{
  "paths": [
    {
      "id": "p_1",
      "clip": "shot_a",
      "from": 0.0,
      "to": 3.0,
      "axes": ["x", "z"],
      "geometry": { "type": "linear" },
      "timing": { "type": "linear" }
    }
  ]
}
```

写盘只有这一个数组，与 `clips[]` 平级；不写路径的 UI 状态、草稿、选中、诊断结果。

### 4.4 边界

- 面板不 import `clip.effects` 的组件，只共享选择、提交、字段目录和几何表单。
- 面板关闭再打开时恢复草稿与选中路径；未提交的改动不落盘。
- 路径定位使用共享选择里的 `pathId`，不用数组下标——删除中间条目不会让选择指向错行。
- 主时间轴不画路径覆盖条、不画端点；覆盖关系只在路径面板和预览里显示。
- 路径面板与项目图的诊断共享 `pathId`，可从图节点跳到路径行。

## 五、为什么不选别的

| 备选方案 | 做法 | 代价 | 为什么没选 |
|---|---|---|---|
| 端点允许自由输入时间 | 文本框写秒数 | 新建快 | 端点必须命中位置节点才生效；自由输入等于允许造无效数据 |
| 端点用 `1e-4` 容差匹配节点 | 容忍浮点误差 | 输入更宽松 | 写盘会写入容差匹配后的节点原值，与作者看到的数字不一致；精确匹配更可解释 |
| 自动改路径端点 | 插节点后把端点挪到最近节点 | 操作不断链 | 路径的几何和时间区间都会变，作者没同意就改了他的曲线 |
| 自动拆路径 | 区间内插节点时把一条拆两条 | 保持覆盖 | 拆出来的两条几何与 timing 怎么分没有正确答案，容易造出比原意更差的结果 |
| 把路径放进 `clip.effects` | 复用效果面板 | 少一个面板 | 路径是脚本级概念，一条路径跨片段边界时归属说不清 |
| 主时间轴画路径覆盖条 | 在编排视图里显示覆盖 | 覆盖关系直观 | 主时间轴的职责是轨道/片段/标记，加覆盖条会引入第二套时间语义 |

**本方案的缺点**：

- 端点只能选相邻节点，作者想跨多个节点建一条路径时必须先调整位置关键帧。
- 引用完整性一律「阻止 + 让作者决定」，连续调整时会频繁弹窗。
- 部分重叠合法但优先级规则要靠徽标和文案解释，不是一眼能看懂的设计。
- 路径面板是脚本级面板，与片段编辑分处两个区域，来回切换有成本。

验收要点：

- 新建路径产出完整条目：默认 `id`、三轴 axes、`line` 几何、时间区间正确。
- 目标片段没有 `id`、或位置节点少于两个时新建禁用；设置 id 后恢复可用。
- 端点下拉只有节点时间；手输、粘贴的数字进不到 `from/to`；A 选最后一个节点时 B 为空。
- 同片段同端点对的第二条被拦下；改成部分重叠可保存，两行都显示重叠徽标。
- 在路径区间内插位置帧、删端点帧、移动端点：默认阻止并列出受影响路径；选「删除路径并继续」后帧操作与路径删除同一次撤销。
- 删除目标片段被引用时阻止；删除路径后可删片段。
- 片段改 id 时 `paths[].clip` 同步、路径 id 不变。
- 只勾部分 axes 时预览只覆盖勾选轴、未覆盖轴走普通位置采样；axes 全不勾时添加禁用、已有条目拦下。
- 非法 geometry 本地拦下并展开字段错误；修好后可保存。
- 面板关闭重开恢复草稿与选中路径，未提交改动不落盘；默认停在 `document.drawer`，可拖到其他 slot，不在 `clip.effects` 下。
- 主时间轴没有路径行、端点或覆盖条。
