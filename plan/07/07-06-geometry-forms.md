# 路径几何表单

> 状态：未实现
> 范围：11 种 `curveTypes` 的参数表单、锚点语义、点位写法
> 关联：02 字段目录、07-05 路径集合、07-07 圆形生成器、07-10 路径预览

## 一、摘要

模组的 `curveTypes` 注册了 11 种几何，参数各不相同，锚定方式也分三类：端点参与形状、端点只做绑定、只有起点参与。路径几何表单要做的，是让作者选一个类型、填它自己的参数、看清这个类型「端点管不管用」，而不是去背每种类型的字段清单。所有类型定义、参数名、默认值、能力都从 `schema.curveTypes` 读，编辑器不维护第二份硬编码表。当前状态：未实现。

## 二、为什么做

### 2.1 问题

- 11 种类型的参数差异很大：`bezier` 要恰好两个内部控制点，`arc` 要圆心/半径/起止角/法向/参考轴，`fourier` 要一组余弦正弦系数和周期。纯 JSON 编辑等于让作者记 11 套字段名。
- 每种类型的控制点数量约束不同：`bezier` 恰好 2 个，`rational_bezier` 1~2 个，`bspline` 至少 2 个，`hermite.tangents` 恰好 2 个。填错数量时运行期才报错。
- 锚点语义不写在字段名里：`arc` 和 `ellipse` 的端点只做绑定，移动端点不改形状；`clothoid` 只有起点锚定；其他类型端点参与形状。作者按「端点决定形状」的直觉操作 `arc`，会得到与预期不符的结果。
- 点位有两种写法：绝对 `x/y/z` 和相对起点 `dx/dy/dz`。混写会让解析结果不可预期。
- `line` 是 `linear` 的别名，只允许 `type`。作者加上 `control_points` 会得到一条不被接受的几何。

### 2.2 目标

- 类型下拉列出全部注册类型加 `line` 别名，选中后只显示该类型的参数。
- 参数数量、范围、互斥关系在本地校验，错误吸附到具体字段。
- 锚点类别在表单和路径面板上都有徽标，`FREE` 类型能看到端点偏差。
- 切换类型时旧参数清空，且可一次撤销恢复。

### 2.3 非目标

- 不新增几何类型，不改 `PathCurveRegistry` 或 `PathEvaluator`。
- 不维护「类型 → 参数」的第二份硬编码表，一切从 schema 派生。
- 不把几何参数写进 `paths[]` 之外的任何位置。
- 不在几何表单里预览整条路径（那是 07-10 的职责），只提供「交给预览」的入口。

## 三、方案

类型下拉把 `line` 单独置顶作为别名项，其余按 schema 顺序。切换类型会清空旧类型参数、保留 `type` 与公共字段（`id`/`clip`/`from`/`to`/`axes`），切换前弹确认「将重置几何参数」，确认后一次撤销可恢复旧参数。类型为空或未知时本地拦下，不写本地默认值。

参数控件按形态分九类：数值（拒绝 `NaN` 与无穷）、整数（越界拒绝）、开关、枚举（选项来自 schema）、文本（结构/方块 id 走专用校验）、点、点列表、数值列表、向量。点位有两种写法二选一：绝对 `x/y/z` 相对表达式空间原点，或相对 `dx/dy/dz` 相对段起点；同一个点不能混写两组，切换时清空另一组。向量只支持绝对分量。

点列表显示行号、点、删除、上移下移；数量约束由类型决定，不足或超出时行内报错、不写盘；每个点独立选择绝对或相对，不强制整列一致。数值列表用于 `weights`、`knots`、`cos/sin`，显示「当前 N / 期望 M」，不静默截断。

锚点分三类，表单和路径面板都要显示徽标：

| 锚点 | 类型 | 端点行为 |
|---|---|---|
| `FREE` | `arc`、`ellipse`、周期 `fourier` | 端点只用于绑定，移动端点不改形状 |
| `START` | `clothoid` | 只固定起点，终点由参数决定 |
| `ENDPOINTS` | 其余 | 端点参与形状，移动端点会改形状 |

`FREE` 路径在端点位置与几何起终点不一致时显示偏差值，并提供「按几何重算端点」——只改位置帧，不改几何。`START` 路径的终点只用于绑定和时间，不显示「控制点」之类的误导文案。`ENDPOINTS` 路径要求端点存在，不提供「忽略端点」开关。

参数按 schema 顺序排列，点位与点列表占整行；错误吸附到字段，顶部只显示「N 个字段需要修复」。切换 `axes` 不影响几何参数——几何在三维空间定义，显示时按 axes 投影。「在路径中预览」把当前草稿交给预览模块，不提交文档。

## 四、技术细节

### 4.1 核心模型

11 种类型的参数语义摘要：

- `linear` 无参数。
- `bezier` 恰好 2 个内部控制点。
- `rational_bezier` 1~2 个内部控制点加同长度 `weights`。
- `arc` 圆心、半径、起止角、可选法向与参考轴；半径必须为正，起止角不相等且跨度不超过 360，法向与参考轴不能平行。内部按不超过 90° 一段展开为有理二次贝塞尔，是精确圆弧。
- `ellipse` 圆心、长短半轴、旋转、起止角、可选法向与参考轴；半轴为正，角度是参数角（不是弧长角），允许跨 0。
- `bspline` 内部控制点、`degree`、可选 `knots`；`degree` 在 1 到「总控制点数减 1」之间，默认 3，点不足时提示降 degree；`knots` 为空时由注册表生成，填写时长度必须匹配。
- `nurbs` 在 `bspline` 基础上加 `weights`，数量等于内部控制点数。
- `catmull_rom` 内部点、参数化方式（`uniform`/`chordal`/`centripetal`，默认 `centripetal`）、`tension` 0~1、端点处理 `mirror`/`clamp`。
- `hermite` 恰好 2 个切线，对应两端，可绝对或相对起点。
- `clothoid` 起止曲率（任意有限数，可同号、异号、为零）、长度为正、可选起始方向与法向；只有起点锚定。
- `fourier` `a0` 加一组余弦正弦系数与周期；`period > 0`，`cos`/`sin` 数量相等；周期时锚点 `FREE` 且端点忽略，非周期时锚点 `ENDPOINTS` 且 `a0` 必须为零向量。

`line` 是 `linear` 的解析别名：`{type:'line'}` 只允许 `type`，加任何其他参数都不被接受；新建路径默认用它，已有 `line` 不自动改写成 `linear`，作者主动切到 `linear` 时才写 `linear`。

### 4.2 契约

`geometry.type` 必填；不写 `type` 直接拦下，不依赖运行期默认。参数数量、范围、互斥关系在本地校验，错误精确到字段名。未知类型或未知参数不静默接受，展开显示类型名与参数名。

### 4.3 数据形态

```json
{
  "geometry": {
    "type": "arc",
    "center": { "dx": 0, "dy": 0, "dz": 0 },
    "radius": 4.0,
    "start_angle": 0.0,
    "end_angle": 180.0,
    "normal": { "x": 0, "y": 1, "z": 0 },
    "reference_axis": { "x": 1, "y": 0, "z": 0 }
  }
}
```

点对象只有两种合法写法：`{x,y,z}` 或 `{dx,dy,dz}`，不混写。`arc.center` 默认写相对起点，避免依赖未知的表达式空间原点。

### 4.4 边界

- 表单不直接写文档；父级条目编辑器统一提交。
- 切换类型不清 `timing`，几何与时间映射相互独立。
- `clothoid` 的终点时间不参与形状，只用于绑定。
- 未知类型时不画曲线（预览侧），表单侧显示错误卡片与字段路径。
- 保存重开后 11 种参数原样保留，`line` 仍是 `line`，不自动补 `control_points`。

## 五、为什么不选别的

| 备选方案 | 做法 | 代价 | 为什么没选 |
|---|---|---|---|
| 一个通用 JSON 编辑器 | 直接编辑 geometry 对象 | 实现成本最低 | 11 套参数要作者自己记；数量与范围错误只在运行期暴露 |
| 每种类型写一个专用表单组件 | 11 个独立组件 | 控件完全贴合 | 与 schema 重复维护 11 份字段清单，注册表一变就漂移 |
| 用 `1e-4` 容差放宽数量校验 | 少报错 | 输入宽松 | 数量不对就是不对，容差只会把错误推到运行期 |
| 切换类型时保留旧参数 | 不丢数据 | 可回退 | 旧参数在新类型下是未知字段，会写进 `paths[]` 让注册表拒绝 |
| 把 `line` 自动改写成 `linear` | 统一内部表示 | 类型表干净 | 写盘形态会变，作者看到的与保存的不一致；`line` 是合法别名 |
| 用绝对坐标统一所有点位 | 少一种写法 | 概念简单 | 相对起点是模组既有能力，去掉会改变曲线的可移植性 |

**本方案的缺点**：

- 11 种类型的参数语义差异很大，表单即使按 schema 派生，作者仍需逐个理解。
- `arc`/`ellipse` 的角度是参数角而非弧长角，这个区别需要文案持续解释。
- 切换类型清空参数虽然可撤销，但连续试几种类型时操作成本不低。
- 锚点徽标是间接表达，作者要真正理解 `FREE` 的含义还是得读文档。

验收要点：

- 类型下拉列出 11 种加 `line` 别名；`line` 只写 `type`，加其他参数被拦下。
- `bezier` 控制点恰好 2 个；`rational_bezier` 控制点 1~2 且权重同长；`hermite` 切线恰好 2 个。

- `FREE` 锚点路径移动端点后形状不变、偏差更新，「按几何重算端点」只改位置帧。
