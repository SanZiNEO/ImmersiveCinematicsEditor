# 编辑器完整美术与交互风格建议

> 状态：未实现（视觉规范，不是UI实现或实测报告）。适用于WebUI和游戏内Forge+AUI；主模组Forge/Fabric均是WebUI正常目标，仅游戏内Fabric+AUI适配暂缓。

## 一、摘要

采用“安静、精确的制作工作台”：借剪辑软件的时间轴、效果控件和资源组织，让作者专注生成固定格式脚本。默认深色，同时完整提供浅色与跟随系统主题。强调真实游戏预览、清晰的时间/对象关系、可调整面板和可靠状态，不依赖装饰动画、玻璃效果或假画面营造专业感。

## 二、为什么做

现有样式分散在App、Timeline、ScriptGraph和DynamicForm；固定列宽、旧左栏、单主题和微小字号不适合长时间制作。目标是所有功能在两主题下可读、状态不靠颜色单独表达、布局可随镜头/字幕/行为任务调整、中文英文均可使用。

**明确必做**：深/浅/系统主题（05.20）、面板移动/缩放/停靠与布局恢复（05.21–23）、中文英文与IME、字幕批量界面（12.20–23）。这些不是额外建议。**非目标**：品牌插画、启动页动画、通用视频剪辑器、视频导出、假游戏场景或随机波形。

**源码参考**：[工作台/偏好/宿主](../references/03-workspace-preferences-host.md)、[属性关键帧](../references/02-olive-property-keyframes.md)、[项目关系入口](../references/05-project-graph-navigation.md)给出具体交互来源和不可照搬项。用于解释面板焦点、双主题、字段状态与图选择，不授权复制参考软件的图标/CSS资产，不以参考软件的技术限制预先削减WebUI或宣称AUI已实证。

## 三、方案

### 3.1 视觉方向

- 默认构图借完整截图的职责：效果控件在预览旁、真实游戏画面居中、快捷属性独立在右、主时间轴在下，资源/模板按需抽屉。它不是旧五区改标签；clip.effects与selection.properties是两个可同时可见的停靠面板。所有面板仍按05布局树换位/缩放/分组/恢复，不恢复常驻脚本/源码列。
- 项目入口是按文件夹分组的关系图。脚本卡片突出名称、身份、触发关系与校验；悬停补充摘要，点击打开；文件夹/依赖/布局维护彼此区分，不在图上编辑具体轨道内容。
- 工作区视觉层级：游戏画面第一、当前选择第二、错误与确认第三、辅助元信息第四。主题不改变游戏画面像素或脚本调色。
- 效果控件是片段级完整工作区：一对象/功能组一块、组内叶子成行，左参数右独立节点，多个组同时展开并共用局部标尺；选择属性只高亮，不隐藏其他已展开组。快捷属性只做当前项常用参数和定位，不另画节点轴。实际字段组按模组schema定制，详见[工作区合同](effect-controls-workspace.md)。
- 字幕工作区让真实预览、cue表格与时间轴同时可用；长中文/换行、批次来源和手工修改冲突看得清，不把字幕编辑缩成单个text输入框。

### 3.2 风格边界

低饱和中性底、蓝色交互强调、少量轨道分类色。面板边界用1px分隔，不靠大阴影。没有信息价值的渐变、持续闪烁、装饰菱形和全屏毛玻璃不用；这是工具审美选择，不是未经实证的AUI能力结论。

## 四、技术细节

### 4.1 双主题token建议

值为设计候选，实施时按真实字体/抗锯齿与背景复验对比度。两主题共用token名称；不能在组件里散写第二套颜色。ThemeService负责dark/light/system解析，PreferencesStore持久化；切换不重建文档、预览流或连接。

| 语义token | 深色 | 浅色 | 用途 |
|---|---|---|---|
| bg-app | #151519 | #ececf1 | 应用底与标题区 |
| bg-panel | #1e1e24 | #f8f8fb | 工作面板与时间轴 |
| bg-raised | #26262e | #ffffff | 输入框/卡片 |
| bg-hover | #30303a | #e9edf5 | 悬停 |
| bg-selected | #2f3b55 | #d9e3f7 | 选中填充 |
| text | #e3e3eb | #1f1f26 | 正文 |
| text-secondary | #b0b0bd | #5c5c68 | 元信息/单位 |
| text-muted | #8a8a96 | #6e6e7a | 非关键辅助说明，仍需可读 |
| border | #3b3b47 | #d6d6df | 结构分隔 |
| border-strong | #686879 | #8a8a99 | 关键输入/浮层边界 |
| accent | #8eb4ff | #24509a | 链接/交互文本 |
| focus | #a6c4ff | #2f5fb3 | 焦点环 |
| success | #61d5a2 | #147a56 | 成功状态 |
| warning | #f0c365 | #8a5a00 | 警告/待确认 |
| error | #f26363 | #c62828 | 错误 |
| error-bg | #38252a | #fbe9e9 | 字段错误背景 |
| selection-outline | #ffffff | #1f1f26 | 选中片段/节点外描边 |

系统主题变化只影响system模式，不覆盖显式深/浅选择；启动先恢复偏好再首屏显示，避免闪白。坏主题配置回默认并提示，不重置脚本。主题资源使用统一token源；AUI无法直接消费CSS变量时在构建/适配时生成字面值，不手工维护第二份语义表。

### 4.2 轨道和关系图分类色

分类色不随主题反色；只用于色条、类型图标、小面积片段。正文不直接套分类色，片段墨色按真实对比计算选黑/白。新注册轨道使用稳定映射并显示原类型ID。

| 类型 | 候选色 | 必须同时显示 |
|---|---|---|
| CAMERA | #3b6fc4 | 相机图标 + 类型名 |
| LETTERBOX | #4a7d7d | 遮幅图标 + 类型名 |
| AUDIO | #2f9e6e | 声音图标 + 类型名 |
| EVENT | #c78f3a | 事件图标 + 类型名 |
| MOD_EVENT | #7d4aa8 | 模组事件图标 + 不支持/未知能力状态 |
| OVERLAY | #c45f8a | 图层图标 + 子类型 |
| ADJUST | #7b6b9e | 调色图标 + 作用范围 |

图边不按故事“好坏”配色：正常边用中性色，选中链条用accent；悬空/冲突加错误图标与文本，环/跨文件夹用线型或弯曲区分。依赖类型、来源触发器和目标身份始终可查看。维护确认不能只用一条高亮线代替影响范围。

### 4.3 排版、中文与双语

| 层级 | 建议字号 | 行高 | 用途 |
|---|---|---|---|
| 对话框标题 | 18px | 1.35 | 重要操作/冲突 |
| 面板标题 | 14–15px | 1.4 | 区域与分组 |
| 正文/字段 | 13px | 1.5 | 标签、表格、输入 |
| 紧凑列表 | 12px | 1.4 | 轨道/cue/节点列表 |
| 辅助元信息 | 11–12px | 1.4 | 非关键单位/ID；核心操作不低于12px |

WebUI中文字体优先系统微软雅黑/思源黑体可用回退，英文Segoe UI/system-ui；时间/坐标用Cascadia Mono/Consolas/系统等宽回退。AUI按实际可加载字体选择，不假设和Chromium字形完全一致。

字段标签默认104px，可随面板宽调整；窄于320px时改上标签下控件。长中文/英文最多两行并提供完整可聚焦提示；关键区别词前置，单位不被截掉。按钮标题以短动词为主，不硬性把所有业务标签压成固定字数。翻译缺失展示原字段路径并标明，不显示空白。

所有菜单/设置/错误/帮助提供zh_cn/en_us。数字精度是显示设置，不修改底层脚本秒数；字幕保留毫秒，非整帧时间不量化。IME组合期间不提交字段、不触发删除/播放快捷键；输入框中的复制/撤销遵循文本编辑范围。

### 4.4 密度、边界和可调整布局

默认舒适档：字段行28px、轨道行48px、属性行24px、面板内边距12px；紧凑档：24/40/22/8px。可选更密设置不得让中文和命中目标不可用。圆角控件4px、卡片6px、浮层8px，保持克制。

图标视觉16px，常用按钮命中区至少24×24px、游戏内建议28–32px；分隔线视觉4px、命中8px，键盘可调。菱形视觉8–10px但命中区16–24px，交叠时明确候选而非随意选中。边缘裁切与面板移动手势区不同，不能一拖同时移动片段和面板。

布局只归WorkspaceLayoutService：面板停靠/标签重排/拆分/隐藏恢复、预设、视口校正都使用同一树；损坏只恢复布局，不删文档。标题栏是面板移动把手，参数区域不是。所有面板有“重新打开”和“恢复默认”，不把面板丢到窗口外。保存“镜头/字幕/行为”等工作流布局，重启恢复。

### 4.5 图标、组件状态与焦点

统一16px视框、约1.5px线性描边；复用现有assets/icons，缺图标才补同风格资产。图标语义固定：菱形=关键帧、磁铁=吸附、锁=轨道锁定、眼=可见性、三角旗=标记。不要用emoji或未验证图标字体替代；图标有可读名称和双主题可辨资源。

| 状态 | 视觉与行为 |
|---|---|
| 默认/悬停/按下 | 背景层级轻变；悬停不是唯一可发现方式 |
| 选中 | 描边+选中底+对象名，不只改颜色 |
| 焦点 | 2px焦点环，与选中态可同时区分，永不被动画延迟 |
| 禁用/只读 | 文字原因、锁/只读标签；保留原值，不假装未设置 |
| 加载/未知 | 显示真实加载/未知，不用0或默认值冒充返回结果 |
| 错误/警告 | 图标+文字+定位入口；失败保留草稿，不仅toast |
| 锁定/隐藏 | 锁/眼状态与纹理/文字区分，不把整行降到看不清 |
| 未保存/已保存 | 文档脏标记与实际保存回执一致 |
| 播放/暂停/断连 | 明确文字；命令发送和游戏实际状态分开 |

禁止outline:none而无替代。弹窗有初始焦点、Tab范围、Esc取消和焦点归还；删除/重导入冲突显示影响条目，默认不是破坏性确认。主题切换后焦点仍清楚。大列表/时间轴提供键盘等价操作和可读名称，视觉辅助不替代准确数据。

### 4.6 主时间轴、效果控件与快捷属性的图形语言

- 主时间轴标尺使用全局秒，轨道头固定可见，片段显示类型/名称/起止/循环；无限窗口用斜纹与∞。不画属性节点、关键帧汇总点、对象子行或属性曲线，也没有展开对象的片段箭头。
- 效果控件顶部只有一条片段局部秒标尺，参数列和节点列按同一行布局对齐；组头可折叠，叶子以紧凑行呈现，不一叶子一张大卡片。曲线/段详情展开后左右同步增高，虚拟滚动也用同一纵向窗口。
- 当前值、时钟状态与菱形节点状态可区分：时钟是该叶子动画启停，菱形是当前时刻节点，前后箭头只导航。VALUE无动画控件；STEP用方块/阶跃，连续属性按真实interp标识，不给所有节点提供任意Bezier类型。
- 效果控件轴外节点用虚线/斜纹及“不生效”文本，可适配全部/定位/编辑；有效片段窗口背景与轴外清楚区分。显示范围扩展不拉宽主时间轴片段，同属性重复时间拒绝不覆盖。
- 效果控件要有参数列与节点区的真实横向空间，不套用旧快捷检查器的280–560px宽度。列宽可调，窄窗用停靠标签/折叠或受控滚动保证可达，不能降成单属性独占页或移回主时间轴。
- 快捷属性使用同一值控件/单位/错误样式，标题明确当前片段/组/叶子/节点；与效果控件同时可见、同值回显，不能另建动画标尺或第二份选择。草稿焦点不被回显覆盖。
- 两个时间视图的播放头按真实映射同步，局部/全局标签明确；滚动/缩放状态独立。拖动即时反馈，不用平滑动画掩盖真实seek回执。
- 转场显示交界窗口与通道摘要，不画视频转场素材；脚本macro循环与UI A–B范围用不同线型/文字，marker不写非法timeline.markers。
- 无真实波形/缩略图数据时不伪造素材装饰。曲线/路径标明参数或几何示意，世界实体/光影/HUD仍看游戏真实画面。

### 4.7 字幕、资源、模板与诊断的视觉

字幕表格起止时间对齐、文本支持多行，来源批次与手工改动有清晰徽标；批量条只在有选区时出现，明确作用条数。重导入显示新增/删除/变更/冲突，用户可取消。样式表只列schema实际支持项，不拿CSS字体/描边冒充游戏渲染。

资源表区分文件存在、格式支持、解码状态未知/失败，不能用“可选择”冒充“可播放”。模板按层/来源分组，参数单位、生成差异、引用冲突在提交前可见；纯数据模板与内置同样可用。诊断按严重度/字段定位，允许复制问题，不恢复旧常驻整脚本源码栏。

### 4.8 动效和可访问性

悬停120ms、折叠180ms、抽屉/对话框不超过240ms；拖动/播放头/数值输入0ms。减少动效设置关闭非必要过渡，不能用脉冲当状态真值。正文对比目标≥4.5:1，关键非文本边界/焦点目标≥3:1；实施时计算候选颜色并做真实主题视觉核查，不在本计划假报已符合某认证。

所有主要功能可键盘完成；支持放大/字体密度调整与窄面板换行，2倍缩放检查核心操作可达。错误有文本与位置；关键保存/校验/连接状态可读可播报。输入法组合、快捷键冲突、焦点陷阱在05当轮解决，13只复核宿主差异，不把未完功能延期。

### 4.9 AUI能力与真实预览边界

先完成WebUI所有视觉/交互；AUI的CSS/DOM/输入/纹理兼容性在13验收WebUI后由14锁版本实证。本页是迁移同语义参考，未实证不写不支持，也不为AUI提前限制WebUI功能。

03先提供WebUI真实RGBA/H264，14后置迁移进程内GPU；保持游戏像素、比例和真实状态，不捕获编辑器UI。AUI未实现不是WebUI视觉验收前置。

## 五、为什么不选别的

| 备选 | 代价 | 选择 |
|---|---|---|
| 单一深色、固定五区 | 不满足已明确的主题/可移动组件需求 | 双主题+系统跟随，可恢复停靠布局 |
| 复制完整剪辑软件 | 素材/渲染模型不匹配固定脚本 | 借交互形式，不引入成片导出 |
| 炫光/毛玻璃/持续动效 | 分散注意、兼容性难验证 | 克制边框、明确状态 |
| 用假画面/波形填空 | 误导作者判断脚本效果 | 真实帧或明确无画面 |
| 两宿主各做一套样式语义 | 同状态含义与操作漂移 | 统一token/状态/交互合同，宿主适配 |

代价：两主题、自由布局与中文长内容需要更多视觉场景；AUI能力需要实证。不能通过删浅色、固定布局或关闭字幕批量来降低成本。

## 六、实现结果

未实现。本页是完整建议与实施约束；颜色/字号是设计候选，不是已测结果。实施时分别在WebUI深/浅、不同窗口/DPI与游戏内Forge实际界面验证主题、停靠、异步节点、字幕表格、IME/键盘、错误与无帧状态，并记录与规范的偏离。关联任务见05.20–23、06、12.20–23、13及14。
