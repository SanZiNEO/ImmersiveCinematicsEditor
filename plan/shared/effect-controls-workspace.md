# 片段效果控件工作区：主时间轴、效果控件与快捷属性

> 状态：未实现（本页为用户截图所明确的新交互合同，不是实现报告）。
> 合同：C17；依附C03/C04/C08/C13的界面职责，不改变0.3.6标准脚本、属性身份、采样或插值语义。

## 一、摘要

主时间轴只编排轨道与片段；选中一个片段后，在统一效果控件中集中展示它适用的对象/处理分组、静态参数与独立属性关键帧；另一个快捷属性面板展示当前选中项的常用参数。效果控件的左侧属性和右侧节点区域共用一条片段局部时间标尺及播放头，多个属性可以同时展开对照，但时间序列独立。

这不是旧界面增加一个标签：废止主时间轴展开对象/属性行、在片段上绘制或编辑关键帧，以及选中属性后切换到只能看该属性的孤立面板。底层按类拆任务，不等于每个类或属性都成为一个独立大面板。

## 二、为什么做

### 2.1 问题

主时间轴若随片段展开数十至上百条属性行，就无法承担整体片段编排；单属性切页又不能上下对照不同参数的变化。沿用旧整帧模型的入口、布局和快捷键，即使换成objects保存，也不等于新的创作方式。

### 2.2 目标

- 对象数量增加不扩大主时间轴轨道高度；主时间轴不出现属性节点、曲线、对象展开或关键帧汇总点。
- 同一片段的多个对象/功能组可在同一效果控件内展开；选择一个属性只改变高亮与编辑目标，不隐藏其余已展开属性。
- 节点、静态参数和快捷属性共用同一标准文档、Selection与命令，不出现两份值或两套节点历史。
- 轴外帧仍可定位、编辑、撤销和保存；不会因为离开主时间轴而丢掉能力。

### 2.3 非目标

不仿制PR素材播放、任意效果链或插件系统，不创建新运行时对象层，不为主时间轴保留可选关键帧模式，不改真实游戏预览，不扩大到本轮代码实现。

用户完整截图进一步明确：左上效果控件、中央预览、右侧独立属性、下方主时间轴是职责参照；此前图④是属性面板，不是另一套效果控件。我们按模组能力定制内容而非照抄PR界面。截图左下的素材区在本项目仅对应按需资源/模板/字幕工具入口，绝不恢复旧常驻脚本/源码栏；游戏真实画面仍占主要预览区，不能用离线素材播放器替代。

## 三、方案

### 3.1 三个不同职责

| 区域 | 负责 | 明确不负责 |
|---|---|---|
| 主时间轴 | 轨道/片段选择、位置、起止、时长、分割、循环及既有片段命令；全局标尺/播放头/工作区标记 | 属性行、动画节点、节点增删移动、属性曲线、节点汇总标记 |
| 片段效果控件 | 当前片段的对象/功能组目录；左侧参数与行内值编辑；右侧对齐的独立属性节点；段缓动和适用的事件入口 | 项目脚本列表、全脚本meta/触发器/规则树、任意新增效果实例、游戏渲染 |
| 快捷属性 | 当前选中片段/对象组/叶子/节点的常用参数、上下文摘要与定位到效果控件；复用同一字段控件 | 第二套节点时间轴、强迫切页才能完整编辑、缓存另一份参数或选择 |

“对象/处理组”是作者可理解的界面组织：位置、朝向、裁切、透明度、声音等按实际schema.section与能力组合。标准objects仍以完整叶子路径为编辑单元；组名不写进脚本，不为它制造对象实例ID、统一时间或自由效果堆栈。添加/删除/开关/排序只有真实schema/parser支持才开放，不因截图有按钮就新增运行时语义。

### 3.2 同一片段，多属性可见

效果控件顶部显示片段身份、轨道类型、局部时长与局部标尺；左侧按功能分组，组内每个叶子一行，列包括名称、当前值/未设置、模式/可用性、秒表、前后节点和当前节点状态；右侧同一行显示该属性自己的节点。组和属性可以折叠，组不生成一个合并节点带。

例如position.x在0/2/5秒有节点、position.y在1/3秒有节点、position.z是常量：展开位置组时同时看到三行；右侧只有前两行有各自节点，z行仅显示常量状态。改x不会切走y，也不会给y/z补帧。

VALUE只显示值控件；ANIMATED按该属性的value/keyframes状态呈现秒表和菱形，二者是不同语义；EVENT使用06事件记录组件，不伪装成连续曲线。mode/interp来自schema且只读，不从截图引入Linear/Bezier/Hold帧类型。曲线/段区域只有支持的属性才展开，作者缓动和07真实路径编辑继续遵守原格式与显式烘焙边界。

### 3.3 布局不受旧右栏限制

效果控件与快捷属性是两个独立可停靠面板，可同时可见，不是同一个tab内的二选一。注册标识统一为clip.effects与selection.properties，不能把两者压回一个旧object/keyframe标签。默认可将效果控件置于预览旁、快捷属性置于右侧、主时间轴置于下方；用户仍可按05布局树换位/分组/缩放/恢复。

效果控件要有足够横向空间容纳参数列和节点列，不继承旧快捷检查器280–560px窄栏限制。小窗口以停靠标签/折叠、列宽调整和必要的受控滚动保证可达，不降级为单属性切页，也不把节点送回主时间轴。截图用于职责参照，不当成精确像素规格。

### 3.4 模组定制的对象组与快捷属性

下表是界面归类，不是新字段清单。每个组内的实际叶子、mode/interp、依赖和可写范围必须来自当前schema及对应轨道消费者；第三方字段进入原section或明确的扩展组，不被硬编码七轨截断。

| 当前片段类型 | 效果控件内的处理组 | 快捷属性的当前项摘要 | 专门工具边界 |
|---|---|---|---|
| CAMERA | 位置/参考系/点源、朝向、光学、裁切/画面合成等实际对象 | 当前片段播放参数或所选位置/朝向叶子的当前值与节点目标 | 07路径/数学、08转场/lane、12取景通过同一上下文进入，不另造动画编辑器 |
| OVERLAY | 按image/subtitle/video/fade适用性展示内容、几何、透明度等 | 当前图层类型、资源/文本及选中参数 | 09负责真实字段与合成；12字幕批量是外部整合工作流，不变成模组字幕工程 |
| LETTERBOX | 遮幅的形状、颜色及实际可动画参数 | 当前遮幅对象的常用参数 | 使用09元能力，不复制网页遮幅假预览 |
| AUDIO | 音源、播放参数、空间/监听相关对象 | 当前音源/监听目标与选中参数 | 使用10注册资源和真实声音能力，不凭PR音频效果添加模组没有的处理 |
| ADJUST | 实际调色参数与LUT相关对象 | 当前调色项或LUT引用 | 10负责真实字段/资源，主题不改变调色结果 |
| EVENT/MOD_EVENT | 事件/记录分组，按记录结构编辑而非连续曲线 | 当前事件身份、载荷摘要、适用的时间/字段 | 06基础记录与11专用内容/权限分工保持不变 |

脚本meta、screen_layers、触发器、规则/绑定和脚本级paths仍有原文档/行为/路径入口，不因当前片段被选中就把全脚本内容搬入效果控件。片段起止/长度等快捷属性与主时间轴复用同一片段命令，不形成第二份时长。

## 四、技术细节

### 4.1 单一状态与数据所有者

- 标准文档/clipKey/Selection/节点批选和old→new映射归02；所有值/节点写入都走原C04命令。
- 有且仅有一个有效clipKey时，效果控件派生该片段全部适用行；在同一片段内换objectPath/keyframeTime不重建片段上下文或清掉其他展开组。
- 多片段选择显示明确多选状态，不默认取第一个、不合并成虚拟片段。无片段/失效片段显示空态/失效原因；明确的结构实体导航可以通过既有clipKey打开独立片段，不把它塞进主时间轴。
- pin若保留，只是显式的同文档UI上下文；标题明确固定对象，写入必须针对实际展示的有效clipKey。删除、关闭文档、失效引用后不继续写旧对象；不以pin制造第二份Selection。
- 效果控件UI状态按文档会话+clipKey保存组折叠、过滤、列宽、局部视口；主时间轴全局视口另存。快捷属性只消费共享选择和命令，不存一份可编辑副本。

### 4.2 两种时间视图，共用真实播放时间

主时间轴使用全局秒；效果控件所有属性行共享一个局部秒viewport。时间线片段的局部时间=全局时间-start_time；点击效果控件局部t时，经同一映射请求全局seek。片段循环不通过前端取模假造执行时间；独立片段的编辑局部时钟及实际播放时间来源按03宿主合同处理，不制造start_time。

局部视口的缩放、平移、显示范围、参考线、行命中与纵向虚拟化由06效果控件负责；不能依赖05主时间轴对象行框架。共用纯数值换算函数可以，不能共用一份可变scale/scroll状态。左参数列和右节点列必须使用同一行布局与纵向窗口，展开/滚动/字体缩放不串行。

有限片段0≤t≤duration为轴内；合法t>duration的节点留在文档并在效果控件标轴外，提供适配全部节点/跳到轴外节点的入口。局部显示范围可扩展，但不扩大主时间轴片段宽度或脚本时长。无限片段的合法t≥0不因显示窗口有限变轴外，不写Infinity。

### 4.3 写入与快捷属性

单属性行命令仍精确定位clipKey+完整objectPath+节点time，不按数组下标，不因同时间跨属性重合就联选/合并。多选节点按原06允许操作和逐属性冲突规则执行；统一展示不新增跨属性批量改值。秒表控制动画形态，菱形控制当前时刻节点，前后按钮只导航；禁止把“当前有节点”当作秒表点击失效的理由。

快捷属性复用06-PropertyValueForm及同一命令分派：编辑value、指定节点或显式添加节点必须有明确目标；已动画属性不允许静默只改不参与采样的value并声称动画已变化，不隐式补别的属性。提交失败/取消保留原文档，草稿与回显不覆盖用户正在输入的值。

### 4.4 类任务与干净切换

| 责任任务 | 新职责 |
|---|---|
| 05-03/04/05/06 | 主时间轴几何、片段交互、全局播放头，不含属性节点 |
| 05-07 InspectorHost | 分别承载clip.effects和selection.properties，冻结上下文/错误/焦点合同；不实现06业务 |
| 06-ObjectPropertyList | 效果控件中的对象/功能组目录和对齐参数列，允许委托值控件行内提交 |
| 06-ClipEffectControlsPanel | 统一片段级效果控件容器、上下文、共享局部时标、行/曲线/事件组合 |
| 06-EffectControlsRows | 效果控件的左右行对齐、节点几何/命中、局部视口/虚拟化与轴外显示 |
| 06-PropertyValueForm | 效果控件与快捷属性共用字段组件/提交和动画目标分派 |
| 06-KeyframeEditOps | 原单属性/批选命令、原子历史和冲突规则，移除主时间轴节点入口 |
| 06-ObjectDiagnostics | 定位到效果控件中的片段、组、属性、节点，不展开主时间轴对象行 |

九个06类/模块任务按上表干净切换：统一片段容器与效果控件行替代旧单属性独占页/主轴对象行任务；旧任务文件与引用迁走，不留双轨。全部格式、值类型、事件、缓动、引用和错误要求保留。05只提供宿主/工作台，06完整负责自己的局部视口/节点能力，不反派给05或延期给14。

### 4.5 人工验收的硬场景

1. 主时间轴选择一个100+属性片段：轨道高度不变，片段无节点/汇总菱形，也没有对象展开菜单。
2. 效果控件同时展开位置和朝向，x与yaw不同时间各有节点、y是常量；切换选中行时其他已展开行仍可见，左右行始终对齐。
3. 拖x的一帧只改x；同一行重复时间整次拒绝；撤销恢复节点与共享选择，yaw/y不变。
4. 将有限片段5秒之外的7秒节点定位、编辑并拖回，显示与采样状态相符；主时间轴片段仍5秒。缩短片段不删节点。
5. 快捷属性修改同一目标，效果控件和标准文档同步；取消/错误/删除片段后不串写另一个对象。
6. 改全局播放头、改局部播放头、缩放两个视口，时间映射正确，两个缩放不互相重置；游戏画面来自真实通路而非曲线模拟。
7. 两面板分别停靠、换位、缩放、隐藏恢复及重启恢复；小窗口仍可操作，IME/文本、节点拖动、主时间轴片段拖动、停靠拖动不互抢。
8. 无选择、多片段、独立片段、未知schema、缺资源、断连、取消、保存重开都给出正确状态；不以假值或假成功通过。

不新增自动化测试/单测/CI/测试脚本；本次不运行游戏或实现代码，以上是未来人工操作清单，不能预填通过。

## 五、为什么不选别的

| 未采用方案 | 原因 |
|---|---|
| 主时间轴按片段展开对象行 | 混淆编排和参数动画，用户截图已明确排除 |
| 单独选一个属性才显示它的完整面板 | 其他处理消失，无法上下对照，不是统一效果控件 |
| 每个叶子一张独立大卡片/独立标尺 | 空间浪费且时间难对照；一功能组一块、叶子成行、共享局部标尺 |
| 合并同时间不同属性节点 | 破坏异步模型；可见对齐不等于数据同步 |
| 全部仍塞进旧右侧窄栏 | 受旧布局限制；效果控件有独立停靠身份与横向工作空间 |
| 任意添加/排序效果链 | 界面参照不能创造模组不认识的运行时能力 |

代价是06必须独立完成局部视口、左右行同步、虚拟化与上下文控制，并让两处值控件通过同一命令联动；不是把旧组件搬到新位置就完成。
