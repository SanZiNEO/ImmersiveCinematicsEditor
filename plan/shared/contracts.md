# 共享实现合同

## 一、摘要

本页冻结跨轮不变量，不把拟新增接口说成现有实现。任务中新类名是职责建议；同职责不得在两分支各造一套。执行任务前将其名称映射到本页合同 ID，若已有相同职责先复用或干净迁移。

## 二、为什么做

模型、预览和项目关系如果各自定义身份、时间或保存方式，后续面板即使都能打开也不能组合使用。目标是所有编辑操作通过同一文档命令、所有播放/校验通过同一宿主语义、所有画面都来自游戏。

## 四、技术细节

### C01：schema 不等于宽松 JSON Schema 验证器

`J:script/schema/SchemaExporter.java — exportAll（42–141）` 导出 meta、tracks.playControl/objects、triggers、models、curveTypes、script_structure。消费者必须保留对象的 mode/type/interp/default/requires 以及结构元数据，不能沿用旧 clips/keyframes shape。缺失字段意味着能力未知/不可用，不意味着可以以旧默认写入。

`author` 的 schema/parser 冲突按基线文档处理：写入字符串且不删。其余冲突逐项记录，禁止把全 schema 一律改为 required 或关闭校验。

### C02–C04：文档和事务

1. 运行时脚本、schema、编辑器会话、播放回执、预览帧、资源索引是不同状态，不把后一份当脚本。
2. 文档允许脚本级独立 clips（没有 start_time，有 track），不能强迫放入 timeline 后保存。`ScriptParser.parseStandaloneClips（437–489）` 是实际边界。
3. clip.id 与 trigger/rule/path/binding 身份不同；文档内唯一性和引用规则依真实 parser/validator。UI 临时节点 ID 不写入脚本。
4. 有限时长按有效片段和循环语义派生；无限不能写成 JSON Infinity、null 或随手固定长度。显示范围可以有限窗口，不改变内容时长。
5. 任何保存都从标准文档快照生成，先真实 validate，再由受控服务保存；响应成功后才清脏。并发改变、失败或断连不清脏。外部变更不自动覆盖本地。
6. 自动精简默认值不能改变缺省/空/null/显式默认的语义，也不能删除 parser 实际必填的 author。对象常量不靠“填满默认关键帧”实现。
7. 全局秒、clip 局部秒、rule gate、path timing 和 trigger tick 必须有显式单位。60 fps 预览不是把脚本时间量化成 1/60 秒的理由。
8. marker、缩放、折叠、轨道 UI 锁定/静音、图节点坐标等优先视为编辑器状态；只有 parser/schema 真正支持的字段才能输出。`timeline.loop_start/loop_end` 是 parser 认可的字段，不能和纯 UI A–B 范围混淆。

### C05–C06：信号与画面

- 本计划不新造与现有 WebUI 相冲突的 envelope；确切已有消息/返回形状由 03 从 WebEditorApi/WebSocketSession/store 核对。不存在的 folder.move/dependency.edit 等名称即使写成例子也只是提案。
- 游戏内适配与 WebSocket 适配对上层暴露同语义端口，不允许一个直接读文件、另一个让主模组校验。AUI 不获得任意文件系统、命令执行或主模组私有类访问权。
- 脚本控制、飞控状态、画面数据是不同通道；seek 成功不等于对应视频帧已抵达。帧按会话/顺序关联，丢弃旧会话帧；具体字段必须复用已有协议或明确提新协议。
- 固定 1080p60 是 Z 设计目标，不是本次测试结果。没有帧/编码器/有效尺寸时显示占位和原因，不能伪装播放成功或自动切离线演示。
- 同进程不应绕 CPU/网络重走 WebUI；如果当前公共 API 或 AUI 纹理入口不具备此能力，必须完成受审前置接口，再进入 Forge 冒烟。不得默默降级成截图刷新充数。
- 屏幕关闭/禁用/换世界释放输入、会话、纹理/流、监听器；关闭重复执行幂等。编辑器自己的 UI 不进入捕获画面。

### C07：图的三类“位置”

布局坐标 → 编辑器元数据，不写脚本；文件夹位置 → 服务端路径事务，受根目录/路径校验约束；meta.id → 脚本语义身份，不能假设等于相对文件路径。移动文件前先用 ScriptFileService/ScriptGraphService 的实际寻址规则确定是否需改引用；不要无条件重写全部 meta.id。

依赖边保留触发器/条件路径/类型，非全部关系都可直接添加删除。合法可维护关系使用真实的条件数据；复杂只读派生边仍可导航。事务显示影响范围、校验后提交、失败恢复；不得在图内开放任意脚本源码编辑。

### C08–C11：异步、行为、模板

属性独立关键帧严格递增，同时间冲突应阻止而不是自动合并；超出窗口的节点保留并标明不生效，不静默删除。VALUE 不允许 keyframes；STEP 不提供连续贝塞尔。路径的相邻位置节点约束由运行时确认。规则条件与脚本触发条件可能使用相似 UI，但必须保留各自 schema、时间单位、事实来源和动作权限。

界面职责由[C17效果控件工作区](effect-controls-workspace.md)冻结：主时间轴绝不显示/编辑属性节点、对象展开或汇总帧带；片段效果控件多组可同时可见、左参数右独立节点，选属性不切独占页。效果控件与快捷属性两个panelId独立注册/可同时停靠；只有一份标准文档/Selection/命令，局部视口与主轴全局视口分开。节点轴外可达/虚拟化由06负责，不改变上述异步/时间/引用/模式语义。

模板展开、随机种子、片段身份重映射、路径/规则引用重写在一次文档事务里完成；展开结果必须能由主模组直接解析。模板库元信息与图布局一样不成为运行时扩展字段。

### C15：统一包与双模式

按[editor-package-modes.md](editor-package-modes.md)执行旧webui包到editor的干净切换。J:webui是当前事实路径，不是未来包规划；api/editor是稳定对外契约，editor是内部共享管理/服务和两模式适配。总关闭禁止两模式新会话并释放编辑器资源，不能卸载普通播放能力或其他捕获消费者；模式能力发现不等于启动所有服务。

## 五、为什么不选别的

不保留旧格式兼容层，不用宽泛any掩盖数据丢失，不用乐观UI代替回执。代价是前两轮迁移旧消费者，03收口WebUI与统一入口；进程内公共接口缺口在WebUI完成后的14落实，不阻塞早期功能轮。
