# 06-ClipEffectControlsPanel：统一片段级效果控件

> 状态：未实现（提案设计）。
> 范围：本轮只完整实现/人工验收WebUI；13全验通过后14迁移Forge+AUI，不构成本轮前置。
> 合同：C03/C04/C08/C13；界面权威见[效果控件工作区](../shared/effect-controls-workspace.md)。
> 前置：02标准文档/Selection/命令，05双面板宿主；同轮ObjectPropertyList、EffectControlsRows、PropertyValueForm、KeyframeEditOps。

## 一、摘要

一个片段对应一个效果控件上下文，统一列出其适用的对象/功能组：左侧参数与值控件，右侧是同一局部时间标尺下的各属性独立关键帧组。可同时展开位置、朝向、裁切、声音等实际适用组；选择某属性或节点只改变编辑目标/高亮，不切换到只显示这个属性的独占页面。

这是关键帧编辑的完整工作区，不是主时间轴的片段子行，也不是窄快捷属性栏中的单属性小表。右侧快捷属性是独立的selection.properties面板，使用同一参数控件与命令，不能成为另一套节点编辑器。

## 二、为什么做

### 2.1 问题与源码基线

| 已有事实 | 实际迁移锚点 | 与新工作区的差异 |
|---|---|---|
| KeyframePanel读取整帧数组、按下标选择 | EDITOR:src/components/KeyframePanel.vue 12、29、129–161 | 不能作为新面板数据源或直接保留旧路由 |
| App右侧用旧固定tab承载面板 | EDITOR:src/App.vue 367–377 | 需要05宿主独立注册clip.effects/selection.properties，而非object→单属性切页 |
| 主时间轴直接增删/拖动整帧 | EDITOR:src/components/Timeline.vue 104–108、342–366、384–388 | 全部节点交互迁离主时间轴，由本工作区承载 |
| 运行时节点只有time/value | J:script/object/ObjectKeyframe.java 12 | 统一展示不能新增帧类型、组帧或effect实例字段 |
| 运行时只过滤有效窗口内节点 | J:script/object/SampledProperty.java compile 153–162 | 轴外节点保留并在效果控件显示，不扩大片段 |

EDITOR/J路径前缀沿02基线；行号是旧源码定位，不代表新类已存在，实施前按符号重读。

### 2.2 目标

- 当前片段全部适用处理在同一容器中可发现；多个组/属性同时显示与对照。
- 常量、动画、事件按真实mode呈现；不同属性保持各自时间、值、STEP/连续能力。
- 主时间轴仅改片段编排；选择片段不展开主轴对象行，不画任何属性节点或汇总点。
- 未选中、多选、独立片段、数据失效、异步切换、停靠恢复都有明确状态。

### 2.3 非目标

不实现任意效果插件链、运行时分组对象、素材播放、PR逐帧插值类型或本地游戏渲染；不把单属性底层命令误解为只许显示单属性。

## 三、方案

### 3.1 可见结构与职责

| 区块 | 显示内容 | 责任组件（提案） |
|---|---|---|
| 片段头 | 名称/轨道/身份、有限或无限时长、未保存/校验摘要 | EffectControlsHeader.vue |
| 对象/功能组 | 来自当前schema的适用组，折叠/搜索/可用性原因 | ObjectPropertyList、EffectControlGroup.vue |
| 参数列 | 当前值、静态控件、秒表、前后节点、当前节点菱形 | ObjectPropertyRow、PropertyValueForm |
| 节点区域 | 所有已展开行对齐的独立节点与轴外状态 | EffectControlsRows.vue |
| 共享局部标尺 | 当前片段局部秒、播放头、缩放/适配/跳到全部节点 | EffectControlsRuler.vue；由Rows任务负责几何 |
| 展开详情 | 选中节点时间/值、适用段缓动、事件记录或专用对象组件 | KeyframeDetailEditor.vue及06/07/11已有组件 |

组来自schema.section与真实能力，可把作者相关字段组织为位置/朝向等，但不是输出数据的新层级。第三方/未分组属性仍可发现；未知或不可编辑项只读保留并给原因，不默默删除。内容添加/删除/开关/顺序必须有真实格式语义，不能因为截图有fx列表就开放任意效果链。

### 3.2 同时可见与选择

打开片段时一次派生完整组/行集合，按保存的展开状态或默认组展示。点yaw只高亮yaw和它的节点详情，position等已经展开行继续存在；清过滤恢复原顺序，不以数组下标恢复选区。搜索/只看有帧是显式过滤，不自动随所选属性过滤整个面板。

各属性右侧节点共享片段局部标尺与一个局部播放头：x@0/2/5、yaw@1/3可上下比较，常量y也保留参数行但没有动画节点。对齐不合并节点，操作x不改yaw/y。展开曲线/段区域只影响相应行高度，左右列一起变化；不能把一行的曲线伸到别的对象上。

### 3.3 各模式

| schema模式 | 参数与节点呈现 | 不允许 |
|---|---|---|
| VALUE | 行内值编辑，无动画时钟/节点带 | 给它新增keyframes |
| ANIMATED | 常量/动画状态、秒表、当前时刻节点菱形、前后导航、独立节点 | 时钟和菱形混为一键；给其他属性补帧 |
| EVENT | 按真实结构挂接EventRecordEditor，保留记录时间/载荷诊断 | 画成连续值曲线或凭节点组件猜事件语义 |

前后节点按钮只改导航；秒表关闭动画需确认并按原命令保留确定的value，取消恢复控件；在播放头添加已有同属性时间节点时拒绝并提示。局部t必须合法，不对负时间静默clamp；轴外合法t可通过明确的节点时间编辑保留/调整。已有节点的值修改和新增节点必须有明确命令目标。

## 四、技术细节

### 4.1 类与输入输出

建议目录EDITOR:src/components/effects/及src/effects/；若已有同职责组件先干净迁移，不平行保留两套。以下名称均为提案。

| 类/模块 | 输入 | 输出与所有权 |
|---|---|---|
| ClipEffectControlsPanel.vue | 02只读文档/修订、Selection/节点批选、schema、宿主状态 | 组合布局、当前有效片段视图；只发选择/文档命令/seek意图 |
| effectContext.ts — bindEffectContext | 05只读none/multi/clip/invalid上下文、同一02Selection/docRevision、可选显式pin | 绑定该上下文的业务视图/订阅与过期结果拒绝；不再复制宿主的片段选择判断 |
| effectControlsState.ts | 文档会话+clipKey及UI事件 | 组折叠、过滤、列宽、局部viewport；不是第二份文档或Selection |
| EffectControlGroup.vue | 组标题、稳定路径行、展开状态 | UI展开/聚焦请求，不创建运行时组对象 |
| KeyframeDetailEditor.vue | 完整目标clipKey/path/time与schema值定义 | 委托PropertyValueForm/KeyframeEditOps；不缓存另一份可编辑节点 |

ObjectPropertyList负责左列及目录，EffectControlsRows负责局部视口/行布局/节点命中与显示，两者消费同一派生行布局；本容器不再重复实现命令、采样或虚拟化。

### 4.2 上下文与生命周期

1. 有一个有效clipKey时展示该片段全部适用组；选子属性/节点仍是同一片段上下文，保留展开与局部视口。
2. 无选择显示空态；片段多选显示批选摘要与已有片段批量命令入口，不合并objects或伪造多片段统一节点。
3. 脚本级独立片段可从结构/行为入口用真实clipKey定位本容器，主时间轴不新增伪片段。局部编辑时间和实际执行播放时间按03区分。
4. 文档关闭卸载订阅/拖动/输入草稿；删除片段时显示失效目标，清掉其选择，不自动切到邻片段；撤销按02恢复原键。
5. 快速切换片段/文档用docRevision和请求来源丢弃过期数据；未知schema/资源失败显示诊断，不能填0或旧片段值。
6. 显式pin按05共享合同展示固定对象及不匹配提示，所有写入针对标题显示的有效目标；不把pin藏成第二份全局Selection。

### 4.3 时间与范围

- 主时间轴是全局秒；本面板使用片段局部秒，各行共用一个局部viewport。内联片段仅在映射点执行global=start_time+local；独立片段不发明start_time或虚假的执行时钟。
- 局部播放头导航经03实际seek/回执；没有运行会话时可移动编辑游标，但不能宣称游戏画面已经对应。循环不在前端取模伪造运行时间。
- 本地查看范围可覆盖t>duration的轴外节点，有限片段t=duration仍轴内；无限片段合法t≥0不因窗口末端变轴外。
- 显示轴外节点不拉宽主时间轴片段，不修改duration/loop，也不以预览fps量化节点。

### 4.4 与快捷属性、专门工具的关系

selection.properties由05提供独立宿主，06-PropertyValueForm提供SelectionPropertiesPanel内容与共用控件。片段播放参数调用05既有命令；选中对象/叶子/节点时显示适用常用参数或详情定位，不再塞一条独立关键帧时间轴。两面板可以同时停靠，改同一目标走同一02命令并相互回显；输入草稿未提交时不被回显覆盖。

07路径/数学、08镜头转场、09覆盖层、10音频调色、11事件、12飞控/几何/字幕均沿当前片段和叶子路径定位；复杂专门工具仍在原位置，但节点编辑复用本容器中的行。游戏真实预览不由这里的曲线/数值示意替代。

### 4.5 实施步骤

1. 读实际App/旧KeyframePanel/Timeline/字段组件及上述schema/消费者；确认05宿主的两个panelId已存在，不自己加旧rightTab分支。
2. 消费05宿主已解析的none/multi/clip/invalid上下文，建按clipKey索引的业务UI状态并组合ClipEffectControlsPanel；不另做一份片段选择解析或取多选第一项。独立片段仍通过真实clipKey进入同一合同。
3. 以完整适用行集合挂接ObjectPropertyList、EffectControlsRows与共享局部标尺，保证多个组同时可见；选中行只聚焦，不排除其他行。
4. 绑定原06单属性命令、事件组件、缓动组件和共用值控件；节点身份与路径端点影响由02命令处理，不在容器猜重绑。
5. 衔接selection.properties及诊断/路径/飞控定位；写失败/取消保持标准文档、选择和原显示值。

### 4.6 人工验收与完成定义

| 场景 | 操作与观察 | 失败判据 |
|---|---|---|
| 统一片段上下文 | 打开CAMERA，同时展开位置/朝向；x@0/2/5、yaw@1/3、y常量 | 点yaw后只剩yaw，或三轴合并成一条帧带 |
| 主轴分离 | 打开100+属性片段并反复展开效果组 | 主时间轴出现属性行/节点/汇总菱形或轨道高度改变 |
| 独立命令 | 在x@2改值、移动、删除并撤销 | yaw/y变化、选择指错对象、历史不是一次操作 |
| 轴外 | duration=5时编辑t=7节点并适配全部，再拖回 | 数据被夹回/删除、片段宽度被拉成7秒 |
| 值控件同步 | 快捷属性与效果控件编辑同一目标，取消一次/提交一次 | 两份值、动画只改无效value、静默补其他属性帧 |
| 模式/约束 | VALUE/ANIMATED/EVENT、STEP、null/引用及路径端点分别操作 | 可给VALUE加帧、STEP连续把手、引用失败半写 |
| 视口/焦点 | 两面板分开停靠，滚动/缩放局部轴，主轴另行缩放，中文输入 | 视口互相重置、左右串行、按键误删片段或抢飞控 |
| 恢复/错误 | 切片段、删片段、撤销、多选、缺schema、断连、重开 | 过期值串写、假成功、自动取多选第一项 |

所有正常、取消和失败路径与保存重载/游戏表现均人工操作记录；未操作不填通过。不新增单测/CI/测试脚本，不以菜单或JSON存在替代可用性。

## 五、为什么不选别的

不继续主时间轴对象行，不采用单属性独占面板，不为每个叶子创建大卡片/独立时钟，不合并跨属性节点，不复制PR效果链。统一容器需要完整上下文和视口协调，但它才让异步关键帧可对照且不挤占片段编排。类粒度保持精细，UI按作者任务组合。
