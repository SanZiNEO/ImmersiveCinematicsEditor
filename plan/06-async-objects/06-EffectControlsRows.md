# 06-EffectControlsRows：效果控件行、局部视口与独立节点

> 状态：未实现（提案设计）。

## 一、摘要

只在clip.effects内部生成和渲染对象组/属性行及独立关键帧组，完成左右列行对齐、共享片段局部标尺、局部缩放/平移/范围、节点命中/选择、拖动预览、轴外显示和纵向虚拟化。主时间轴不消费这些行，不画节点、不展开对象，也不为本任务提供节点视口框架。

本任务与ClipEffectControlsPanel分别负责“如何正确绘制/命中”与“展示哪个片段并组合哪些能力”；ObjectPropertyList负责左侧目录/参数内容，左右列共同消费同一布局，不各自算一遍y。

### 2.2 可观察目标

- 一个片段可同时展开多个功能组和多个独立属性节点组；选x时yaw仍可见。
- 左值控件、右节点和可变高详情/曲线在滚动、折叠、字体/密度变化后严格同行。
- 100+属性与大量节点可操作；窗口化不让选中节点丢失或点击命中到别行。
- 轴外节点在此面板可达、可编辑且不拉宽主轴片段；同时间跨属性不会合并。

### 2.3 非目标

不做主时间轴片段渲染，不负责片段移动/裁切，不重定义Selection/节点批选，不复制运行时采样，不把每个组或叶子做一套独立时间轴状态。

## 三、方案

### 3.1 同一行树与一个局部视口

按schema.section及适用性建立功能组，叶子按schema声明顺序进入组；行稳定键包含clipKey+完整objectPath，组键仅UI使用。左参数列与右节点列共享过滤/展开结果、rowTop/height、可见区和纵向滚动源。详情或作者段区域展开时增加一条明确子行，不能只在右侧撑高。

每个片段上下文只有一个局部viewport：originLocalSeconds、pxPerSecond、viewportWidth与scrollTop；所有可见属性节点取同一秒→像素映射。主时间轴有自己的全局viewport，只有播放头时间经03/同一换算点互通。可复用纯换算工具，但不复用05主轴的可变pxPerSecond/scrollLeft或命中类型。

### 3.2 行与节点的显示

| 项 | 本面板规则 |
|---|---|
| 组头 | 折叠/展开该组UI，不产生组帧、运行时对象或统一关键帧 |
| 静态叶子 | 左侧可编辑值/状态，右侧没有可动画节点 |
| 动画叶子 | 每个节点属于本完整路径；x=(localTime-originLocalSeconds)×pxPerSecond，绝不能除以duration当像素宽度 |
| 当前播放头 | 顶部局部标尺与右侧所有展开行共用一条线；左列当前值/菱形从同一时间派生 |
| STEP/连续 | STEP用明确阶跃样式；其他interp只按schema标识；曲线只是允许范围内的示意/作者段，不冒充游戏求值 |
| 事件 | 挂接事件记录专用行/组件；不同记录不合并，不套连续曲线 |
| 轴外节点 | 有限片段t>duration标轴外且仍可选/编辑，背景明确片段有效窗口；t=duration仍轴内 |
| 参考线 | 只画当前合法节点拖动的候选，不把主轴片段吸附候选当默认节点吸附规则 |
| 未知/不可用 | 只读或置灰加原因；过滤只改显示，不删原数据 |

主时间轴片段没有“关键帧数量点”、汇总菱形或展开箭头作为替代。片段名/循环等既有摘要可以保留，但不能把所有节点藏成一条总帧带。

### 3.3 可达范围与无限片段

默认局部显示范围可围绕片段窗口，提供“适配片段”“适配全部节点”“跳到选中/轴外节点”。最远合法节点只扩展效果控件localDisplayEnd，不写derived主时间轴时长、clip.duration或脚本字段。过滤后隐藏的选中行通过明确reveal可定位，不能永远不可见。

无限片段仍用有限可滚动编辑窗口，合法t≥0全部轴内；滚动扩展不写Infinity，不把可视末端变成有效时长。负时间不是轴外合法节点，提交必须按命令拒绝，不夹成0。

### 3.4 交互与上下文

| 动作 | 意图 | 不允许 |
|---|---|---|
| 点组头 | 仅改UI展开 | 清其他组/选择，向标准脚本写group |
| 点叶子标签 | 更新共享objectPath并聚焦 | 隐藏其他已展开属性或切单属性独占页面 |
| 点节点 | 选择clipKey/path/time；可明确选择导航播放头 | 按同时间跨属性自动联选、用下标 |
| 拖节点 | 临时预览→松手一次命令；命令回执映射选择 | mousemove入历史、半次提交、冲突覆盖 |
| 框选/节点批选 | 按06-KeyframeEditOps现有允许范围记录到同一keyframeSelection | 新增跨属性批量改值/隐式兄弟轴选择 |
| 节点菜单 | 添加/删/改时间值/复制粘贴及适用段入口 | 主时间轴出现相同节点菜单 |
| 定位诊断/路径节点 | reveal片段上下文、组、叶子、局部时间 | 展开主时间轴对象行或自动改片段长度 |

节点拖动吸附时机、复制粘贴冲突、路径端点相邻与批量限制继续由原06命令/02引用合同决定。Esc/指针取消/失焦/组件卸载清临时状态与监听，不写文档、不产生空历史。

## 四、技术细节

### 4.1 类级输入输出

| 提案职责/文件 | 输入 | 输出 |
|---|---|---|
| src/effects/effectRows.ts — buildEffectRows | 单片段只读对象、schema行定义、展开/过滤、共享Selection | 功能组/叶子/详情行列表及稳定键，不含主轴轨道行 |
| src/effects/effectRowLayout.ts — layoutEffectRows | 同一行列表、密度、实测高度与视口 | 统一rowTop/height/visibleRange；左右列共同消费 |
| src/effects/effectViewport.ts | 当前clipKey、局部窗口、缩放/滚动、显示范围请求 | localTimeToX/xToLocalTime及合法显示范围；状态归效果控件UI会话 |
| src/effects/effectHitTest.ts | 行布局、局部viewport、指针 | group/property/node/segment/empty命中，含完整目标，不返回数组索引身份 |
| src/components/effects/EffectControlsRows.vue | 行布局、只读节点、播放头、选择 | 渲染、命中与意图；值/时间修改交给共享命令 |
| src/components/effects/EffectControlsRuler.vue | 同一局部viewport与播放头来源 | 刻度/局部seek意图，不直接写03运行状态 |

数据形态可沿既有ObjectRow扩展展示信息，不在标准objects、ObjectKeyframe或脚本meta中加入rowId/viewport/expanded。一个clipKey内所有属性共享局部viewport；切片段后按其UI状态恢复，不共用最后一个属性的缩放。

### 4.2 实施顺序

1. 读旧Timeline节点入口和新ClipEffectControlsPanel上下文合同；确认主轴删除节点逻辑归05，不能重新挂对象行到Timeline.vue。
2. 建效果控件行模型与布局；接ObjectPropertyList左列和右列，在折叠/过滤/可变高子行下保证同一y。初值/可用性从既有ObjectRow派生，不在行布局读网络。
3. 完成本地标尺、滚动、指针锚定缩放、适配片段/全部节点、无限窗口与轴外定位；主轴视口不被改动。
4. 按可见纵向行及局部时间窗口渲染，二分查找可见节点；保留命中slop和选区/焦点，虚拟卸载不删除任何节点或把选择移到邻居。
5. 接KeyframeEditOps的开始/预览/提交/取消及定位映射，完成STEP、VALUE、事件专用呈现；路径端点高亮仅是本面板背景/选区，不新增运行时字段。
6. 挂接诊断/路径/飞控/快捷属性的reveal请求，通过同一clipKey/path/time定位；隐藏面板先恢复显示再滚到目标。
7. 完成取消、失败、虚拟化、停靠、小窗、不同密度、保存重开及游戏验证，再清除旧timelineRows.ts/旧主轴对象行提案与废弃调用。

### 4.3 人工验收

| 准备/操作 | 预期 | 异常检查 |
|---|---|---|
| duration=5；x@0/3、yaw@1/2、y常量，同屏展开 | 三行左列和对应右区对齐，各自节点清楚 | 点yaw后x/y不消失，主轴无节点 |
| x末节点改到7秒，适配全部 | 效果控件显示轴外7秒，主轴片段仍5秒 | 不夹回、不删除、不改脚本时长 |
| 缩短片段再展开/恢复 | 轴外数量变化，原节点值/时间保留 | 不补边界帧、不重排别的属性 |
| 无限片段t=100，滚动到该节点 | 显示合法轴内，不写Infinity或duration=100 | 可视窗口不是采样窗口 |
| 100+属性、嵌套组/详情、缩放字体后滚动 | 左右行不串、可见节点可命中、操作可达 | 不把复杂度转移到主轴高度 |
| 拖动同一属性节点撞同时间，Esc/失焦 | 整次失败/取消无文档变化，历史不增 | 不自动合并或覆盖 |
| 定位一个被折叠/过滤的轴外节点 | 显式reveal并滚到效果控件正确行 | 不选相邻节点，不展开主轴对象行 |
| 从快捷属性改值并撤销/重做/保存重开 | 两处回显一致，选择按命令映射 | 不出现第二份节点或历史 |

轴外采样表现、STEP/连续、字段合法性和实际播放仍用真实parser/validator与游戏画面人工观察。未运行不填通过，不新增测试框架或脚本。

### 4.4 14迁移边界

13完整WebUI验收后，14用EditorEffectControlsController/AUI元素实现相同组行、局部视口、节点拖动、取消、轴外、可达性与输入作用域。不能只交“片段+有帧行点选”，不能推迟拖动/缓动到未定义后轮，也不能为小窗把节点搬回主轴。系统窗口等已有不适用边界保留。

## 五、为什么不选别的

不把对象行作为主时间轴的子行，不让每个属性拥有互相漂移的标尺，不把单属性独占页作为小窗降级，不依赖05节点框架，不合并同刻不同属性节点。效果控件内仍有行，但这些是片段参数工作区的行，不是整体编排轨道。代价是06承担完整局部几何和虚拟化，换来清晰的整体编排与异步对照。
