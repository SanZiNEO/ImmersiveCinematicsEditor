# R14-09 R2～R12 全功能迁移矩阵

> 前置：R14-08 垂直切片全部 PASS
> 出口：R14 全功能迁移完成
> 状态：设计合同；逐模块真实验收未执行时不填 PASS

## 1. 职责

把 R2～R12 在 WebUI 已定的能力，逐模块迁到 AUI 宿主。不是“宿主能开就算完成”，也不是“把 WebUI 组件截图搬进游戏”。

本文件只做迁移与承载，不新增编辑语义：

- 不新增脚本字段/消息名；
- 不新增第二套文档/撤销/模板/字幕批次；
- 不把旧编辑器代码当设计依据；
- 不在 AUI 里补 WebUI 未验收的功能；缺什么回原轮。

## 2. 分层

```text
AUI 页面（HTML/CSS/DOM，仅视图与本地视图状态）
        ↕ Java 侧 Element.addEventListener / DOM 更新
Editor*Controller（附属模组，视图与创作意图）
        ↕
编辑器共享创作核心（文档/命令/撤销/序列化/模板/字幕批次）
        ↕ EditorSignalBridge（R14-04）
主模组 editor 服务（schema/文件/校验/图事务/播放/事实/画面/飞控）
```

- 创作状态仍属编辑器核心；主模组只提供权威服务。
- AUI 只保存选择/滚动/面板尺寸/主题等视图状态；脚本内容通过消息请求/回执。
- AUI 无 Vue/现代 JS 运行时；交互由 Java 侧绑定 DOM，页面 JS 只能作为可选增强，验收不依赖。
- 同一套消息名/字段/信封；进程内与 WebSocket 只是载体不同。

## 4. 关键语义边界

### 4.1 R8 转场

- 转场面板以 **A→B 片段交界** 为编辑对象，不是片段内字段，不在主轴画转场节点。
- 叠化是 **crossfade**：A 位置不动，B 前移 D 秒，两段真实重叠 D 秒；A 保持不透明，B 在重叠区从 0 淡入到 1。
- `fade` 是覆盖层颜色/遮罩渐变，不是 crossfade；不要把二者混称。
- `morph` 是参数过渡，不是画面叠化；同一交界允许共存，面板显示 morph 优先区间与叠化可见区间。
- 统一用“叠化（crossfade）”，不用其他名称。

### 4.2 R9/R10 调色

- R9 是覆盖层、字幕、画幅、层级，不建游戏 HUD 合成管线。
- 调色是 CAMERA/ADJUST 的既有颜色字段；该有什么就有什么，不塞 R9 没有的字段。
- R9 只写 R9-05 字段面；调色字段属于 R10，不塞进 R9。

### 4.3 R11 触发器悬停

- 鼠标悬停脚本对象时，Tooltip 必须显示该脚本**全部触发器**，不是只显示第一条。
- 每个触发器显示条件摘要、`requires` 前置（脚本 id/名/文件夹）、悬空/自引用标记；条件树过长时展开，不截断。
- 数据来自 R11 图/触发器读取；AUI 用 Java 侧 `mouseenter/mousemove` 绑定，不能依赖页面 JS。
- 悬停不改变选择、不打开脚本；点击才打开。

### 4.4 R12 模板/字幕

- 模板只做内置片段/轨道/脚本三层；不做纯数据模板、模板包、DSL。
- 飞控九槽是编辑器侧暂存输入源，不是新飞控协议。
- 字幕导入只写 R9-05 字段面；固定白色；不建 sidecar；批次就是字幕轨道；不做样式批处理/拆分合并为必过项。
- 字幕导入用游戏内路径/资源选择器，不用浏览器 `<input type=file>`。

### 4.5 资源扩展名

按模组当前代码，不按浏览器 `accept` 习惯：

| 类型 | 允许 | 说明 |
|---|---|---|
| `kind=image` | `png/gif` | 不含 `jpg/jpeg/webp` |
| `kind=video` | `mp4/webm/mkv` | R13 补 `kind=video`；不含 `mov` |
| `OVERLAY image.path` | `png/gif/mp4/webm/mkv` | 图片与视频共用字段，按扩展名分流 |
| `kind=audio` | `ogg/wav` | 基础集合 |
| 音频（有 ffmpeg） | 再加 `mp3/aac/flac/m4a/opus/wma/oga/ogx` | 无 ffmpeg 时这些不是必过项；明确提示降级 |

约束：

- `jpg/jpeg/webp`、`mov` 当前不支持，不写成必过项。
- R1-06 的提案不是已实现；R14 只按实际代码集合显示/校验。
- 资源选择器过滤与主模组服务端校验使用同一集合；前端过滤不能比服务端更宽。

## 5. 宿主不适用项（不得静默删除）

| 项 | WebUI | AUI | 处理 |
|---|---|---|---|
| 系统文件对话框 | Electron/浏览器文件选择 | 无系统文件对话框 | 用游戏内路径/资源选择器；明确说明入口不同 |
| 系统窗口控制 | Electron 最小化/最大化/关闭 | 无独立窗口 | 全屏 Screen；不做窗口控制；布局/偏好写游戏配置 |
| LUT 桌面导出 | 可选桌面路径 | 无桌面路径选择 | 用游戏内路径/资源选择器；不假装有桌面导出 |
| 浏览器 localStorage | 有 | 无 | 主题/布局/偏好写游戏配置或附属模组 JSON；页面不直接读写文件 |
| 页面 JS 运行时 | 浏览器 JS | 当前无 KubeJS/Rhino | 交互 Java 侧绑定；页面 JS 仅可选增强，不进验收前提 |

除上表外，R2～R12 的必做能力一律“迁移”或“宿主替换”，没有“可选/后续”。
