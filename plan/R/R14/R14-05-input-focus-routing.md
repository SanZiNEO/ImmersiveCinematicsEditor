# R14-05 输入、焦点与按键路由

> 前置：R14-02 Screen 可打开；R14-04 端点可用
> 后续：R14-06 飞控、R14-08 垂直切片
> 状态：设计合同；真实输入未执行时不填 PASS

## 1. 职责

冻结游戏内编辑器的输入路径：

- 一个统一编辑器键 `F6`，可改绑；不是 F8/F9 两个入口；
- ESC/F7/飞控键与 AUI 键盘事件共存；
- 鼠标、光标、文本焦点、IME、面板手势；
- 玩家移动输入不被编辑器误驱动；
- 图节点悬停显示该脚本的全部触发条件，包括 `requires` 前置；
- 关闭时释放按键/焦点/光标状态。

本文件不实现飞控逻辑（R14-06）与画面（R14-03）。

## 2. 当前事实

### 2.1 现有键位

- 主模组 `CinematicKeyBindings` 当前 F9 打开 WebUI 预览屏；F7 与飞控键存在。
- 此前 ingame 入口按本轮统一决定默认 `F6`；R14 把 WebUI/AUI 都统一到 `EDITOR_OPEN`（默认 F6）。
- R13 文档里的 WebUI 验收引用已同步为 `F6`；R14 起统一 `F6`，验收时 AUI 不存在，`F6` 落到 WebUI。
- 附属模组当前没有 `EditorAuiScreen`，也没有输入路由。

### 2.2 AUI 输入

- AUI 在 `KeyboardHandler.keyPress` HEAD 派发给 Document；`keydown` 可被页面 `preventDefault`。
- `MouseHandler.onPress/onScroll` 派发鼠标事件；按文档层级/`interceptsMouseEventsAt` 命中。
- `Operation` 处理焦点文本、按钮、Select、滚轮；`Document` 有焦点/清理。
- `ApricityScreen` 的 `keyPressed` 只处理 reload/缩放，其余交 `super`。
- `blockMouseEventsWhenCursorHidden` 配置存在；编辑器需要鼠标可见。
- 当前 Forge dev 无 KubeJS/Rhino；页面 JS 不执行，交互必须 Java 侧 `Element.addEventListener`/DOM 更新。

## 3. 方案

### 3.1 单键

| 键 | 行为 |
|---|---|
| `F6` | 打开/关闭当前活动载体；默认 `EDITOR_OPEN`，可改绑 |
| `ESC` | 飞控中先取消飞控；文本焦点先失焦；否则关闭编辑器 |
| `F7` | 飞控激活时退出飞控；非飞控不打开编辑器 |
| 飞控键 | 激活时转发 `FlightModeManager.onKeyEvent`；关闭/退出后恢复 |

约束：

- `F6` 是主模组统一键，不是附属模组第二键；附属模组只注册 `INGAME` 载体。
- 改绑走原版 Controls；改绑后 `F6` 不再硬编码在 Screen 里，Screen 只认 `EDITOR_OPEN` 键位状态。
- 同一按键一次只消费一层：AUI 先 `keydown`；若页面/焦点消费，则 Screen 不再重复处理。
- `F6` 关闭时若飞控激活：先取消（不写回）再关闭；不把“关闭”当成“记录退出”。
- 标题界面/未进世界不打开；总开关关闭时无动作。

### 3.2 焦点与文本

- 编辑器输入框点击后获得 AUI 焦点；文本/数字/快捷键由 AUI 处理，Screen 不抢 `A-Z/0-9/空格/标点`。
- 文本焦点时 `ESC`：第一次失焦并消费；第二次才关闭；飞控中 `ESC` 优先取消飞控。
- `Tab/Shift+Tab`、方向键、Enter、Esc 在面板内统一规则；不各面板一套。
- IME/中文输入：以 AUI 当前能力为准；若 AUI 输入法事件不完整，必须记录为宿主限制并提供可用的替代输入方式，不能假装支持。
- 关闭时清焦点、清 pressed/hover 状态、释放按键；不把按键状态留到游戏。

### 3.3 鼠标/光标

- 编辑器打开时鼠标可见、可点击；必要时显式释放光标。
- AUI 鼠标事件负责点击/滚动/拖拽；面板拖动/停靠只从标题开始，节点拖动不触发片段移动。
- 飞控激活时鼠标用于视角，编辑器 UI 不接收鼠标；退出飞控后恢复焦点到原面板，不恢复到任意旧属性。
- 关闭时恢复光标/按键状态；不残留 grabbed。

### 3.4 玩家输入

- `setPauseGame(false)`：游戏继续 tick/渲染；不等于玩家输入自动屏蔽。
- 打开编辑器时必须实测 WASD/空格/Shift 是否仍驱动玩家；若仍驱动，在 `EditorAuiScreen` 层吞移动键或清空 `Minecraft.player.input`，不修改玩家持久状态。
- 飞控激活时玩家移动由飞控接管，不走原版移动；退出后恢复原状态。
- 关闭后不得留下“按键一直被吞”的状态。

### 3.5 面板手势作用域

按 C17 区分：

| 区域 | 输入职责 |
|---|---|
| 主时间轴 | 只编排片段：移动/裁切/分割/复制粘贴/删除/循环/波纹/播放头/缩放/滚动 |
| `clip.effects` | 属性/效果组、节点选择、复制粘贴、删帧、局部缩放/滚动 |
| `selection.properties` | 当前目标的值输入与 reveal；不设第二节点轴 |
| 抽屉/对话框 | 自身焦点与滚动；不与主轴/效果控件抢滚轮 |
| 飞控 | 独占鼠标/飞控键；退出后恢复正确面板焦点 |

约束：

- 指针按下后由当前手势持有到释放/取消；节点拖动不触发片段移动或面板停靠。
- Esc/失焦/丢指针/卸载清临时预览、释放捕获，不提交半次命令。
- 局部节点轴与主轴滚轮各自拥有视口；不能一滚同时改变两轴。

### 3.6 图节点悬停：全部触发条件

R11 的脚本图要求：鼠标放到脚本对象上，显示该脚本的**全部触发条件**，包括与其他脚本的前置关系（`requires`）。

AUI 实现：

- `mouseenter`/`mouseleave`/`mousemove` 由 Java 侧绑定到图节点元素；不依赖页面 JS。
- 数据来自 R11 的图/触发器读取结果：`meta.triggers` 的每个触发器、条件树、`requires` 前置脚本、时序/连续性。
- Tooltip 内容按触发器分组：
  - 触发器 id/类型/条件摘要；
  - `requires` 的前置脚本 id + 脚本名 + 文件夹；
  - 悬空/自引用标记；
  - 如果条件树过长，先显示摘要 + “展开”按钮，不截断到只显示第一条。
- Tooltip 不能超出屏幕；靠近边缘翻转；滚轮/缩放时不丢失。
- 悬停不改变选择、不触发打开脚本；点击才打开。
- 多触发器全部列出；不能只显示“第一个触发器”或只显示“requires 数量”。

## 4. 输入输出

### 4.1 输入

- `EDITOR_OPEN` 键位状态；`EditorEntry.activeCarrier`。
- AUI Document/元素/焦点/鼠标事件。
- R11 图数据（触发器/条件/`requires`）。
- 飞控状态（R14-06）。

### 4.2 输出

- F6 打开/关闭/改绑可用。
- ESC/F7/飞控键语义唯一。
- 文本/鼠标/面板手势可用；玩家不被误驱动。
- 图节点悬停显示全部触发条件（含前置）。
- 关闭后无按键/焦点/光标残留。

### 4.3 禁止

- 注册 F8/F9 作为第二编辑器入口。
- 在 Screen 里硬编码 F6 而不读键位映射。
- 文本焦点时 Screen 抢字符键。
- 飞控中让 UI 同时接收鼠标。
- 用页面 JS 绑定图节点悬停作为唯一实现。
- Tooltip 只显示第一条触发器/只显示 requires 数量。

## 5. 验收

### 5.1 正例

**正例 A**：默认 F6 打开 AUI；改绑到其他键后，旧键无效、新键生效；重启后保留。

**正例 B**：文本输入框可输入中英文/数字；ESC 第一次失焦，第二次关闭；不双触发。

**正例 C**：鼠标可见、可点击/滚动/拖动面板；关闭后光标恢复。

**正例 D**：打开编辑器时 WASD/空格不驱动玩家；关闭后玩家输入恢复；不改玩家持久状态。

**正例 E**：飞控中 ESC 取消飞控；再 ESC 关闭；F7 退出飞控；UI 不抢鼠标。

**正例 F**：图节点悬停 → Tooltip 列出该脚本全部触发器；每个触发器显示条件摘要与 `requires` 前置（含脚本名/文件夹）；悬空/自引用有标记。

**正例 G**：悬停靠近屏幕边缘 → Tooltip 翻转/收拢，不超出；滚轮缩放后仍跟随节点。

**正例 H**：`clip.effects` 节点拖动不移动片段；主轴拖动不改变局部节点轴；两轴滚轮互不串。

### 5.2 反例

| 反例 | 判定 |
|---|---|
| F6 与 F9 都能打开编辑器 | 失败：双入口 |
| 改绑后 Screen 仍认 F6 | 失败：硬编码 |
| 文本焦点时按字符触发全局快捷键 | 失败：焦点被抢 |
| 编辑器打开时玩家仍能 WASD 移动 | 失败：输入未屏蔽 |
| 飞控中点击 UI 按钮 | 失败：飞控未独占 |
| 图节点悬停只显示第一条触发器 | 失败：未显示全部触发条件 |
| Tooltip 不含 `requires` 前置 | 失败：漏前置关系 |
| Tooltip 用页面 JS 才能出现 | 失败：当前无 JS 引擎 |
| 关闭后光标仍 grabbed | 失败：状态残留 |
