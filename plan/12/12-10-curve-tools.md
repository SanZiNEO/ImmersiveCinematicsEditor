# 12-10 曲线工具

## 目标

在 07 的路径编辑体系里补三类工具：形状入口、控制点拾取、弧长重采样。曲线工具不另立路径编辑器，不改 `paths[]` 的端点绑定，不改运行时曲线求值。

07 已经定义路径条目、端点、`geometry`、`timing`，并已有圆/圆弧/椭圆的形状生成。12 只补 07 没有的形状入口、在预览上取控制点、把 `timing` 按弧长重采样。

## 已有边界

- `paths[]` 条目：`id` / `clip` / `from` / `to` / `axes` / `geometry` / `timing`。
- 端点 `from/to` 必须命中目标片段位置节点时间并集的相邻节点；端点编辑归 07。
- `axes` 是 `x/y/z` 的非空子集；单轴合法，不强行要求两轴。
- `geometry` 的 `type` 必须来自当前 `schema.curveTypes`；本轮不新增曲线类型。
- `control_points` 必须是 `{x,y,z}` 或 `{dx,dy,dz}` 对象；不写数组形态。
- 编辑器只做显示近似与重采样，不实现运行时求值、不做运行时弧长表、不把近似结果写回。

## 职责划分

| 能力 | 归属 |
|---|---|
| 路径条目选择、端点绑定、`from/to/axes` 编辑 | 07 |
| 圆/圆弧/椭圆的精确形状生成 | 07 |
| 直线/抛物/S 形的形状入口 | 12，复用 07 生成器/路径页 |
| 预览上控制点拾取 | 12 |
| 弧长等距重采样 | 12 |
| 运行时曲线求值、弧长 LUT | 模组，12 不实现 |
| 位置关键帧/相机运动 | 07 |

## 1. 形状入口

### 支持形状

| 形状 | 产物 | 说明 |
|---|---|---|
| `line` | `geometry: { type: "line" }` | 两端点直线；无控制点 |
| `arc` | `geometry: { type: "arc", ... }` | 复用 07 已有圆弧生成；12 不重写 |
| `ellipse` | `geometry: { type: "ellipse", ... }` | 复用 07 已有椭圆生成；12 不重写 |
| `parabola` | `geometry: { type: "bezier", control_points: [...] }` | 两点控制，拱高由参数给 |
| `s` | `geometry: { type: "bezier", control_points: [...] }` | 两点控制，两侧反向偏移 |

规则：

- `line` 不改端点；`geometry` 写现有类型。
- `arc` / `ellipse` 的参数（圆心、半径、半轴、起止角、法向、参考轴）按 07 的形状生成契约；12 只提供入口，不重复数学。
- `parabola` / `s` 用 `bezier` 的两个控制点，控制点写相对段起点 `{dx,dy,dz}` 或绝对 `{x,y,z}`；不写数组。
- `axes` 只有 `x/z` 时，控制点 `dy` 必须为 0；有 `y` 轴时才允许 y 方向变化。
- 不改变 `from/to`、不改变 `timing`、不改变 `clip`。
- 不把 `arc`/`ellipse` 自动转成 `bezier`；形状切换是显式操作，转换后端点仍由 07 校验。
- 不生成 `curveTypes` 未注册的类型；其他注册类型按 `curveTypes.params` 渲染参数，不硬编码名字。
- 一次形状应用一个事务；撤销一次回退 `geometry`。

### 抛物/S 参数

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `height` | float | 0 | 抛物拱高；沿参考轴方向 |
| `tension` | float | 0.5 | S 形两侧偏移比例；0–1 |
| `reference` | enum | `up` | 参考方向：`up` / `right` / `fwd`；按路径 axes 可用轴 |
| `control_mode` | enum | `relative` | `relative` 写 `{dx,dy,dz}`；`absolute` 写 `{x,y,z}` |

- 抛物：两个控制点在端点连线的中点附近，沿 `reference` 方向抬高 `height`；不再额外加中点。
- S 形：第一个控制点向一侧偏，第二个向反向偏；偏移量由 `tension` 和段长比例决定。
- 不自动猜“上”方向；`reference` 必须与 `axes` 兼容；`axes` 只有 x/z 时不能选 `up`。
- 预览只画近似折线，标注“近似”。

## 2. 控制点拾取

### 可用条件

- 目标片段 `position_mode=absolute`，且没有 `look_at`、`orient=tangent`、路径切线依赖。
- 当前预览能用相机姿态构造屏幕射线；编辑器能拿到当前 yaw/pitch/fov 和播放窗口尺寸。
- 目标 `geometry` 支持控制点（至少 `bezier`；其他类型按 `curveTypes` 的 `control_points` 能力）。
- 目标路径的 `axes` 与拾取平面兼容；默认用固定 y 平面求交。

### 行为

1. 在预览画布上点一个屏幕位置。
2. 编辑器用当前视角做屏幕射线，与固定高度平面求交，得到世界点。
3. 把世界点转成路径控制点：
   - `relative`：减去段起点，写 `{dx,dy,dz}`。
   - `absolute`：写 `{x,y,z}`。
4. 只改选中的控制点；不自动新增/删除控制点数量。
5. 没有选中控制点时，可“追加一个控制点”，但只在 `curveTypes` 允许的数量范围内；`bezier` 固定两个，不追加第三个。
6. 拾取后显示“基于当前视角与固定高度，需目视确认”；不静默写入错误点。

### 禁止

- 片段是 `relative`/`base`、动态原点、`look_at`、`orient=tangent` 时，不做世界点拾取；只能数值输入。
- 没有深度缓冲，不试图“点哪打哪”到任意几何体；只做固定平面近似。
- 不把屏幕二维点直接写成 `position.x/y`；必须经过射线求交。
- 不把拾取结果写成位置关键帧；只写当前控制点。
- 不自动转换 `arc`/`ellipse` 为 `bezier` 来“支持拾取”。

## 3. 弧长重采样

### 输入

- 目标路径 `geometry`。
- `axes`。
- 采样数 `n`，8–64。
- 目标 `timing` 当前类型（linear 或 keyframes）。

### 过程

- 编辑器按 `geometry` 做数值积分求弧长；只用于编辑器侧重采样，不声称与运行时逐位一致。
- 在 `s∈[0,1]` 上等分；得到每个采样点的参数 `t` 和弧长比例 `s`。
- 输出 `timing: { type: "keyframes", points: [{t,s}, ...] }`。
- 约束：
  - 首点 `t=0,s=0`；末点 `t=1,s=1`。
  - `t` 严格/非降递增；至少 2 点。
  - `points` 只写 `t`/`s`；不写位置、不写控制点。
  - 不改变 `geometry`、`from/to`、`axes`。

### 用途

- 让弧线在弧长上匀速，而不是参数上匀速；3 轴路径才是完整 3D 匀速，2 轴只在平面内匀速。
- 重采样只改时间映射；不是把路径采样成位置关键帧。
- 采样越多越接近，但增加数据量；默认 16，作者可调 8–64。
- 编辑器预览显示近似匀速；最终以游戏播放为准。

### 禁止

- 不把 `timing.points` 写成 `objects.position.*` 关键帧。
- 不新增 `timing` 类型；只用现有 `linear` / `keyframes`。
- 不把编辑器积分结果写进脚本当“运行时弧长表”。
- 不自动重采样所有路径；只对作者显式选中的一条。

## 4. 预览可视化

- 在 07 的路径页/预览画布上叠加路径折线、端点、控制点手柄。
- 采样 64 段做折线显示；标注“显示近似，实际以运行时为准”。
- 端点与控制点用不同颜色；控制点可拖动，拖动只改当前 `geometry`。
- 不画“最终画面”，不画假材质/假模型。
- 相机/覆盖层两套坐标不混用；路径坐标空间由 07 标注。

## 与九槽的关系

- 控制点/端点旁的“从槽位取”打开 12-08 的九槽选择器。
- 只对绝对路径或编辑器能确定原点的 `relative + world` 路径可用。
- 槽取的是世界点；写控制点时按 `relative`/`absolute` 转成 `{dx,dy,dz}` 或 `{x,y,z}`。
- 路径端点必须已有对应位置节点；没有节点时先走 07 端点编辑，不直接塞点。
- 槽 id 不写进路径；只写数值。

## 禁止项

- 不新建第二套路径编辑器、不在 `clip.effects` 之外另开曲线 tab。
- 不新增曲线类型、不改 `PathCurveRegistry`、不改运行时求值。
- 不把控制点写成数组、不混用 `{x,y,z}` 和 `{dx,dy,dz}`。
- 不把 `from/to/axes` 改由曲线工具负责；端点仍归 07。
- 不把近似预览/积分结果当运行时真值。
- 不自动把形状转换、自动重采样、自动补端点。
- 不碰片段级转场、不碰相机位置关键帧。

## 验收出口

1. 选中 x/z 路径，应用“抛物”：生成 `bezier` 两个 `{dx,0,dz}` 控制点；游戏内呈拱形，`script.validate` 通过。
2. 应用“S 形”：两个控制点反向偏移；不改变端点/`timing`。
3. 应用“圆弧”：走 07 已有 `arc` 参数，不转成 bezier；`script.validate` 通过。
4. 控制点拾取：绝对片段可用；`look_at`/base/动态原点片段按钮禁用，提示改数值输入。
5. 拾取后只改一个控制点；不新增第三控制点；不写位置关键帧。
6. 弧长重采样 n=16：`timing.points` 16 点，首尾 0/0 与 1/1，`t` 单调不减；播放速度更均匀。
7. 重采样后 `geometry`/`from/to`/`axes` 不变；撤销一次全部回退。
8. 预览折线标注“近似”；没有假最终画面。
