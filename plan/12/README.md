# 12 模板飞控工具

## 本轮主题

12 是“模板 + 字幕完整工作流”的编辑器侧设计：

1. 模板展开与快捷效果：片段、轨道、脚本三层内置模板，参数、嵌套、装配、面板。
2. 飞控取点与九槽输入源：编辑器自己维护九个姿态槽，供模板、关键帧、路径取点；不改飞控协议。
3. 几何工具：把素材尺寸、裁切、缩放、屏幕区域换算成现有脚本字段。
4. 曲线工具：控制点拾取、弧长重采样，复用 07 已有形状生成。
5. 字幕导入、批处理、编译、面板：外部 SRT/VTT 变成标准 `OVERLAY/subtitle` 片段。

出口是“模板能生成标准脚本、字幕能从外部文件走到真实游戏播放”，不是编辑器里再长一套运行时。

## 设计依据

- 模组当前代码：模板只在新建脚本骨架里存在，运行时没有模板语义；飞控已有姿态回推；字幕固定白色文字；覆盖层按统一缩放系数换算。
- `plans/0.3.6/Z-editor/templates.md`：模板归编辑器，产物必须是标准脚本 JSON；纯数据模板是后续层。
- 02/03/04/05/06/07/08/09/10/11 已写合同：字段目录、文档模型、面板容器、控件、路径、转场、字幕、LUT、触发规则。
- 冻结轮次地图 12 行：模板展开/快捷效果、飞控几何、字幕导入/批量/编译。
- 旧 `plan/12-templates-flight-tools` 只作路线参考；旧编辑器路径、旧 `PresetsPanel`、旧 `store.ts/operations.ts` 不是设计依据。

## 三条硬边界

### 1. 模板不是运行时

模板只存在编辑器侧。模板展开的结果是普通脚本：`meta`、`timeline.tracks`、标准 `objects`、`paths[]`、`triggers` 等。运行时只解析、校验、播放产物，不认识模板 id、参数、来源或生成记录。

本轮不做纯数据模板。现行模板合同把用户自定义数据模板定为后续层；本轮先把内置模板、参数口径、嵌套和面板跑通。模板产物与模板不保持再生成关联，作者改产物后就是普通脚本。

### 2. 转场是片段交界操作

08 已冻结：叠化是 A 片段不动、B 片段前移、B 的 `composite.opacity` 在重叠区 0→1；`transition*` 只是相机六参数 morph，不是片段属性。

12 的片段/轨道模板只排相邻片段，不写片段级转场字段，不自动做 crossfade。需要叠化时，生成后到 08 的转场面板做 A→B 交界操作。模板不代替 08。

### 3. 字幕只写现有字段

当前字幕层固定白色文字，没有颜色、字体族、描边、背景框、对齐字段；`text` 是 value-only，支持 `\n`，不自动换行；`@lang:` 查语言表，`@@lang:` 转义；透明度低到 alpha < 4 时不绘制。

12 字幕编译器只写 09-05 已定义的字幕字段面，不新增字幕字段、不新增字幕轨道类型、不把 ASS 样式或网页 CSS 冒充游戏效果。

## 与其他轮次的分工

| 轮次 | 已有能力 | 12 只做什么 |
|---|---|---|
| 04 | 抽屉、面板容器、文件端口 | 用 `templates` 抽屉槽；字幕导入扩一个编辑器主进程文件端口 |
| 05 | 项目图、主时间轴、属性/效果面板 | 模板产物走现有选择/命令/事务；不新开属性面板 |
| 06 | 属性控件、效果控件 | 模板参数表单复用控件约定；字幕样式仍在现有字幕组编辑 |
| 07 | 位置、朝向、路径、形状生成 | 曲线工具只补拾取、重采样和未覆盖形状；不重做路径编辑器 |
| 08 | 镜头转场、lane、叠化、参数过渡 | 模板只排硬切；转场仍归 08 |
| 09 | 字幕字段面、覆盖层便利预设 | 字幕编译复用字段面；不复制 09-08 预设 |
| 10 | LUT 字段、层混合 | 不做 LUT 修正工具 |
| 11 | 触发器、规则、事件 | 脚本模板只写触发器骨架；不执行规则 |

## 本轮不做

- 不做纯数据模板、模板包导入、模板 DSL。
- 不做 LUT 修正工具、不烘焙 LUT、不预览最终调色画面。
- 不写片段级 `transition`、不写 crossfade、不自动改相邻片段。
- 不新增运行时模板字段、模板轨道、模板转场。
- 不新增字幕颜色/字体族/描边/背景/对齐字段。
- 不建第二套字幕 JSON、字幕 sidecar、全局 z 表。
- 不伪造素材像素尺寸、不伪造最终画面预览、不把编辑器近似结果当游戏结果。
- 不新增模组按键、消息、`.java` 改动。
