# 12-01 模板模型与装配

## 目标

定义 12 的三层模板：片段级、轨道级、脚本级。模板是编辑器侧的参数化生成器，输入参数，输出标准脚本 JSON 片段；模板本身不进入脚本，不被运行时识别。

本轮只做内置模板。模板定义、参数声明、展开函数、装配器、注册表都在编辑器侧；模组只做标准脚本的解析、校验、播放和文件搬运。

## 三层模型

```text
脚本级模板 Script Template
  生成整份脚本骨架：meta 常用值、空轨、触发器骨架、顶层轨道编排
  引用轨道级模板 × N

轨道级模板 Track Template
  生成一条轨道的片段编排：起点、时长、相邻关系
  引用片段级模板 × N

片段级模板 Clip Template
  生成一个片段的 objects，必要时附 paths[] 条目
```

三层只向下引用：脚本 → 轨道 → 片段。片段级不能引用轨道级，轨道级不能引用脚本级；同层不横向引用。

## 模板定义

模板定义是编辑器内部对象，不是脚本资产。最小字段：

| 字段 | 含义 |
|---|---|
| `id` | 模板 id，层内唯一；推荐 `clip.xxx` / `track.xxx` / `script.xxx` |
| `layer` | `clip` / `track` / `script` |
| `trackType` | 片段/轨道模板的目标轨道类型；脚本模板可为空 |
| `titleKey` / `docKey` | 面板标题与说明的 i18n key |
| `params` | 参数声明列表 |
| `expand` | 纯函数：参数对象 → 本层 JSON 片段 |
| `refs` | 可选的向下引用列表；脚本/轨道级使用 |
| `validate` | 可选的跨参数校验；只报模板参数错误，不代替脚本校验 |

模板定义无状态。每次展开都新建 JSON 对象，不复用上一次展开结果，不缓存运行时状态。

## 参数声明

参数声明复用 02 字段元数据的形状：类型、默认值、是否必填、枚举候选、分组、单位、范围。模板参数不是第二套字段系统，也不写进脚本。

本轮参数类型：

| 类型 | 用途 |
|---|---|
| `float` / `int` | 时长、半径、角度、数量 |
| `bool` | 开关 |
| `enum` | 模式、方向、呼吸类型 |
| `string` | 颜色、名称、目标 id |
| `position` | 一个三维点；可来自九槽 |
| `selector` | 实体/玩家选择器 |
| `pose` | 编辑器侧的一组姿态值：位置 + yaw/pitch/roll + fov/zoom；可来自九槽 |
| `pose_list` | `pose` 的有序数组；用于多机位；数量由另一个参数约束，不写进脚本 |

`pose` / `pose_list` 只是模板参数类型，不进入脚本字段。展开时拆成目标片段已有的位置、朝向、光学字段。

参数规则：

- 未填取声明默认值；没有默认值且必填 → 参数错误。
- 未声明的键直接报错，不静默丢弃。
- 数值先做有限性检查，再按声明范围检查。
- 枚举只接受声明候选，不接受自由字符串。
- 位置参数只接受三维点；不把二维屏幕点当世界点。
- 选择器参数只写现有 `position_origin` / `look_at_selector` 等字段；不新造选择器语法。

## 展开契约

片段级展开输出：

```text
{
  clip: {
    id?, start_time?, duration?, loop?, loop_count?, loop_mode?,
    objects: { ... },
    exit?: { ... }
  },
  paths?: [ ... ]
}
```

轨道级展开输出：

```text
{
  track: { type, id?, name? },
  clips: [ clipFragment, ... ],
  paths?: [ ... ]
}
```

脚本级展开输出：

```text
{
  meta: { ... },
  tracks: [ trackFragment, ... ],
  triggers?: [ ... ],
  paths?: [ ... ]
}
```

约束：

- `objects` 的每个键必须是目标轨道 schema 中存在的字段；值必须是该字段允许的 `{value}` 或 `{keyframes}` 形态。
- `text`、`layer_type`、`position_mode`、`fov` 等 value-only 字段不生成 keyframes。
- `keyframes` 的 `time` 从 0 开始，单位秒，严格递增；不生成同一时间重复节点。
- 片段级模板只负责片段内部的字段；片段起点由装配器给，模板不写绝对 `start_time`（除非模板参数明确要求固定起点）。
- 轨道级模板只负责一条轨道的片段编排；不碰其他轨道。
- 脚本级模板只负责整份骨架；不碰已有文档的其他内容。
- 模板不定义曲线类型、路径端点语义、规则执行、事件语义；这些字段照 07/11 的合同写。
- 模板不写 `meta.version`、`timeline.total_duration` 或已废弃字段；`meta` 只写 schema 需要的非默认值或模板明确参数。

## 装配

装配器是模板与文档之间的唯一桥。模板只输出片段，装配器负责放进目标文档。

### 片段级装配

1. 选择目标轨道：必须与模板 `trackType` 一致。
2. 选择插入点：播放头、选中片段之后、指定时间。
3. 计算 `start_time`；默认等于插入点。
4. 检查目标轨道的重叠：新片段区间与已有片段相交时拒绝，提示“目标位置已有片段”，由作者改插入点或新建轨道；不静默挪已有片段。
5. 分配片段 id：按现有 `^[A-Za-z0-9_]{1,64}$` 规则；与文档已有 id 冲突时追加稳定后缀；被 `paths[]` 引用时必须写 id。
6. 分配路径 id：与片段 id 同一命名空间，冲突时追加后缀；`paths[].clip` 指向新片段 id。
7. 一次事务写入片段和路径；撤销一次全部回退。

### 轨道级装配

1. 目标轨道可新建，或追加到同类型轨道。
2. 新建轨道时，轨道 id 按现有 `{type小写}_{n}` 规则分配；已有同名 id 时递增。
3. 追加时，起点默认接在目标轨道最后一个有限片段的末端；不移动已有片段。
4. 模板产出的片段按顺序排布，默认首尾相接；相邻片段之间不写任何转场字段。
5. 如果任何片段与目标轨道已有内容重叠，整次装配拒绝，不生成半条轨道。
6. 轨道级模板的所有片段共享一个事务；撤销一次全部消失。

### 脚本级装配

1. 只用于新建文档或明确的“从模板新建脚本”入口；不往已有脚本里塞整份骨架。
2. `meta` 使用现有新建脚本默认值，再覆盖模板明确给出的字段；不写空触发器数组。
3. 轨道列表使用标准内置轨道；模板只改目标轨道的内容。
4. 触发器骨架只写 11 的字段：`id`、`type`、`delay`、`repeatable`、`conditions`、`continuity`。不写规则、绑定、执行状态。
5. 生成后仍走保存/校验通道；模板不直接写游戏目录。
6. 当前文档有脏改动时，先走 04/05 的未保存守卫，不静默覆盖。

## 注册表

- 内置注册表是只读列表，注册顺序即面板展示顺序。
- 三层可共用一个查找入口，但 id 必须层内唯一；推荐前缀区分。
- 注册时检查：`layer` 与 `refs` 方向、`trackType` 是否存在、参数声明是否重复键、`expand` 是否返回合法层。
- 注册失败只让该模板不可用，不阻止编辑器启动。
- 本轮不加载外部模板包、不扫描用户目录、不执行用户脚本。

## 产物归属

- 模板不持有产物；展开后立即交给装配器/文档。
- 产物是普通脚本片段，作者可以逐字段继续改。
- 模板不保留“再生成”关系；参数、模板 id、来源不写进脚本。
- 当前会话可以显示“本次生成用了哪个模板/哪些参数”，仅用于面板摘要；刷新/重开不保留，不落盘。
- 模板升级只影响新生成内容，不改已生成片段。

## 事务与选择

- 一次应用 = 一个文档事务；成功后可一次撤销。
- 失败时文档、选择、路径集合保持应用前状态。
- 成功后选择第一个生成的片段；轨道级/脚本级选择目标轨道的第一个片段。
- 选择使用 `clipKey`，不使用数组下标。
- 生成路径后，若路径端点引用了新片段位置节点，选择可定位到新路径条目。

## 字段与轨道兼容

- 片段模板声明 `trackType`；装配器不把 CAMERA 片段塞进 OVERLAY 轨。
- OVERLAY 模板只写 `overlayObjects()` 的字段；CAMERA 模板只写 `cameraObjects()` 的字段。
- `LETTERBOX` 只写 `aspect_ratio` / `opacity`；`AUDIO` 只写音频字段；`EVENT` / `MOD_EVENT` 只写事件字段。
- 模板不跨轨道复制字段；需要组合时由脚本级模板引用多条轨道模板。
- 第三方轨道如果 schema 存在，模板可按其字段生成；本轮内置模板只覆盖 CAMERA / OVERLAY / LETTERBOX。

## 与九槽的关系

模板参数中的 `position` / `pose` 可以从 12-08 的九槽取值：

- 取槽只在参数表单发生，不把槽位 id 写进模板产物。
- 展开时槽位已经被解析成具体数值；模板定义不知道槽的存在。
- 同一个模板参数可以手动填，也可以从槽位取；两者等价。
- 槽位值不合法（非有限数、缺少轴）时按参数错误处理，不生成。

## 本地校验

| 检查 | 处理 |
|---|---|
| 模板 id 重复/为空 | 注册失败；该模板不展示 |
| 参数键未声明 | 参数错误；不展开 |
| 必填参数缺失 | 参数错误；不展开 |
| 数值非有限/越界 | 参数错误；不展开 |
| 枚举值不在候选 | 参数错误；不展开 |
| `trackType` 与片段字段不匹配 | 装配前拒绝 |
| 目标轨道类型不符 | 装配前拒绝 |
| 目标区间重叠 | 拒绝；提示改插入点/新建轨道 |
| 片段 id 冲突 | 追加稳定后缀；不覆盖已有 |
| 路径端点不匹配位置节点 | 校验错误；不写入半条路径 |
| 产物字段不在 schema | 生成错误；不装配 |
| 产物 value-only 字段带 keyframes | 生成错误；不装配 |
| 产物带片段级 `transition` | 生成错误；不装配 |
| 最终 `script.validate` 失败 | 整次应用回滚；诊断定位到模板/参数/片段 |

## 完成定义

- 三层模型、参数声明、展开、装配、注册表、事务边界完整。
- 模板产物与手写脚本同构，能过现有校验器。
- 模板不写运行时模板字段、不写片段级转场、不写字幕不存在的样式字段。
- 失败零残留；撤销一次回退。
- 本轮只注册内置模板；纯数据模板留给后续层。
