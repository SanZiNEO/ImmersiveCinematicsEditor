# 模板面板

> 状态：未实现
> 范围：`templates` 抽屉面板的层选择、模板列表、参数表单、结构摘要、插入目标、生成前 diff 与错误呈现
> 关联：12-01 装配与事务、12-02 嵌套错误、12-07 快捷效果、12-08 九槽选择器、12-11 诊断、04 抽屉、06 控件

## 一、摘要

模板面板是模板能力的唯一入口：选层、选模板、填参数、看结构摘要、看生成前 diff、选插入目标、一次生成。它只做入口与参数，展开、装配、校验分别归 12-01、12-02、12-11。面板不画预览图，也不保留"这段是模板生成的"这种来源关系。

## 二、为什么做

### 2.1 问题

模板一旦只有参数没有入口，作者就得记住模板 id 和参数名，等于把"参数化生成"退化成"背文档"。而入口做得太自由又会出别的问题：如果面板提供"添加属性""重新生成""同步模板"这类按钮，作者会以为产物与模板保持关联，于是手改之后再点一次，改动就没了；如果面板画一张最终画面预览，作者会把它当游戏结果，然后在真实播放时发现字体宽度、遮罩、合成都对不上。

参数本身也需要约束：越界、缺必填、枚举写自由字符串，这些错误如果只在生成后由脚本校验器报出来，作者看到的是字段路径，不是"我哪个参数填错了"。

### 2.2 目标

- 作者不用记模板 id：按层浏览、按标题与一句话说明选。
- 参数错误在字段旁直接说清，生成按钮禁用，不用弹窗打断。
- 生成前能看到将发生什么：几个片段、几条轨道、几条路径、几个触发器、是否有冲突。
- 生成后能继续编辑产物，且找不到任何"回到模板"的路径。
- 生成失败时文档、选择、参数草稿都不受影响。

### 2.3 非目标

- 不在面板里做展开、装配或最终校验。
- 不画假预览图、假时间轴缩略图、假游戏画面。
- 不把参数或槽位 id 写进脚本。
- 不提供"再生成/同步/更新模板产物"。
- 不做纯数据模板或模板包导入。
- 不新增第二个模板入口：菜单、右键菜单、旧预设面板都不出现。
- 不改 04 的抽屉容器与 05 的主轴。

## 三、方案

面板挂在文档抽屉的模板页签，单例、切页保活。关闭再打开时保留当前层、选中模板、参数草稿与滚动位置，但不保留"加载中"这类假状态。

上层是层切换（片段、轨道、脚本），左侧是该层的模板列表，右侧是参数表单与摘要。列表每项显示标题、一句话说明、目标轨道类型和可用状态；不可用的模板置灰并在行内说明原因——参数不完整、目标轨道类型不存在、当前文档没有可用的目标轨道。列表不显示缩略图。选中模板后参数表单按该模板的声明重建，不保留上一个模板的参数。

参数控件复用 06 的既有约定：数值输入带单位、开关、只列声明候选的枚举、带十六进制校验的颜色输入、三轴位置输入、姿态组输入、可增删排序的姿态列表、带提示的选择器输入。必填参数标注并在缺失时禁用生成；数值先查有限性再查范围；范围错误贴在字段下方，不用浮层提示。

位置、姿态与姿态列表旁边有"从槽位取"，打开九槽选择器并把值填进当前参数——位置只填位置，姿态填位置与朝向与光学，列表填当前行。槽位 id、序号、来源都不进产物，展开时只剩数值；槽位值非法按参数错误处理。

结构摘要只写事实：将生成几个片段、几条轨道、几条路径、几个触发器，总时长与每段时长，目标轨道类型，关键节点数与路径条数，是否带黑场/遮幅/呼吸，是否会新建轨道，是否与已有片段冲突。对脚本模板还要说清是否新建文档、是否带触发器骨架。摘要随参数实时更新，不承诺最终画面。

插入目标按层给不同选项。片段级可以在播放头、选中片段之后、指定时间三处插入，目标轨道只列与模板轨道类型一致的轨道，区间冲突时显示冲突片段并禁用生成。轨道级可以新建轨道或追加到同类型轨道，追加时起点接在该轨道最后一个有限片段末端，没有片段时用播放头。脚本级只能新建文档，或在当前文档为空且无未保存改动时替换。

点生成前显示一次结构 diff：新片段的数量、轨道、起点、时长；新轨道的类型与片段数；新路径的条数与所属片段；新触发器的数量与类型；以及所有冲突。确认后一次提交，取消不改文档、不改选择、不写草稿。生成完成后状态区给一行结果与撤销提示，选中第一个生成片段，参数表单保留本次值以便再生成一次——再生成是全新事务，不改上一次产物。

## 四、技术细节

### 4.1 核心模型

面板自己只持有视图状态：当前层、选中模板 id、参数草稿、滚动位置、摘要与 diff 结果。模板定义、展开产物、装配结果都不在面板里保存；文档修订号变化时重新取目标轨道与冲突信息。

### 4.2 契约

面板通过 04 的面板上下文取命令、选择、文档修订与宿主端口，不直接操作文档存储。所有写入经命令层，失败由命令层回滚，面板只负责显示结果。参数草稿不写脚本；切换模板或关闭面板不自动提交。

### 4.3 数据形态

参数草稿以模板 id 为键存放，切模板时按声明重建。摘要与 diff 是从草稿与目标文档现算的派生结果，不持久化。生成后的产物就是标准片段、轨道、路径与触发器骨架，面板不额外写任何元数据。

### 4.4 边界

面板加载失败只影响模板页签，显示失败原因与重试入口，其他面板正常。断连或未连接时生成本地可做，保存与推送按现有宿主端口提示，不伪造"已保存/已推送"。快捷效果条放在面板顶部，条目与来源由 12-07 定义，同样走模板注册表与同一套 diff、事务、选择流程，不跳过参数校验。

## 五、为什么不选别的

| 备选方案 | 做法 | 代价 | 为什么没选 |
|---|---|---|---|
| 独立模板工作区 | 新开一个页面专门放模板 | 与文档选择、目标轨道分离，需要跨页同步 | 模板生成天然依赖当前文档与选择 |
| 生成后保留来源与再生成 | 产物记住模板与参数，可一键重建 | 手改会被覆盖；冲突无法自动判定 | 产物即普通脚本是硬边界 |
| 参数错误用浮层提示 | 生成时统一弹窗列出所有错误 | 打断输入，且错误与字段分离 | 字段旁红字更贴近"改哪个参数" |
| 面板内画最终画面预览 | 用编辑器渲染近似游戏画面 | 字体测量、遮罩、合成都无法忠实复现 | 会变成假预览，误导作者 |
| 直接生成不显示 diff | 点按钮立即写入文档 | 冲突与错误在写入后才暴露 | 结构 diff 成本低，能提前拦住冲突 |

**本方案的缺点**：

- 参数表单要覆盖八种参数类型，表单本身较复杂，首次使用需要读文案。
- 结构摘要与展开逻辑是两处实现，可能出现摘要说一套、生成另一套。
- 摘要是文字描述，作者想确认视觉效果仍要生成后到游戏里看。

### 验收要点

- 打开模板页签能看到层切换、模板列表、参数表单、摘要、插入目标与生成按钮，且找不到任何预览图或添加属性入口。
- 参数越界或缺失必填时字段旁给出红字，生成按钮禁用，不弹浮层。
- 修改参数后摘要实时更新片段数、路径数、时长与冲突信息。
- 插入"选中片段之后"时起点等于选中片段末端；与后续片段冲突时禁止生成且不覆盖。
- 从九槽取姿态后生成，脚本里没有槽位 id 或模板 id。
- 生成后不显示来源与再生成入口；取消 diff 时文档、选择、草稿都不变。
- 关闭再打开页签时参数草稿与滚动位置保留；重开文档时重置。
