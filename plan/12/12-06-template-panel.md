# 12-06 模板面板

## 目标

在 04 已保留的 `templates` 抽屉槽里放模板面板：选层、选模板、填参数、看结构摘要、看生成 diff、选插入目标、一次生成。

面板只做入口和参数，不做展开数学、不做装配、不做最终校验。展开/装配/校验分别由 12-01、12-02、12-11 负责。

## 位置与容器

- 面板挂在 `document.drawer` 的 `templates` 页签；keepAlive=true。
- 不新开工作区页面，不做独立窗口，不做第二个模板入口。
- 面板通过 04 的 `PanelContext` 取命令、选择、文档修订和宿主端口；不直接 import 文档 store，不直接改 `state.doc`。
- 模板面板关闭再打开保留当前层、选中模板、参数草稿、滚动位置；不保留“加载中”假状态。

## 布局

```text
[层: 片段 | 轨道 | 脚本]
[模板列表]                 [参数表单]
  · 环绕弧                  位置 / 朝向 / 光学 / 时间
  · 推近                    半径 [8] 块
  · 固定 + 呼吸             起始角 [0] °
  ...                       ...
                            [结构摘要]
                            [插入目标] [生成]
```

### 模板列表

- 按层分组；当前层只显示该层模板。
- 每项显示标题、一句话说明、目标轨道类型、可用状态。
- 不可用模板置灰，并在行内显示原因：参数不完整、目标轨类型不存在、当前文档没有目标轨道。
- 列表不显示“预览缩略图”或“假游戏画面”。
- 选中模板后，参数表单用该模板的声明重建；不保留上一个模板的参数。

### 参数表单

按参数声明的 `section` 分组；没有分组时按声明顺序。

控件复用 06 约定：

| 参数类型 | 控件 |
|---|---|
| `float` / `int` | 数值输入，Enter 提交、Esc 还原；显示单位 |
| `bool` | 开关 |
| `enum` | 下拉/分段按钮；只列声明候选 |
| `string` | 文本输入；颜色显示色块与十六进制校验 |
| `position` | 三轴输入；旁边有“从槽位取” |
| `pose` | 位置 + yaw/pitch/roll + fov/zoom 一组输入；旁边有“从槽位取” |
| `pose_list` | 行列表；每行一组 pose；支持添加/删除/上移/下移；每行可“从槽位取” |
| `selector` | 文本输入 + 现有选择器提示；不做实体选择器弹窗 |

规则：

- 必填参数标 `*`；缺必填时生成按钮禁用，字段下方红字。
- 数值先做有限性，再做范围；范围错误贴在字段下方，不用 toast。
- `position` 只接受三维点；缺轴/非有限数报错。
- `pose` 的 fov 按 1–179；zoom >0；yaw/pitch/roll 度。
- `pose_list` 的行数由另一个参数（如 `shots`）约束；不一致时汇总区提示。
- 参数默认值来自模板声明，不来自 schema 默认值；只有模板明确写出的字段才进产物。
- 参数草稿不写脚本；切换模板/关闭面板不自动提交。

### 从九槽取

- `position` / `pose` / `pose_list` 行旁有“从槽位取”按钮。
- 打开 12-08 的九槽选择器，选一个槽；把槽的姿态填进当前参数。
- 只填当前参数需要的字段：`position` 只填位置；`pose` 填位置+朝向+光学；`pose_list` 填当前行。
- 槽位 id、槽位序号、来源不进模板产物；展开时只剩数值。
- 槽位值非法时按参数错误处理，不生成。

### 结构摘要

摘要只写事实，不画画面：

- 将生成几个片段、几条轨道、几条路径、几个触发器。
- 总时长、每段时长、目标轨道类型。
- 关键节点数量、路径条数、是否有 `paths[]`。
- 是否有黑场/遮幅/呼吸；不承诺最终画面。
- 是否会产生新轨道；是否与已有片段冲突。
- 对脚本模板：是否新建文档、是否带触发器骨架、是否带规则（本轮不带）。

摘要随参数实时更新；不显示“预计像素效果”或“游戏最终画面”。

## 插入目标

### 片段级

| 选项 | 语义 |
|---|---|
| 播放头 | 起点 = 当前播放头 |
| 选中片段之后 | 起点 = 选中片段结束时间 |
| 指定时间 | 作者填秒数；必须是有限非负数 |

- 目标轨道只列与模板 `trackType` 一致的轨道。
- 目标区间与已有片段重叠 → 显示冲突片段，生成按钮禁用；作者改插入点或新建轨道。
- 不自动挪已有片段，不自动拆轨。

### 轨道级

| 选项 | 语义 |
|---|---|
| 新建轨道 | 按 `{type小写}_{n}` 分配 id；默认 CAMERA |
| 追加到同类型轨道 | 起点 = 目标轨道最后一个有限片段末端 |

- 追加时显示目标轨道的末片段；没有片段时用播放头。
- 与已有片段重叠 → 拒绝。
- 不自动改变轨道顺序，不自动重命名轨道。

### 脚本级

| 选项 | 语义 |
|---|---|
| 新建文档 | 用模板生成整份骨架；当前文档脏时先走未保存守卫 |
| 替换当前空文档 | 仅当前文档为空、无未保存改动时可用；否则禁用 |

- 不把脚本模板塞进已有非空文档。
- 新建文档后走现有保存/推送通道；不直接写游戏目录。
- 生成后自动打开新文档并选中第一个片段。

## 生成前 diff

点“生成”前显示一次结构 diff：

- 新片段：数量、轨道、起点、时长、id（若已分配）。
- 新轨道：类型、id、片段数。
- 新路径：条数、所属片段、端点时间。
- 新触发器：数量、类型。
- 冲突：目标区间重叠、轨道类型不符、id 冲突、参数错误。
- 不显示像素预览；不声称“最终画面已生成”。

确认后一次提交；取消不改文档、不改选择、不写草稿。

## 生成后

- 状态区一行：“已生成 N 片段 · M 路径 · 撤销 Ctrl+Z”。
- 选中第一个生成片段；脚本模板选中第一条非空轨道的第一片段。
- 不显示“查看来源/重新生成/同步模板”；本轮不保留来源。
- 参数表单保留本次值，方便作者再生成一次；再次生成是全新事务，不改上一次产物。
- 不把模板 id、参数、生成时间写进脚本或文档元数据。

## 错误与诊断

- 参数错误：字段下方红字 + 汇总区；生成按钮禁用。
- 展开错误：汇总区显示模板 id、引用链、错误码；不打开半成品。
- 装配错误：显示目标轨道、区间冲突、id 冲突；文档不变。
- 最终校验错误：显示 issue 路径，定位到模板参数或目标片段；整次回滚。
- 面板加载失败：只影响 `templates` 页签，显示“加载失败 + 原因 + 重试”；其他面板正常。
- 断连/未连接：生成本地可做；保存/推送按现有宿主端口提示，不伪造“已保存/已推送”。

## 快捷效果

- 面板顶部保留快捷效果条，具体条目和来源由 12-07 定义。
- 快捷效果只调用同一模板注册表；不写第二套参数、不在面板里硬编码效果数学。
- 快捷效果生成后同样走 diff/事务/选择；不跳过参数校验。

## 禁止项

- 不在面板里展开模板、不装配、不校验。
- 不画假预览图、假时间轴缩略图、假游戏画面。
- 不把参数写进脚本，不把槽位 id 写进脚本。
- 不提供“再生成/同步/更新模板产物”。
- 不做纯数据模板/模板包导入。
- 不新增第二个模板入口（菜单、右键、旧 `PresetsPanel` 都不出现）。
- 不改 04 抽屉容器和 05 主轴。

## 验收出口

1. 选 `clip.orbit_arc`，改半径 8→12：摘要更新片段数/路径数；生成后游戏内半径变大。
2. `sweep=130`：字段下方红字“最大 120°”，生成按钮禁用。
3. 插入“选中片段之后”：起点等于选中片段末端；与后续片段冲突时禁止，不覆盖。
4. 选 `track.multi_cam`，`poses` 从九槽填 2 行；摘要显示 2 片段；生成后是硬切，没有转场字段。
5. 选 `script.camera_intro`，`black_fade=2`；新建文档后 CAMERA+LETTERBOX+OVERLAY 三轨；游戏内片头黑场消失。
6. 生成后不显示来源/再生成；脚本里没有模板 id/参数/槽位 id。
7. 参数错误只在字段/汇总区提示，不弹 toast；取消不改文档。
8. 关闭再打开 `templates` 页签，参数草稿和滚动保留；不显示假加载。
