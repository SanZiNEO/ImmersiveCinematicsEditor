# 12-12 字幕导入

## 目标

把 `.srt` / `.vtt` 字幕文件解析成编辑器里的字幕 cue，再由 12-14 编译成标准脚本里的字幕片段。导入只读文本和时间，不解析样式，不生成第二套字幕格式。

## 输入与文件端口

- 支持 `.srt`、`.vtt`；其他扩展名拒绝。
- 文件选择/读取走编辑器主进程新增的字幕文件端口，例如 `openSubtitle` / `readSubtitle`；该端口只选字幕文件并返回路径、文件名、字节/文本，不做任意路径读取。
- 这不改模组协议，不新增游戏消息；字幕最终仍是脚本里的 OVERLAY 字幕片段。
- 不把本地路径写进脚本；不把字幕文件复制进工程目录/资源包。
- 拖放不是必需入口；如果做，走同一读取端口，不绕过扩展名/编码检查。

## 解析

### SRT

- 块之间用空行分隔。
- 时间行：`HH:MM:SS,mmm --> HH:MM:SS,mmm`；小时可超过两位，毫秒 1–3 位按毫秒补齐。
- 序号行可省略；有则忽略。
- 时间行后的非空行是文本；多行用 `\n` 保留。
- 空文本、结束时间 ≤ 开始时间、时间行缺失 → 该 cue 标记 error，不静默丢；导入预览显示并可跳过。
- 不解析字体/颜色/位置标签；`<i>`、`<b>`、`<font ...>` 等按“去标记”处理并提示。

### VTT

- 首行 `WEBVTT`；允许 BOM/前导空行。
- `NOTE`、`STYLE`、`REGION` 块跳过，不进入 cue。
- cue 行：`[id]` 可选，时间行 `HH:MM:SS.mmm --> HH:MM:SS.mmm`；也接受 `MM:SS.mmm`。
- 时间行后的 cue 设置（如 `line:`、`position:`、`align:`、`size:`）整段忽略，并计数提示“VTT 设置不支持”。
- cue 文本多行保留；`<v Speaker>`、`<c.class>`、`<ruby>` 等标记去掉，只留可读文本。
- `&amp;` / `&lt;` / `&gt;` / `&quot;` / `&#39;` 解码；其他实体原样保留并提示。
- `WEBVTT` 后无 cue → error，不生成空批次。

### 时间

- 内部统一用秒（float，毫秒精度足够）；不引入帧率换算。
- 导入偏移 `offset` 秒：可正可负；加完后 start < 0 的 cue → 标记 error，作者选择跳过/裁到 0；不静默改时间。
- 结束时间必须 > 开始时间；相等/倒置 → error。
- 不按 fps 重采样；不把 23.976/25/30fps 的差异“自动修正”。
- 时间精度保留到毫秒；显示时按 `mm:ss.mmm`。

### 文本

- 文本按原文件换行保留；不自动换行、不自动折行、不按字数切分。
- 去标记后如果文本为空 → warning/跳过，不生成空字幕片段。
- 实体解码只做一次；不重复解码 `&amp;lt;`。
- 不把 HTML/VTT 样式转成字幕字段；字幕只有固定白色文字、字号、位置、锚点、缩放、透明度、层级。

### `@lang:` 转义

运行时 `text` 以 `@lang:` 开头会查语言表；外部字幕的 `@lang:` 是普通文本，必须转义：

- 文本以单个 `@lang:` 开头 → 写成 `@@lang:`，运行时显示字面 `@lang:`。
- 文本以 `@@lang:` 开头 → 运行时只会显示 `@lang:`；无法用现有语法保留双 `@` 字面。导入预览给 warning，作者可改写或接受。
- 只处理开头；正文中间的 `@lang:` 不触发语言表，原样保留。
- 不把外部字幕当语言 key；不查询语言表、不把译文写进 `text`。
- 转义开关默认开；关闭时提示“运行时可能查语言表”。

## 导入向导

### 步骤

1. 选文件。
2. 解析结果：文件类型、编码、cue 数、warning/error 数。
3. 预览表：序号、起止、时长、文本、状态。
4. 选项：
   - 时间偏移（秒）；
   - `@lang:` 转义（默认开）；
   - 去 HTML/VTT 标记（默认开）；
   - 实体解码（默认开）；
   - 编码（自动失败时显示）。
5. 目标：选已有字幕轨道，或新建字幕轨道。
6. 冲突预览：与目标轨道已有 cue 的重叠、重复文本、将被跳过的 cue。
7. 确认导入（生成 cue 草稿；不直接写文档）。

### 预览表

- 每行显示：序号、开始、结束、时长、文本首行、文本行数、状态。
- 状态：`ok` / `warning` / `error` / `skip`。
- 文本可展开看全文；保留 `\n`。
- 不显示样式预览、不画最终字幕画面。
- 可勾选“跳过”单条 cue；error 默认不勾选。
- 显示总 cue 数、总时长范围、重叠 cue 数。

### 编码

- 优先 UTF-8（含 BOM）。
- 有 UTF-16 LE/BE BOM 时按 UTF-16 解码。
- 无 BOM 且严格 UTF-8 解码失败 → 弹编码选择：`UTF-8` / `GB18030`；不静默用系统默认编码。
- 仍失败 → error，显示“无法解码”，不猜测。
- 解码失败不把半份文本塞进预览。

### 目标轨道

- 已有字幕轨道：只列 `OVERLAY` 且已有/可判定为字幕片段的轨道；轨道显示 id、cue 数、时间范围。
- 新建轨道：按 `overlay_{n}` 分配；类型 `OVERLAY`。
- 一个批次可以选多条字幕轨道；导入时按重叠把 cue 分配到这些轨道，或按 12-13 的轨道打包规则新建。
- “批次”就是作者选定的字幕轨道集合；不创建 sidecar，不创建第二套字幕 JSON。

## 导入后的状态

- 导入向导只产出**cue 草稿**：内存表 + 目标轨道 + 选项；不立刻改文档。
- 确认后由 12-14 编译：一 cue 一片段；一次事务；失败零残留。
- 草稿可以取消；取消不写文档、不写轨道、不写临时文件。
- 不自动保存字幕文件副本；不在工程目录生成 `.srt`/`.vtt`/`.json` 伴随文件。
- 导入日志只在当前会话；不写入脚本。

## 与现有字幕字段的关系

导入只产生以下目标字段：

- `layer_type=subtitle`
- `text`
- `x/y`
- `anchor_x/anchor_y`
- `scale_x/scale_y`
- `font_scale`
- `opacity`
- `z_index`

不产生：

- 颜色、字体族、描边、背景框、对齐、富文本、逐字动画。
- `source.*`、`path`、`gradient`、`mask_*`、`blend_mode`。
- `text` 关键帧；`text` 是 value-only。
- 第二套字幕轨道/图层类型。

## 禁止项

- 不解析 ASS/SSA、不解析卡拉 OK 标签、不做字幕样式转换。
- 不自动换行、不自动按字符数切分、不自动翻译。
- 不按 fps 自动换算时间。
- 不静默丢 cue、不静默改时间、不静默去重。
- 不把 `@lang:` 原样写入 `text` 让运行时误查语言表。
- 不建 sidecar、不建工程内字幕副本、不写第二套字幕 JSON。
- 不改模组协议、不新增字幕网络消息。

## 验收出口

1. 导入 3 条 SRT：预览 3 条；确认后生成 3 个字幕片段；文本换行保留；`text` 是 value。
2. 导入 VTT：`NOTE`/`STYLE` 跳过；`align:`/`line:` 设置忽略并提示；cue 文本正确。
3. SRT 文本含 `<i>hello</i>`：去标记后为 `hello`，预览 warning 计数。
4. 文本以 `@lang:subtitle.one` 开头：写入 `@@lang:subtitle.one`；游戏内显示字面 `@lang:subtitle.one`，不查语言表。
5. 文本以 `@@lang:subtitle.one` 开头：预览 warning；作者可改写，不静默改。
6. 负偏移导致 start<0：该 cue error，默认不勾选；不生成负时间片段。
7. 结束时间 ≤ 开始时间：error；不生成零时长/倒置片段。
8. 无 BOM 非 UTF-8：出现编码选择；选 GB18030 后文本正确；取消不写文档。
9. 导入只产 cue 草稿；确认前文档不变；取消无残留；工程目录没有 sidecar。
10. 字幕字段只出现 09-05 字段面；没有颜色/字体/描边/对齐字段。
