# 12-02 模板嵌套与展开

## 目标

让脚本级模板引用轨道级模板、轨道级模板引用片段级模板，并规定参数逐层传递、实例 id、命名空间、深度与环检测、失败回滚。

嵌套只发生在编辑器展开期。保存后的脚本里没有模板 id、引用链、命名空间或参数；只有最终片段、路径、轨道和字段。

## 引用声明

模板定义可以带 `refs`。一条引用至少包含：

| 字段 | 含义 |
|---|---|
| `template` | 被引用模板 id；必须严格低于当前层 |
| `params` | 传给下层的参数绑定 |
| `repeat` | 可选：生成几个实例；缺省 1 |
| `indexVar` | 可选：实例索引变量名，只在当前 `repeat` 内有效 |
| `placement` | 可选：本层如何放置这些实例；缺省顺序追加 |

参数绑定只有三种：

1. **常量**：`{ const: 值 }`。
2. **上层同名参数**：`{ from: "参数名" }`；只能引用当前层已声明的参数，不跨层跳取。
3. **已登记派生**：`{ derive: "arc-split", ... }` 等引擎内置的封闭派生。本轮只登记实际模板需要的派生；不执行任意表达式、不 `eval`、不访问未声明变量。

不允许的绑定：

- 引用上层两层以上的参数。
- 用数组下标、片段 id、运行时状态作为参数。
- 字符串模板表达式、函数、正则或用户输入代码。
- 把槽位 id 写进参数；九槽取值必须在表单层先解析成数值。

## 逐层传参

- 脚本模板声明自己的参数；引用轨道模板时，只把脚本层已声明的参数或常量传下去。
- 轨道模板声明自己的参数；引用片段模板时，只把轨道层已声明的参数或常量传下去。
- 下层未声明同名参数时，`from` 报错，不静默透传。
- 上层参数默认值只在上层解析一次；下层拿到的已是归一后的值。
- 下层可以覆盖自己的默认值，但不能读取上层未声明的变量。
- 参数对象在展开期只读；展开函数不得修改传入的参数。

## 实例与命名空间

每次引用展开生成一个实例命名空间：

```text
<模板短 id>_<实例序号>
```

例如 `orbit_arc_0`、`orbit_arc_1`。命名空间只用于展开期分配最终 id，不写进脚本。

最终 id 规则：

- 片段 id：`^[A-Za-z0-9_]{1,64}$`，与文档已有 id 去重；冲突时追加 `_2`、`_3`。
- 轨道 id：沿用 `{type小写}_{n}`；同类型多条轨道递增。
- 路径 id：与片段 id 同一命名空间；冲突时追加稳定后缀。
- 规则/绑定 id：如果脚本模板生成了骨架，也按现有 id 规则分配；不另造一套。
- 命名空间字符串不能出现在保存后的 JSON 的任何字段里。
- 不能用数组下标作为跨层引用；选择、路径、规则都用最终 id 或 `clipKey`。

`repeat` 规则：

- `repeat.count` 必须是整数，1–64。
- 单次展开总实例数上限 512；超过整次展开失败。
- `indexVar` 只在当前实例内可见；不能泄漏到同级或父层。
- 每个实例的参数独立；不共享可变对象。
- 实例顺序按引用声明顺序和 `repeat` 索引递增；不按数组下标重排。

## 深度与环

- 最大深度 3：脚本 → 轨道 → 片段。
- 引用目标层必须严格低于当前层；否则 `E_NEST_DIRECTION`。
- 展开栈中出现重复模板 id → `E_NEST_CYCLE`，错误信息给出 `a → b → a`。
- 深度超过 3 → `E_NEST_DEPTH`。
- 单次展开实例数超过 512 → `E_NEST_LIMIT`。
- 环检测不靠深度上限代替；即使层数未超，重复 id 也要报环。
- 同一模板被多个父引用不算环；只有当前展开栈里重复才算。

## 展开顺序

1. 校验当前模板参数。
2. 先展开本层自有内容（如果有）。
3. 按 `refs` 顺序展开下层实例。
4. 每个实例分配命名空间和最终 id。
5. 合并本层内容与下层内容；片段/轨道按声明顺序排列。
6. 检查总实例数、id 冲突、目标轨道类型。
7. 返回扁平化后的片段/轨道/脚本片段；装配器只做放置，不再理解模板层级。

## 失败与回滚

- 参数错误：不开始展开。
- 引用方向/深度/环/实例数错误：整次展开失败，不生成半份内容。
- 某个下层实例失败：整条引用链失败；不回滚已经生成的其他引用的内存对象，因为它们尚未写入文档。
- 装配阶段失败：文档不变；展开草稿丢弃。
- 最终校验失败：整次应用回滚；诊断定位到模板 id、引用链、参数名或目标片段。
- 失败信息不吞掉下层错误；最多保留一条根因链，避免重复刷屏。

## 与各层模板的关系

### 脚本级

- 脚本模板可以引用多条轨道模板，每条轨道模板生成一条轨道。
- 脚本模板可以内联少量 meta/triggers 骨架，不引用轨道模板。
- 脚本模板需要单轨起手式时，可以使用内部轨道组合器：组合器调用片段模板的 `expand`，只做轨道 id/起点/顺序，不复制片段数学；它不注册成用户可见模板，但仍属轨道级装配，遵守只向下组合。
- 引用轨道模板时传 `trackType` 必须与轨道模板一致；不一致报错。
- 脚本模板不引用另一个脚本模板；本轮不做脚本嵌套脚本。

### 轨道级

- 轨道模板按顺序引用片段模板；每个片段实例有独立参数。
- 轨道模板可以内联一个片段（不引用），但内联片段仍走同一装配校验。
- 轨道模板不引用另一个轨道模板；需要组合时由脚本模板引用多条轨道模板。
- 轨道模板不横向引用同层其他轨道模板。

### 片段级

- 片段模板是最底层，没有 `refs`。
- 片段模板可以生成多条 `paths[]` 条目，但都只属于本片段。
- 片段模板不引用其他片段模板；需要多段时由轨道模板重复引用。

## 示例：环绕整圈

`track.orbit_full` 引用 `clip.orbit_arc` 三次：

```text
orbit_full
  refs:
    - template: clip.orbit_arc
      repeat: 3
      params:
        center: { from: "center" }
        radius: { from: "radius" }
        height: { from: "height" }
        start_angle: { derive: "arc-split", index: 0 }
        sweep: { derive: "arc-split", angle: 120 }
        duration: { derive: "arc-split", total: 12 }
```

展开后得到三个片段实例，命名空间分别为 `orbit_arc_0/1/2`；最终片段 id 由装配器分配。三个实例各带一条 `paths[]`，路径端点分别落在各自片段的位置节点上。模板不计算片段间转场，片段首尾相接。

## 本地校验

| 检查 | 级别 | 处理 |
|---|---|---|
| 引用目标层高于当前层 | error | 拒绝展开 |
| 引用同层/横向 | error | 拒绝展开 |
| 引用 id 不存在 | error | 拒绝展开 |
| `from` 引用未声明参数 | error | 拒绝展开 |
| `repeat.count` 非整数/越界 | error | 拒绝展开 |
| 总实例数 > 512 | error | 拒绝展开 |
| 展开栈重复 id | error | 报环路径 |
| 深度 > 3 | error | 拒绝展开 |
| 最终 id 冲突 | 自动处理 | 追加后缀；不覆盖 |
| 命名空间写入产物 | error | 生成失败 |
| 产物含模板 id/参数/来源 | error | 生成失败 |

## 完成定义

- 三层引用、逐层传参、命名空间、id 分配、深度/环/实例数检测完整。
- 展开失败零残留；成功时产物只有标准脚本字段。
- 轨道模板不复制片段模板的数学；脚本模板不复制轨道模板编排。
- 不执行任意表达式，不读取运行时状态，不写 namespace 到脚本。
- 纯数据模板不进入本轮；引用机制只服务内置模板。
