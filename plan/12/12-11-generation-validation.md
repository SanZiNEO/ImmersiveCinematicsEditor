# 12-11 生成物校验与诊断

## 目标

给模板、几何、曲线三类生成物定义统一的校验链：参数校验 → 展开结构校验 → 装配校验 → 最终脚本校验。生成物必须是标准脚本；校验权威仍是模组脚本校验器，12 不造第二套语义校验器。

## 校验层级

```text
1. 模板参数校验
2. 展开结构校验
3. 装配校验
4. 最终 script.validate
```

任何一层 error 都阻止写入；warning 允许继续，但必须显示；info 只提示，不阻止。

### 1. 参数校验

- 参数键必须在模板声明里；未声明键报错。
- 必填参数必须存在；缺省取声明默认值。
- 数值必须有限；再做范围/单位检查。
- 枚举值必须在候选里。
- 位置三轴齐全；`pose` 的位置/角度/光学齐全；`pose_list` 行数与 `shots` 等约束一致。
- 颜色必须是六位十六进制；selector 不能为空。
- 参数错误定位到模板 id + 参数键；不开始展开。

### 2. 展开结构校验

- 产物层必须与模板声明一致（`clip`/`track`/`script`）。
- 片段 `objects` 的键必须存在于目标轨道 schema。
- 字段模式必须匹配：
  - value-only 字段不能带 `keyframes`。
  - animated 字段可写 `{value}` 或 `{keyframes}`。
  - 事件记录、结构体字段按 schema 形态写。
- `keyframes` 时间必须有限、非负、严格递增；不能出现同一时间重复节点。
- 路径条目：
  - `clip` 必须指向本模板生成的片段；
  - `from/to` 必须命中位置节点时间并集的相邻节点；
  - `axes` 非空，元素在 `x/y/z` 内；
  - `geometry.type` 在当前 `curveTypes` 内；
  - `control_points` 是 `{x,y,z}` 或 `{dx,dy,dz}` 对象，不是数组；
  - `timing` 类型/点集合法。
- 轨道类型与片段字段匹配：CAMERA 片段不写 OVERLAY 字段，反之亦然。
- 产物不能出现模板 id、参数、槽位 id、命名空间、来源、生成时间。
- 产物不能出现片段级 `transition` / `transition_duration` / `transition_curve` / `transition_params` / `transition_interrupt`。
- 产物不能出现 `meta.version`、`timeline.total_duration`、空 `triggers: []`。
- 产物不能出现 schema 不存在的字幕样式字段（颜色/字体族/描边/背景/对齐）。

### 3. 装配校验

- 目标轨道存在且类型匹配。
- 目标区间与已有片段不重叠。
- 轨道级模板的片段顺序、起点、时长一致；没有隐式重叠。
- 脚本模板新建文档时，meta/轨道/触发器结构完整；不覆盖非空文档。
- id 分配后无冲突；路径引用指向最终片段 id。
- 一次装配一个事务；任一片段失败整次回滚。

### 4. 最终脚本校验

- 生成/装配后，把标准脚本交给现有脚本校验器。
- 校验器返回的 issue 按现有级别处理：
  - 只有 `[警告]` 前缀算 warning；
  - 其余 issue 一律 error；
  - info 不阻止。
- error → 不写入、不推送；显示 issue 路径。
- warning → 允许写入，但面板/诊断显示；不自动改值。
- 最终校验失败不能只显示“模板生成失败”；必须定位到 `meta` / 轨道 / 片段 / 字段 / 路径 / 触发器。

## 模板专项校验

| 检查 | 级别 | 处理 |
|---|---|---|
| 模板 id 重复/为空 | error | 该模板不可用 |
| 参数键未声明 | error | 不展开 |
| 参数越界/非有限 | error | 不展开 |
| `pose_list` 行数不匹配 | error | 不展开 |
| 引用方向错误/环/深度/实例数 | error | 不展开 |
| 目标轨类型不符 | error | 不装配 |
| 片段区间重叠 | error | 不装配 |
| 片段 id 冲突 | 自动 | 追加后缀；不覆盖 |
| 路径端点不匹配 | error | 不装配 |
| 产物含模板字段/来源 | error | 生成失败 |
| 产物含片段级转场 | error | 生成失败 |
| 产物 value-only 带关键帧 | error | 生成失败 |
| 最终 `script.validate` error | error | 整次回滚 |

## 几何专项校验

| 检查 | 级别 | 处理 |
|---|---|---|
| `base_resolution.w/h` 非正整数 | error | 拒绝提交 |
| `source.w/h<=0` | error | 拒绝；运行时不绘制/异常 |
| `scale_x/y<=0` | warning | 提示“运行时不绘制/可能翻转”；不自动改 |
| `dest`/`source` 超出 0–1 | warning | 提示可能裁切/溢出；允许保存 |
| 非等比 scale | warning | 提示拉伸；不自动修正 |
| 素材原始像素未知 | info | 只做比例示意；不猜尺寸 |
| CAMERA `dest/source` 被套用 k | error | 生成错误；两套公式分开 |
| 字幕使用不存在样式字段 | error | 拒绝 |
| 多片段隐式批改 | error | 不做 |

## 曲线专项校验

| 检查 | 级别 | 处理 |
|---|---|---|
| `geometry.type` 不在 `curveTypes` | error | 拒绝 |
| `control_points` 是数组/缺键 | error | 拒绝 |
| `axes` 为空/含非法轴 | error | 拒绝 |
| `from/to` 不在位置节点并集 | error | 拒绝 |
| `from/to` 不相邻 | error | 拒绝 |
| `timing.points` 少于 2 点 | error | 拒绝 |
| `timing.points` 首尾不是 0/0、1/1 | error | 拒绝 |
| `timing.points` 的 `t` 递减/重复 | error | 拒绝 |
| 重采样写成位置关键帧 | error | 拒绝 |
| 近似积分被声称与运行时一致 | error | 文案/诊断错误 |
| 控制点拾取在不可用片段上执行 | error | 禁用并提示 |

## 诊断结构

每条诊断至少包含：

| 字段 | 含义 |
|---|---|
| `severity` | `error` / `warning` / `info` |
| `source` | `template` / `geometry` / `curve` / `document` |
| `code` | 稳定错误码，如 `E_TEMPLATE_PARAM`、`E_PATH_ENDPOINT` |
| `message` | 作者能读懂的一句话 |
| `templateId` | 模板问题时有 |
| `param` | 参数问题时有 |
| `trackId` / `clipId` / `pathId` | 定位用 |
| `fieldPath` | 字段/路径定位 |
| `detail` | 可选技术细节，不替代 message |

- 诊断显示在模板面板汇总区、04 `diagnostics` 抽屉、字段行内提示三处之一或组合；不重复弹 toast。
- 字段错误必须贴在字段；不能只塞进抽屉。
- 模板引用错误显示引用链 `a → b → c`；环显示闭环。
- 最终脚本校验 issue 保留原路径/消息，不改写成模板语言。
- 诊断可点击跳转：模板参数、目标轨道、目标片段、路径条目、字段行。
- 诊断清空只清 UI 记录，不删源错误；重新生成可再次出现。

## 事务与回滚

- 参数/展开错误：不进入装配，文档不变。
- 装配错误：不写入任何片段/轨道/路径；选择不变。
- 最终校验 error：整次回滚；已分配的 id 不残留。
- 撤销：一次应用一个事务；撤销一次回退全部片段/路径/轨道/触发器骨架。
- 失败后不显示“已生成”状态；不把失败产物留在草稿/剪贴板。
- 同一模板连续生成两次：两个独立事务；第二次失败不影响第一次产物。

## 与 03/11-15 的关系

- 03 负责文档模型、选择身份、事务、保存；12 不复制。
- 11-15 负责行为/规则/事件的合同校验与诊断口径；12 复用同一 issue 级别和诊断展示。
- 12 只补模板/几何/曲线专属前置检查；最终仍走同一脚本校验器。
- 不新增第二套“模板校验器”或“字幕校验器”。

## 禁止项

- 不伪造校验通过；没跑最终校验不写“已通过”。
- 不把 warning 当 error，也不把 error 降成 warning。
- 不自动修参数/自动裁剪/自动补端点来“让校验过”。
- 不在失败时保留半条轨道/半个片段/半条路径。
- 不把旧编辑器校验结果当当前代码结果。
- 不把 12 的生成前检查替代最终 `script.validate`。

## 验收出口

1. 模板参数越界：字段红字，生成按钮禁用，文档不变。
2. 嵌套环：显示闭环引用链，不生成半份内容。
3. 目标轨区间重叠：拒绝装配，已有片段不动。
4. 产物含片段级 `transition`：生成失败，诊断指向字段。
5. 路径端点不匹配位置节点：拒绝，提示先走 07 端点编辑。
6. 最终 `script.validate` 返回 error：整次回滚，诊断定位到字段/片段。
7. 最终校验只有 `[警告]`：允许保存，warning 显示在面板/诊断，不自动改值。
8. 几何/曲线 warning 不阻止保存；error 阻止。
9. 连续生成两次，第二次失败不影响第一次；撤销各自独立。
