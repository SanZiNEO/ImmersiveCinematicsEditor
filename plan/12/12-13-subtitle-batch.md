# 12-13 字幕批次

## 目标

把“一批字幕 cue”落到一组字幕轨道上，并提供批次表、批量时间调整、删除、重导入比对、编译入口。批次不是独立文件，也不是独立数据结构；批次就是作者选定的字幕轨道集合。

## 核心模型

```text
批次 = 选定的 OVERLAY 字幕轨道集合
cue 表 = 从这些轨道的字幕片段实时读出的虚拟表
cue = 一个 layer_type=subtitle 的 OVERLAY 片段
```

- 不建 sidecar，不写第二套字幕 JSON，不建“批次文件”。
- 保存 = 保存脚本；重开 = 从字幕轨道重建 cue 表。
- 批次没有独立 id；轨道 id + 片段 id 就是身份。
- 批次选择集合是 UI 状态；重开后默认选中全部字幕轨道，作者可再勾选。
- 不把批次信息写进 `meta`、片段、轨道或注释。

### 什么算字幕轨道

- `OVERLAY` 轨道。
- 轨道内片段全部是 `layer_type=subtitle`；空轨可以被作者选为字幕轨。
- 混有 image/fade 的 OVERLAY 轨不自动当字幕轨；如作者强制选入，表只读其中的 subtitle 片段，并显示“混合轨”warning。
- 轨道顺序按时间轴顺序；不建立“字幕轨专用层”。

## 面板

- 面板 id：`subtitles`；挂在 `document.drawer` 的 `subtitles` 页签。
- keepAlive=true；与 `clip.effects`/属性面板并存，不替代单片段字幕字段编辑。
- 面板只做批次表、导入向导入口、重导入、编译入口；不做第二套属性面板。

### 布局

```text
[导入 SRT/VTT] [重导入] [编译到脚本]
[轨道选择]  ☑ overlay_1  ☑ overlay_2  ☐ overlay_3
[筛选: 全部 / 重叠 / 缺文本 / 冲突]
[cue 表]
  序号 | 轨道 | 开始 | 结束 | 时长 | 文本 | 行数 | 状态
[批次摘要]  N cue / M 轨 / 重叠 K / 总时长范围
```

- 表格行按开始时间、轨道顺序排序；相同开始按轨道 id。
- 文本列只显示首行/截断；双击行选中对应片段并跳到 09 字幕字段，不在表内做富文本编辑。
- 表内可编辑开始/结束/轨道；文本编辑走 09 面板，避免第二套文本编辑器。
- 选中行与时间轴选择同步；多选用于批量移动/删除。
- 空态：没有字幕轨道时显示“导入字幕或新建字幕轨”；不显示假 cue。

## cue 表

| 列 | 来源 | 说明 |
|---|---|---|
| 序号 | 表内序号 | 不是脚本 id |
| 轨道 | 片段所在轨道 | 只读 |
| 开始/结束 | `start_time` / `start_time+duration` | 秒，毫秒精度 |
| 时长 | `duration` | 秒 |
| 文本 | `text` | 首行/截断；双击打开 09 |
| 行数 | `text` 按 `\n` 分行 | 不是自动换行 |
| 状态 | 计算 | `ok` / `overlap` / `empty` / `conflict` / `low-alpha` |

状态规则：

- `overlap`：同轨与另一 cue 的 `[start,end)` 相交。
- `empty`：`text` 为空或仅空白。
- `conflict`：重导入比对冲突（见后）。
- `low-alpha`：`opacity < 0.016`，运行时实际不绘制；提示但不改值。
- 不显示“最终像素宽度”；字幕宽度由游戏字体测量，表内不伪造。

## 轨道打包规则

用于导入/编译时把 cue 放到轨道：

1. cue 按开始时间升序；同一开始按原文件顺序。
2. 在选定轨道里找第一条“最后 cue 结束 ≤ 当前 cue 开始”的轨道；`end==start` 视为可接。
3. 没有可用轨道 → 新建 `OVERLAY` 轨，id `overlay_{n}`，放在最后一条字幕轨之后。
4. 当前 cue 与同轨 cue 重叠 → 不塞入；继续找下一轨或新建。
5. 同一轨内 cue 不重叠；运行时 `findActiveClip` 取第一个活跃片段，重叠会遮掉后面的 cue。
6. 不建立全局 z 表；每条 cue 的 `z_index` 仍按字幕默认/作者值。
7. 超过 8 条字幕轨时给 warning“轨道过多，建议合并时间”；不硬阻止。
8. 不自动改变已有轨道的 cue；只对本次导入/编译的新 cue 打包。

## 批次操作

### 1. 导入 / 重导入

- “导入 SRT/VTT”打开 12-12 向导；确认后编译进选定轨道。
- “重导入”选同一文件，解析后与当前批次比对；不直接覆盖。
- 重导入匹配规则：
  - 时间匹配：start/end 各在 ±0.5s 内，且区间重叠。
  - 文本匹配：去标记/去首尾空白后完全相同。
  - 完全匹配 → `unchanged`。
  - 时间匹配、文本不同 → `changed` / 冲突；默认保留现有文本。
  - 只有新 cue → `new`。
  - 只有现有 cue → `missing`；默认保留，不删。
- 冲突表显示旧文本/新文本/旧时间/新时间；作者逐条或全选“应用新文本/应用新时间/跳过”。
- 不自动覆盖手改文本；不自动删除现有 cue；不自动合并。
- 应用重导入是一次事务；未选中的冲突不改。

### 2. 批量移动

- 选中多行，输入偏移秒数；所有 start/end 同时平移。
- 平移后 start<0 或同轨重叠 → 汇总 error，不提交；作者改偏移或先移到新轨。
- 不自动把 cue 塞到别的轨；提供“移到新轨”显式操作。
- 一次事务；撤销一次全部回退。

### 3. 批量删除

- 选中多行 → 删除确认（显示条数/时间范围）。
- 删除的是字幕片段；不删轨道（空轨保留）。
- 一次事务；撤销恢复片段和顺序。
- 不自动清理空轨；空轨保留给后续导入。

### 4. 单条时间编辑

- 表内改开始/结束；结束必须 > 开始。
- 同轨重叠 → 行内 `overlap`，不提交；提供“移到新轨/改时间”。
- 不自动推其他 cue；不做 ripple。
- 一次提交一个片段；撤销一次回退。

### 5. 新建空 cue

- 在播放头新建一条字幕 cue，默认布局引用 09-08 `subtitle.lower-third`：`x=0.5`、`y=0.85`、`anchor=0.5`、`font_scale=1`、`scale=1`、`opacity=1`、`z_index=10`；不复制成第二套默认值。
- 默认文本为空；`empty` 状态；不生成运行时不绘制的空片段？允许保存 but 提示；编译时跳过空文本。
- 默认时长 2s；与同轨重叠 → 拒绝/新轨。
- 文本作者去 09 填；不在表内编辑。

## 重开与恢复

- 保存脚本后重开：按轨道内 `layer_type=subtitle` 片段重建 cue 表。
- 恢复字段：轨道 id、片段 id、start/duration、text、布局字段。
- 不恢复：批次选择集合（默认全选）、筛选、滚动、上次导入文件路径、冲突状态。
- 没有 sidecar 时也能完整恢复 cue 表；如果轨道被外部改成混合轨，只读其中的 subtitle 片段并 warning。
- 不把“上次导入文件”写进文档；不做自动增量同步。

## 与编译的关系

- 面板的“编译到脚本”调用 12-14；不直接写片段。
- 编译前检查：
  - 空文本 cue 跳过/报错；
  - 同轨重叠 error；
  - 时间倒置 error；
  - `text` 以单 `@lang:` 开头且未转义 → warning/error（按导入选项）。
- 编译产物就是当前批次的字幕片段；一次事务；失败零残留。
- 不建立第二套字幕轨道/片段；编译前后 cue 表应一致（除空文本跳过）。

## 禁止项

- 不建 sidecar、不建批次文件、不建工程内字幕副本。
- 不建第二套字幕 JSON/字幕图层类型。
- 不建立全局合成 z 表；不按 z 重排轨道。
- 不自动覆盖手改文本、不自动删除 missing cue、不自动合并重叠。
- 不做富文本编辑、不做样式批处理、不做自动换行。
- 不把字幕表写进相机/规则/模板数据。
- 不把“批次”做成脚本字段或模板参数。

## 验收出口

1. 导入 10 条 cue，其中 3 条时间重叠：自动分到 2–3 条字幕轨；同轨无重叠；游戏内每条都能显示。
2. 保存重开：cue 表从轨道恢复，条数/时间/文本/布局一致；没有 sidecar 文件。
3. 重导入同一文件：全部 `unchanged`；不改文档。
4. 手改一条文本后重导入：该条 `changed`，默认保留手改；作者确认后才应用新文本。
5. 批量移动 +2s：所有 cue 平移；有同轨重叠时拒绝并提示；撤销一次回退。
6. 删除 3 条：片段删除、轨道保留；撤销恢复。
7. 表内文本只读；双击跳到 09 字幕字段；没有第二套文本编辑器。
8. 同轨重叠显示 `overlap`，编译拒绝；不自动塞到别的轨。
9. `opacity=0.01` 显示 `low-alpha` 提示；不改值。
10. 编译后 cue 表与片段一致；空文本被跳过/报错；没有新增字幕样式字段。
