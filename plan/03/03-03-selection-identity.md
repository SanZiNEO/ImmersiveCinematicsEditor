# 03-03 片段身份与选择

## 目标

定义三件互相牵连的事：片段运行时身份、编辑器稳定身份、选择状态。核心原则一句话：**选择不用数组下标**（下标在插入/删除/重排后会飘），改用稳定键。

## 三种身份

| 概念 | 规则 | 写盘 |
|---|---|---|
| 运行时身份 `clip.id` | `^[A-Za-z0-9_]{1,64}$`，脚本内唯一；可缺省，但被引用时必须存在 | 是 |
| 编辑器身份 `clipKey` | 会话内唯一稳定键，重排/跨轨/撤销后不变 | 否 |
| 关键帧定位 | `(clipKey, objectPath, keyframeTime)`，时间只是定位值 | 否 |

源码锚点：`ClipIdentity.PATTERN`；`ScriptParser.parseClipId`；`ScriptValidator.checkClipIdentities`（查 id 重复）。

## 选择状态

```text
Selection = {
  clipKey,          // 片段
  objectPath?,      // 属性路径
  keyframeTime?,    // 属性内的时间，不是下标
  pathId?, ruleId?, bindingId?   // 路径 / 规则 / 绑定
}
```

不变式：同一时刻最多一个「主」选择域。属性域必须带 `clipKey`；关键帧域再加 `keyframeTime`；路径/规则域各自独立。

## 引用完整性（结构变更必须显式处理，不静默改指）

| 变更 | 处理 |
|---|---|
| 删除片段 | 先检查所有引用它的 `paths[]` / `rule_bindings[]` / `exit.target`；弹「这些引用将失效」，作者选「一并删除」或「取消」 |
| 删除位置关键帧 | 若该时间是某 `paths[]` 的端点 → 阻止删除，提示先重绑/删路径 |
| 插入位置关键帧 | 若落在现有路径端点之间 → 提示「会切断端点相邻性」，提供重绑或取消 |
| 改 `clip.id` | 若被引用 → 同步改所有引用（一次提交），或拒绝 |
| 撤销/重做 | 修复选择，不改引用 |

添加引用前：目标片段无 `id` 必须先弹「设置 id」，**不自动生成**（避免和作者命名冲突）。

## 路径端点的表达

编辑器里一条 `paths[]` 端点显示为「目标片段 + 端点时间 + 相邻性」，端点只能从「目标片段的位置节点时间序列」里选（下拉），不提供自由数字。节点序列 = `position.x/y/z` 关键帧时间的并集去重升序（`PathCollectionParser.positionNodeTimes`），端点匹配容差 `1e-4` 秒。

## 验收标准

- 有 id 与无 id 片段重排/跨轨后 `clipKey` 均不变，选择仍指同一片段；复制获新键，撤销恢复原键。
- 改 `id:c1` → `id:hero` 且 `paths[0].clip='c1'`：一次提交同时改两处，撤销一次全回退。
- 删除被引用的片段：操作被阻止，引用条目保留。
- 给无 id 片段加路径条目：弹「设置 id」，不自动填。
- 选中 `yaw@t=2` 帧，删掉 `position.x@t=1` 帧：选择仍指 `yaw@2`，不跳到别的帧。
- `grep selection.track` 0 命中（下标选择彻底删除）。
