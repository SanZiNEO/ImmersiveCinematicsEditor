# 13-08 14 交接与冻结

## 目的

13 的最后一个交付物不是安装包，而是给 14 的**冻结输入**：

- 哪些合同已经通过 WebUI 验收，14 不得重写；
- 哪些是 WebUI 专属、AUI 必须换实现；
- 哪些是 13 已知限制，14 要接住；
- 14 先做什么、后做什么，什么情况下不许启动。

14 是 AUI 迁移，先 Forge，后 Fabric。13 未通过，不启动 14。

## 一、冻结原则

14 迁移的是“宿主和呈现方式”，不是“脚本语义和作者工作流”。

| 层 | 13 冻结 | 14 允许换 |
|---|---|---|
| 脚本字段 | 02 字段目录 + 运行时 schema | 不换 |
| 脚本文档 | 03 `ScriptDoc` / `AnimObject` / `Selection` / `serializeDoc` | 不换 |
| 选择/命令/撤销 | 03 + 05/06 的 `EditorCommand` / `commit` | 不换 |
| 面板职责/ID | 04～12 的 panelId、commandId、drawer tab | 不换 |
| 模板/字幕/转场/飞控语义 | 08/12 | 不换 |
| 传输端点 | 01 `EditorEndpoint` / `EditorPush` | WebUI 用 WebSocket；AUI 用进程内端点 |
| 画面源 | 01 `EditorFrameSource` 占位 | WebUI 用 `CaptureHub` + 编码；AUI 用 GPU 帧源 |
| 输入 | WebUI 用浏览器/Electron 输入 | AUI 用游戏内输入 |
| 发布版本 | 13 WebUI 版本格式 | AUI 版本格式另加加载器 |

## 二、冻结合同清单

### 01 地基

- `EditorHostApi` / `EditorSessionApi` / `EditorPush` / `EditorEndpoint` / `EditorPlaybackControl` / `EditorFlightControl` / `EditorFrameSource` / `EditorCommandAck` 的签名与语义；
- `EditorManager` 的开关/模式/生命周期；
- 端点所有权：单端点 detach 只释放本会话；宿主级 teardown 才停服务；
- `flight.exit` 只到 owner；
- 关键回执不静默丢；
- `hello_ack` 的 capabilities/schemaHash；
- 总开关关闭无服务、无捕获、无按键。

### 02 字段目录

- 字段目录是唯一字段来源；
- `sourceRef` / 声明自检 / `schema.get` 对账；
- 14 不新建第二份字段表，不从快照反推；
- schemaHash 随版本变化。

### 03 文档模型

- `ScriptDoc` 顶层、四类集合、未知键策略；
- `AnimObject` / `ObjectKeyframe` 值模型；
- `clipKey` 身份、选择、引用完整性；
- 无损序列化、撤销、校验桥、打开/新建/保存/推送；
- 14 不新建第二套文档模型。

### 04～12 工作流

- 04 插件内核、七类扩展点、布局树、主题、偏好、窗口、命令/焦点；
- 05 项目图、主轴、片段编辑；
- 06 双面板、值控件、关键帧组、局部视口；
- 07 位置/路径/曲线；
- 08 镜头/转场/lane；
- 09 覆盖层/字幕/画幅/z_index；
- 10 音频/调色/LUT/媒体；
- 11 触发器/规则/事件；
- 12 模板/飞控/字幕。

14 可以换面板的“宿主容器”（游戏内 UI），但不能换面板的职责、字段归属、选择模型和命令语义。

## 三、14 必须接住的 WebUI 专属实现

| WebUI 实现 | 14 要换成的 | 不能照搬 |
|---|---|---|
| `WebSocketSession` 作为 `EditorEndpoint` | 进程内端点 | 不在游戏内开 WebSocket 给自己 |
| `WebEditorServer` 8765/token/Origin | 进程内会话注册 | 不再要求 token/端口 |
| `CaptureHub` 捕获 + `PreviewStreamer` 编码 | 进程内 GPU 帧源/纹理租约 | 不再走 18 字节网络头/H.264 |
| `PreviewConfig` 1920×1080@60 | AUI 帧源尺寸/刷新策略 | 不假设固定 1080p60 |
| Electron 窗口/菜单/文件对话框 | 游戏内 Screen/菜单/文件选择 | 不启动 Electron |
| 浏览器 IME/焦点 | 游戏内输入 | 不能假设浏览器输入模型 |
| `src/store.ts` WebSocket 重连/代际 | 进程内会话生命周期 | 不保留 socketGeneration 概念 |
| `Preview.vue` 帧消费 | 游戏内帧源消费者 | 不再有 100ms 网络显示延迟 |

这些是 14 的迁移输入，不是 13 的未完成项。

## 四、14 输入包

13 交付给 14 的输入包应包含：

1. **接口**：01 的 7 接口 + `EditorCommandAck`；
2. **字段**：02 目录 + `schemaHash` 规则；
3. **文档**：03 模型 + 序列化/撤销/校验桥；
4. **面板**：04～12 的 panelId / commandId / drawer tab 清单；
5. **黄金脚本**：13-02 的正例/负例 + 期望文件；
6. **验收状态**：13-01 的执行记录，明确哪些 P0/P1 已 PASS；
7. **已知限制**：13-07 的发布说明；
8. **版本格式**：WebUI 与 AUI 的显示名规则；
9. **迁移顺序**：Forge 先，Fabric 后；先最小脚本，后全量。

## 五、AUI 迁移顺序

### 第一步 · Forge 最小闭环

- 启动 Forge 客户端；
- 打开游戏内编辑器 Screen；
- 用进程内端点挂载一个最小脚本；
- 用 GPU 帧源出第一帧；
- 播放/暂停/seek；
- 关闭/重开。

通过后，才做面板迁移。

### 第二步 · Forge 面板迁移

- 04 工作台外壳换成游戏内 Screen；
- 05 主轴、06 双面板、07 路径、08 转场、09 覆盖层、10 音频/调色、11 行为、12 模板/飞控/字幕；
- 先只读/空态，再编辑；
- 每接一个面板，跑对应黄金脚本；
- 不允许在 AUI 里另建一套选择/命令/文档模型。

### 第三步 · Fabric 对等

- Fabric 复用同一套 `api/editor`、字段目录、文档模型、面板 ID；
- 只替换加载器入口/生命周期；
- 不复制 Forge 的业务代码；
- 两条加载器跑同一组黄金脚本。

## 六、14 不允许做的事

- 不重写 02 字段目录；
- 不重写 03 文档模型/选择/撤销；
- 不新建第二套主时间轴、属性面板、效果面板；
- 不把模板变成运行时；
- 不把字幕变成第二套 JSON/sidecar；
- 不把转场做成片段字段；
- 不把 `fade` 当 crossfade；
- 不把 AUI 做成“游戏内嵌一个 WebView”；
- 不在 13 里提前实现 AUI。
