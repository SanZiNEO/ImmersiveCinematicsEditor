# 13-03 工作台与应用层验收

## 目的

验 04 的工作台骨架，以及 05～12 把它当容器装进去之后，整个应用层是否仍然成立。

这一份不验游戏画面，也不验传输；它验“作者在编辑器里能不能连续工作”：

- 面板放得下、拖得动、恢复得回来；
- 主时间轴只编排片段，不被属性/关键帧污染；
- 属性面板与效果面板职责不串；
- 局部标尺、轴外帧、缩放不互相重置；
- 小窗、停靠、IME、节点拖动、片段拖动不抢输入；
- 主题、窗口、偏好、草稿、最近项目可恢复。

## 设计基线

- 04：插件内核、七类扩展点、布局树、停靠、外壳、面板宿主、抽屉、主题、偏好、Electron 窗口、命令/焦点、参考插件。
- 05：项目图、主轴几何、轨道/片段、片段编辑、标尺/播放头/标记、面板接线。
- 06：`selection.properties` 与 `clip.effects` 双面板、值控件、关键帧组、局部视口、诊断。
- 07～12：路径、转场、覆盖层、音频/调色、行为、模板/飞控/字幕各自的面板与命令。
- 当前旧 `App.vue` / `store.ts` / `rightTab` / 旧对象行不是目标合同。

## 六类核心场景

### 场景 A · 主时间轴只编排

步骤：

1. 打开一个含 100+ 属性叶子的片段；
2. 在 `selection.properties` 里滚动/编辑；
3. 在 `clip.effects` 里展开多组；
4. 观察 `timeline.main`。

必须成立：

- 主时间轴只显示轨道、片段、标尺、播放头、标记；
- 不出现属性行、对象展开、关键帧菱形、属性数量汇总；
- 选中 100+ 属性片段时，轨道高度不变；
- 主轴片段宽度/时长不因为属性面板展开而变化；
- 不出现第二条时间轴。

### 场景 B · 效果面板多组多属性

步骤：

1. 让同一片段至少三组、每组至少两个叶子有关键帧；
2. 展开全部组；
3. 切换选中行，再切回；
4. 改变窗口宽度。

必须成立：

- `clip.effects` 同时展开多组多属性；
- 左侧行名与右侧关键帧组左右对齐；
- 切换选中行不隐藏其他组；
- 组头/行不因为选中态重排；
- 删除某叶子的全部关键帧后，该行回到属性面板，效果面板不留空行；
- 效果面板没有“添加属性”选择器。

### 场景 C · 局部标尺与全局 seek

步骤：

1. 在效果面板内拖动局部播放头；
2. 观察主时间轴全局播放头；
3. 分别调整局部缩放与全局缩放；
4. 用局部 seek 定位到轴外帧。

必须成立：

- 效果控件共用当前片段的局部标尺；
- 局部 seek 经同一映射请求全局 seek，不直接改全局视口；
- 局部缩放不重置全局缩放；
- 全局缩放不重置局部缩放；
- 轴外帧在效果面板内可定位、编辑、撤销、保存；
- 主时间轴片段宽度/时长/全局视口不变。

### 场景 D · 属性面板与效果面板同值

步骤：

1. 同一属性在 `selection.properties` 与 `clip.effects` 同时可见；
2. 在两边分别改同一个目标值；
3. 观察选择、值控件、命令、撤销；
4. 打开“快捷属性”。

必须成立：

- 改同一目标走同一 `Selection` / 值控件 / `EditorCommand`；
- 不出现两套选择状态、两套值控件、两套提交路径；
- 一次修改一次撤销；
- 快捷属性没有自己的关键帧时间轴；
- 属性面板的“开动画”把属性移入效果面板，效果面板不反向创建属性。

### 场景 E · 小窗 / 停靠 / 换位

步骤：

1. 把窗口缩到最小允许尺寸；
2. 把 `clip.effects` 拖到右栏，把 `selection.properties` 拖到左栏；
3. 把抽屉拖出/停回；
4. 切换预设布局，再恢复；
5. 重启应用。

必须成立：

- 小窗下无面板重叠、无按钮被裁掉；
- 停靠/换位后双宿主 ID 不变，选择不丢；
- 抽屉可开关/拖出/错误隔离；
- 布局坏文件只恢复布局，不丢文档；
- 重启后布局/bounds/主题/最近项目恢复；
- 主题切换不重建文档、不重建预览、不弄脏脚本。

### 场景 F · 输入焦点与拖拽

步骤：

1. 在字幕文本、数值输入框、搜索框里输入中文（IME）；
2. 在项目图拖动节点；
3. 在主时间轴拖动片段/裁切手柄；
4. 在效果面板拖动关键帧；
5. 在以上过程中按快捷键、Esc、Delete、Ctrl+Z。

必须成立：

- IME 组合输入不被全局快捷键抢走；
- 输入框/弹窗打开时，工作台命令不触发；
- 节点拖动、片段拖动、关键帧拖动互不抢输入；
- Esc 取消当前拖拽，不关闭整个应用；
- 一次拖拽一次撤销；
- 保存过程中不因为焦点切换丢修改；
- 全键盘可完成主要工作台操作。

## 应用层验收

### 主题

- 内置主题、插件贡献主题、本地导入主题都可选；
- 跟随系统分别配置浅色/深色/高对比；
- 局部 token 覆盖可重置；
- 重启无白闪；
- 主题只改 CSS 变量/原生 themeSource，不改文档、不重建预览。

### 窗口与菜单

- 最小化/最大化/还原/关闭；
- 重启 bounds 可达，不把窗口恢复到屏幕外；
- 脏文档关闭三选一：保存/不保存/取消；
- 保存失败不关闭；
- 文件对话框只通过 preload 白名单，不由渲染进程直接读盘；
- 菜单/快捷键/命令面板同一份 commandId。

### 偏好 / 布局 / 窗口 / 草稿

- 四类状态分文件存放；
- 坏一个只恢复一个；
- 草稿恢复不覆盖已保存文件；
- 最近项目路径可达；
- 设置页 i18n 文案完整，不出现硬编码中文/英文混排（按 04 合同）。

### 项目图

- 节点=脚本、边=requires、泳道=文件夹；
- 节点悬停显示全部触发器/前置（含跨脚本）；
- 双击/Enter 打开脚本，失败留图页；
- 文件夹新建/重命名/删除空目录；
- 移动只改路径，不改 `meta.id`，不改 requires 文本；
- 改 `meta.id` 有预览/备份/原子改写/回滚；
- 坏布局回落自动布局，不丢用户文件；
- 200/800 节点降级可用。

### 面板归属

| 内容 | 归属 | 不放在 |
|---|---|---|
| 主时间轴轨道/片段/标记 | `timeline.main` | 对象行/属性节点/关键帧菱形 |
| 当前片段全部适用属性、静态值、未设置值 | `selection.properties` | 效果面板的“添加器” |
| 已有关键帧的属性/组、关键帧编辑、局部标尺 | `clip.effects` | 主时间轴 |
| 路径集合/几何/timing/预览 | `paths.collection` | 主时间轴/效果面板 |
| 叠化/参数过渡/共存 | `transition.panel` | 片段属性组/主时间轴 |
| lane/连续性/玩家移动/回放检查 | `camera.inspect` | 主时间轴 |
| 触发器/规则/事件 | `behavior` 抽屉 | 主时间轴对象行 |
| 模板参数/摘要/diff/插入 | `templates` 抽屉 | 属性面板 |
| 字幕导入/批次/编译 | `subtitles` 抽屉 | 第二套字幕 JSON |
| 飞控九槽 | `flight.inputs` 面板 | 脚本字段 |

## 证据

每类场景至少保留：

- 全窗口截图（含面板布局、时间轴、状态栏）；
- 关键操作录屏（拖动、停靠、IME、撤销）；
- 相关状态文件（布局/偏好/窗口/草稿）在操作前后的副本；
- 脚本 diff（确认 UI 操作没有写不该写的字段）；
- 若失败，记录期望/实际/回退轮次。

不要求像素级视觉对比；要求行为和职责正确。

## 通过标准

- 六类核心场景全部 `PASS`；
- 04 的主题/窗口/偏好/草稿恢复全部 `PASS`；
- 05 项目图闭环和主轴片段编辑 `PASS`；
- 06 双面板职责、轴外帧、局部标尺 `PASS`；
- 面板归属表没有越界；
- 小窗和 IME 不抢输入；
- 失败项按 13-01 回退到 04/05/06/07/08/09/10/11/12 对应轮。
