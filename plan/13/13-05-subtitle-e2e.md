# 13-05 字幕端到端验收

## 目的

验 12 的字幕完整工作流：

```text
SRT/VTT → 导入 → cue 表 → 字幕轨道 → 编译 → 标准 OVERLAY/subtitle 片段 → 保存/推送 → 游戏播放 → 重开/重导入
```

字幕不是独立运行时，也不是第二套字幕 JSON。它就是当前脚本里的 `OVERLAY` 字幕片段，批次就是作者选定的字幕轨道。

## 设计基线

- 12-12 字幕导入：SRT/VTT、文件端口、cue 模型、文本转义；
- 12-13 字幕批次：cue 表、轨道分配、重叠拆轨、diff、无 sidecar；
- 12-14 字幕编译：一 cue 一片段、09-05 字段面、编译与回读；
- 12-15 字幕面板：`subtitles` 抽屉、导入向导、cue↔clip 定位；
- 09-05 字幕字段面：`text/font_scale/x/y/anchor_x/anchor_y/scale_x/scale_y/opacity/z_index`；
- 09-08 默认布局：`subtitle.lower-third`（x .5、y .85、anchor .5、font_scale 1、scale 1、opacity 1、z 10）。

## 硬边界

### 1. 字幕字段只有 09-05

字幕固定白色文字。没有颜色、字体族、描边、背景框、对齐字段；不新增字幕样式字段。

`text` 是 value-only：

- 支持 `\n`；
- 不自动换行；
- `@lang:` 查语言表；
- `@@lang:` 转义；
- alpha < 4 时不绘制。

### 2. 不建 sidecar

不建 `.srt.json`、`.subtitle.json`、`subtitles/` 副本，也不把源文件复制进工程。字幕文本已经写进 `OVERLAY/subtitle` 片段；源 SRT/VTT 只是导入输入。

### 3. 批次就是字幕轨道

导入后的 cue 表属于作者选定的字幕轨道。没有“批次文件”“批次数据库”“第二套字幕 JSON”。

### 4. 不做旧 13.03 的额外能力

不把下面这些当 13 必过项：

- 字幕拆分/合并；
- 字幕样式批量替换；
- ASS 样式映射；
- 字幕颜色/字体/描边/背景/对齐；
- 字幕 sidecar 删除测试（因为本来就不建）。

这些不是“以后再说”，而是当前字幕合同里没有。

### 5. 一 cue 一片段

一个 cue 编译成一个 `OVERLAY/subtitle` 片段。同轨 `[start,end)` 不允许重叠；重叠必须分轨。时间、文本、布局映射到 09-05 字段，不引入第二个时间模型。

## 导入验收

### 输入

准备：

- UTF-8 SRT；
- UTF-8 VTT；
- 带 BOM 的 UTF-8；
- 含 `\n` 的多行文本；
- 含 `@lang:key`；
- 含 `@@lang:key`（应转义，不查表）；
- 含空行/空 cue；
- 含同轨重叠 cue；
- 含超长文本；
- 含中文/英文/日文。

### 必须成立

- SRT/VTT 都能识别时间、序号、文本；
- BOM 不导致首行乱码；
- 多行文本保留 `\n`，不自动折行；
- `@lang:key` 查语言表；缺失 key 有诊断；
- `@@lang:key` 输出字面 `@lang:key`，不查表；
- 空 cue 被跳过或明确提示；
- 同轨重叠 cue 被拆到不同轨道，不静默覆盖；
- 导入不写 sidecar；
- 导入不改动无关片段；
- 导入前有 diff/预览，导入后可撤销。

## 批次验收

### cue 表

必须显示：

- 序号；
- 起止时间；
- 文本；
- 目标字幕轨道；
- 状态（新增/修改/冲突/跳过）；
- 与现有片段的 diff。

必须支持：

- 选中/多选；
- 改时间；
- 改文本；
- 改轨道；
- 删除；
- 重新分配轨道；
- 定位到已编译片段。

不做：

- 样式批量；
- 拆分/合并；
- 字幕级颜色/字体/描边/背景/对齐；
- 全局 z 表。

### 同轨规则

- 同一字幕轨道内 `[start,end)` 不得重叠；
- 重叠必须分轨；
- 分轨后轨道名/顺序稳定；
- 不把重叠 cue 塞进同一片段用两个 text 字段；
- 不自动 crossfade 字幕。

## 编译验收

### 映射

一个 cue → 一个 `OVERLAY` 片段：

| cue | 片段 |
|---|---|
| `start` / `end` | 片段起止 |
| `text` | `objects.text.value` |
| 布局 | `x/y/anchor_x/anchor_y/scale_x/scale_y/font_scale/opacity/z_index` |
| 层类型 | `layer_type=subtitle` |
| 轨道 | 作者选定的字幕轨道 |

默认布局引用 09-08 `subtitle.lower-third`，不复制第二套默认值。

### 必须成立

- 编译只写 09-05 字段；
- 不写颜色/字体族/描边/背景/对齐；
- 不写 sidecar；
- 不建第二套字幕 JSON；
- 编译不重置已有 `exit` / `opacity` 关键帧；
- 编译不删除作者的其它对象/关键帧；
- 编译失败不留半成品；
- 编译后可回读 cue↔clip；
- 重新编译只更新目标字幕片段，不动无关片段。

### 与手改的关系

- 作者手改字幕片段后，重新导入不自动覆盖；
- 重导入按时间/文本比对，给出 diff；
- 作者选择“替换/保留/跳过”；
- 替换只影响选中的 cue；
- 保留后不把源文件内容偷偷写回；
- 没有“自动同步”把手工修改冲掉。

## 游戏播放验收

用 `golden/05-overlays-subtitles.json` 或字幕专用夹具，在 Forge/Fabric 各跑：

1. 字幕在正确时间出现/消失；
2. 多行文本按 `\n` 换行；
3. 固定白色；
4. 位置/字号/锚点/缩放/透明度正确；
5. `@lang:` 按语言表显示；
6. `@@lang:` 显示字面；
7. alpha < 4 不绘制；
8. 同轨不重叠；
9. 多轨字幕按 `z_index` 排序；
10. 字幕与覆盖层/画幅共存；
11. 暂停/seek 后字幕跟随；
12. 保存/重开/重推后字幕不丢；
13. 删除源 SRT/VTT 后，已编译脚本仍能播放；
14. 工程目录内没有字幕 sidecar/副本。

## 负例

| 负例 | 期望 |
|---|---|
| 同轨重叠 | 拒绝编译或强制分轨，不能静默覆盖 |
| `@lang:` 缺 key | 诊断；不显示空字符串假装正常 |
| `@@lang:` 被误查表 | 输出字面，不查表 |
| 字幕文本为空 | 跳过/提示，不生成空片段 |
| 非 UTF-8 | 明确编码错误，不产生乱码字幕 |
| 字幕字段写颜色/字体 | 结构/字段检查拒绝 |
| 一个 cue 生成多个片段 | 违反一 cue 一片段，拒绝 |
| 字幕片段同轨重叠 | 校验报 issue |
