# 11-14 事件时间轴与 Seek

## 目标

把 `EVENT` / `MOD_EVENT` 的记录挂到现有片段时间轴上：只加事件标记，不建第二时间轴；并写清 seek 对事件的前跳、后跳、循环、暂停语义。

事件标记是记录的视图，不是新的可编辑时间轴数据。

## 标记位置

```text
全局时间 = 片段 startTime + event.time
```

- `event.time` 是片段局部秒；标记放在片段在时间轴上的对应位置。
- 片段移动、裁剪、改 startTime：标记跟随片段，不改 `event.time`。
- 片段时长变短：超出的记录变成“运行时丢弃”，标记移到片段末尾并加警告，不静默删除。
- 事件标记只来自现有 `objects.event` / `objects.mod_event`；不新建轨道、不复制记录。
- 同一片段多个记录：按 time 升序排列；时间相同不允许，标记不重叠在同一 x。
- 多条 EVENT 轨/多个片段：标记按全局时间分层显示，同类可堆叠；不合并成一条“全局事件轨”。

## 标记外观

| 类型 | 形状 | 摘要 |
|---|---|---|
| EVENT 命令 | 实心标记 | `command …` |
| EVENT 移动 | 空心标记 | `移动到 …` |
| EVENT 命令+移动 | 双色标记 | `command … + 移动` |
| EVENT 占位 | 虚线标记 | `占位` |
| MOD_EVENT | 菱形标记 | `event_type · data N 键` |
| 超时长 | 红色标记 | `运行时丢弃` |

- 标记不显示完整命令正文；悬停显示摘要。
- 标记不显示已触发/未触发状态；编辑器没有运行态。
- 标记可选中、可拖动改时间；拖动范围限制在 `[0, duration]`。
- 拖动不能产生相同 time；冲突时回退到上一个合法位置并提示。
- 拖动只改 `event.time`，不改 `command/position/data`。

## 选中与定位

- 单击标记：选中行为页对应记录，不自动 seek、不播放。
- 双击标记：定位播放头到标记；是否预览由播放控制决定，不自动播放。
- “定位到事件”：seek 到标记全局时间。
- “预览此事件”：seek 到标记前 0.1s 再播放；仅当存在合法前置时间时可用。
  - `time=0` 的记录无法通过 seek 回到之前；界面提示“t=0 记录只能在首次推进/新实例触发”，不假装能预览。
  - 事件在片段 `duration` 末尾时，seek 到末尾会把该记录算作已过去；预览改到末尾前 0.1s。
- 定位/预览不修改记录、不创建副本、不重置其他片段事件。

## Seek 语义

### 前跳

- seek 到目标时间：每条事件运行时 `reset(目标局部时间)`。
- 游标移到目标之后的下一条；目标及更早的记录不补触发。
- 前跳跨过的命令不执行；不补发、不排队。
- 目标落在片段之前：局部时间按 0；片段开头及更早的记录不补触发。
- 目标落在有限片段之后：局部时间按 duration；末尾记录不补触发。

### 后跳回退

- 已触发标记清空；游标回到目标之后的下一条。
- 目标之后的记录可以再次触发；目标及更早仍不补触发。
- 回退不会重复执行目标之前的命令。

### 目标恰好在事件时间

- `reset` 跳过 `time <= 目标` 的记录，所以目标时刻的那条不会触发。
- 要看到该事件，必须 seek 到它之前；`time=0` 没有“之前”，只能新实例/首次推进。

### 暂停 / 恢复

- 暂停期间不处理事件；恢复按上报内容位置重定基准。
- 重锚**不重置**事件游标：向前跨过的事件会在恢复后的边沿区间补扫；向后回退不重复触发。
- 暂停与 seek 正交：暂停中的 seek 只重定位基准和游标，不改暂停态。

### 循环

- 片段循环回到开头：已 fired 的记录不会重放；事件只在该实例内每条一次。
- 宏观循环：不重放服务端 EVENT；玩家移动航点索引会复位，但事件记录本身不重触发。
- 多入口：同一实例内已 fired 的记录不因换入口重放。
- `pingpong` 在 EVENT 上拒绝；事件没有反向时间语义。

### 新实例

- 新播放实例 = 新事件运行时 = 新 fired 集合；记录可重新触发。
- 同脚本并行两个实例各自独立，不互相去重。
- 服务端和客户端各自维护身份与 fired 集合，不跨进程比较。

## 时间轴交互

- 沿用 05 时间轴的缩放/平移/播放头；11 不定义新的时间轴尺寸。
- 事件标记不参与片段层级排序，不改 `script.graph` 数据契约。
- 事件标记不改变片段选择模型；选中标记时片段仍可选中。
- 事件标记层可开关；关闭只隐藏标记，不删记录。
- 事件标记多时按像素聚合：同一屏幕 x 附近显示“N 个事件”，展开列表；不丢记录。
- 悬停卡内部滚动，不截断命令/数据摘要。

## 与播放控制的关系

- 播放/暂停/停止使用现有控制；事件标记不新增播放按钮。
- 停止后重新播放：新实例，事件可再触发；编辑器不显示“上次已触发”。
- 编辑器预览中的事件行为由预览运行环境决定；编辑器不伪造服务端命令执行结果。
- `EVENT` 命令只对观看者执行；编辑器不显示“执行成功/失败”。

## 校验

| 检查 | 级别 | 处理 |
|---|---|---|
| 标记时间 < 0 | block | 拖回合法位置 |
| 标记时间 > duration | warn | 红色标记“运行时丢弃” |
| 时间相同 | block | 拒绝拖动/插入 |
| 片段无事件对象 | info | 不显示标记，不自动创建 |
| 多条 EVENT 轨 | warn | “建议最多 1 条” |
| 事件对象结构非法 | block | 标记红框，详情报错 |
| `pingpong` + 事件轨 | block | 禁用 |
| seek 目标非有限/负数 | block | 播放头回 0 |
| seek 到事件时刻 | info | “该时刻记录不触发” |
| `t=0` 预览 | info | “无法 seek 到之前” |

## 验收标准

1. `event.time=1`、片段 startTime=5：标记在全局 6s。
2. 片段移动 startTime：标记跟随，`event.time` 不变。
3. 片段缩短到 3s，原 time=4 记录：红色“运行时丢弃”，不删除。
4. 拖动标记：只能改 time，不能拖出 `[0,duration]`；相同 time 拒绝。
5. 单击标记选中记录，不 seek、不播放。
6. 双击/定位：seek 到标记全局时间；目标时刻记录不触发。
7. “预览此事件”：seek 到前 0.1s 再播放；`t=0` 显示无法预览。
8. 前跳跨过两条命令：不补发、不排队。
9. 后跳：目标之后记录可再次触发；目标之前不重复。
10. 暂停恢复向前跨事件：按边沿补扫；回退不重复。
11. 片段循环：已 fired 记录不重放；界面不承诺循环重播。
12. 宏观循环：服务端 EVENT 不重放；玩家移动航点复位。
13. 新实例：同脚本两条并行实例各自触发，不互相去重。
14. 多条 EVENT 轨：warn，不自动合并。
15. 事件标记层关闭：只隐藏，不删记录；重开恢复。
16. 聚合标记“N 个事件”：展开可见全部记录，不截断。
