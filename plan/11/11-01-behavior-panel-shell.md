# 11-01 行为抽屉与脚本结构树

## 目标

在 04 预留的 `behavior` 抽屉页里装一块脚本级行为编辑器。根是当前脚本，不按片段拆成多块面板，不出现跨脚本触发器总表。

这块面板只写脚本字段：触发器声明、规则定义、规则绑定、事件记录。它不执行规则、不求值条件、不伪造事实状态、不合成画面。

## 面板身份

| 项 | 值 |
|---|---|
| 插件 | `core.behavior-panel` |
| 面板 ID | `behavior` |
| 默认槽位 | `document.drawer` |
| 默认页签标题 | 行为 |
| 页面 | `document` |
| keepAlive | 是 |
| 选择来源 | 当前文档 + 面板会话选择 |

- 复用 04 已经预留的 `behavior` 空位，不新增抽屉 ID。
- 面板未打开时仍然跟随当前文档；切文档后重建树、清空面板选择、不丢未保存草稿前先走草稿守卫。
- 不做独立窗口、不做右侧常驻面板、不做第二时间轴。

## 布局

```text
┌ 行为 · 当前脚本名 ───────────────────────────────────────────────┐
│ [+ 触发器] [+ 规则] [+ 绑定] [+ 事件]   [筛选____] [全部依赖]  3/2/4/12 │
├───────────────────────────┬──────────────────────────────────────┤
│ 触发 3                    │ 详情 / 依赖                          │
│  ├ location · 可重复      │ 身份 / 类型                          │
│  ├ advancement · 单次     │ 条件树                              │
│  └ all_of · 单次          │ 前置                                │
│ 规则 2                    │ 时序                                │
│  ├ rule_boss_phase        │ 诊断                                │
│  │  ├ 绑定 b1 → clip_a    │                                      │
│  │  └ 绑定 b2 → clip_b    │                                      │
│  └ rule_leave（未绑定）   │                                      │
│ 事件 12                   │                                      │
│  ├ EVENT · clip_a         │                                      │
│  └ MOD_EVENT · clip_b     │                                      │
└───────────────────────────┴──────────────────────────────────────┘
```

- 左栏宽度 260–320px，可拖动；右栏最小 360px。
- 抽屉高度归 04 布局树；面板不自己保存高度。
- 左右栏各自滚动；树展开状态只存面板会话，不进文档、不进撤销。
- 抽屉高度不足时，详情区优先保留标题和当前编辑行；树可以收起。

## 结构树

### 触发器

- 节点：每个 `meta.triggers[]` 一条。
- 行内容：类型标签、显式 `id` 或生成的 `type#index`、`repeatable` 徽标、条件/前置数量、最高问题级别。
- 顺序 = 声明顺序。拖动排序会改数组顺序；没有显式 `id` 的触发器会改身份，排序前必须确认。
- 触发器下不挂片段；触发器没有目标片段。

### 规则与绑定

- 一级节点：每个 `rules[]` 一条；显示规则 id、动作数量、条件摘要、是否被绑定。
- 二级节点：该规则的全部 `rule_bindings[]`；显示绑定 id、目标片段、`gate.at`、`control`。
- 没有绑定的规则显示“未绑定”，不隐藏、不自动删。
- 规则顺序按声明顺序；绑定顺序按声明顺序。排序只影响阅读，不影响运行时；不提供拖动改绑定目标。

### 事件

- 一级分组：`EVENT` / `MOD_EVENT`。
- 二级分组：片段。显示片段 id、事件数量、问题级别。
- 三级：事件记录行；显示时间、命令/event_type 摘要、占位/缺失徽标。
- 事件顺序按片段局部时间升序；同一时间按记录下标升序。
- 事件区跟随当前选中片段展开；切片段不强行改主选择，只更新“当前片段”标记。

### 空态

- 没有触发器：显示“无触发器：脚本只能被命令或其他脚本启动”，提供“新增触发器”。
- 没有规则：显示“无规则：播放期间没有条件行为”，提供“新增规则”。
- 没有事件：显示“无事件：片段时间点不发送事件”，提供“新增 EVENT / MOD_EVENT”。
- 整份脚本没有行为：树仍显示四个分组，不显示假节点、不自动建空触发器。

## 选择模型

```ts
type BehaviorSelection =
  | { kind: 'trigger'; identity: string }
  | { kind: 'rule'; ruleId: string }
  | { kind: 'binding'; bindingId: string }
  | { kind: 'event'; clipKey: string; trackType: 'EVENT' | 'MOD_EVENT'; recordKey: string }
  | { kind: 'overview' }
```

- 初始选择 `overview`，显示脚本行为总览与问题计数。
- 触发器用稳定身份；显式 id 优先，缺失时映射到 `type#index`。
- 规则/绑定用文档 id；事件用 `clipKey + trackType + recordKey`；`recordKey` 优先显式记录 id，否则用当前下标。
- 文档变化导致选择目标消失：清空选择回 `overview`，显示“原目标已删除”；不自动选相邻项。
- 点“定位到片段”才调用现有选择命令选中片段；面板自己的选择不写 `state.selection`。

## 详情与依赖

详情顶部是两段切换：

- **编辑**：当前记录的字段面。
- **依赖**：只读的事实/引用关系，见 `11-11`。

默认编辑。依赖页签不提供输入框，不允许改引用。

## 草稿与提交

- 复杂记录（触发器、规则、绑定、事件）使用记录级草稿。
- 同一时间只有一个记录草稿；切换记录时弹“应用 / 放弃 / 取消”。
- 应用 = 一条 `EditorCommand`，一次撤销；不按字段拆成多条命令。
- 简单开关（如展开、显示依赖）只改会话状态，不进文档、不进撤销。
- 新增记录先建本地草稿；应用时才写入 `doc`。取消新增不留下空对象。
- 删除记录是单独命令；删除前显示引用影响：被绑定引用的规则、被条件引用的绑定、被事件页选中的记录。
- 触发器排序是单独命令；规则/绑定/事件排序不进文档。

## 工具条

| 动作 | 行为 | 约束 |
|---|---|---|
| 新增触发器 | 在声明末尾加一条，默认类型 `login`，默认生成可读 id | id 可清空；类型必须从 27 种里选 |
| 新增规则 | 建规则定义草稿，默认 `once=true`、`cooldown=0`、`mode=enter`、`dwell=0`、`timeout=-1` | `actions` 为空时不能应用 |
| 新增绑定 | 必须先选一个规则；默认绑定当前选中片段、`gate.at=0`、`control=observe` | 当前无片段时禁用 |
| 新增事件 | 当前片段必须存在；没有事件轨时走主时间轴建轨/建片段 | 不新建第二条时间轴 |
| 全部依赖 | 切到只读依赖总览，列出全部触发器前置、规则事实、调度事实 | 不显示运行态 |
| 筛选 | 按类型/id/片段/问题过滤；只 dim 不匹配节点，除非打开“只看匹配” | 不自动选中第一个匹配 |

工具条按钮在无文档、文档只读、目标缺失时禁用并给原因。

## 键盘与可访问性

- 树使用 roving tabindex；上下键移动，左右键展开/收起，Enter 进入详情，Esc 回树。
- `F2` 不提供内联重命名；改名走详情字段。
- 新增/删除走命令面板与工具条，不把快捷键写进全局分支。
- 树节点 `aria-label` 包含类型、id、目标片段/时间（事件）。
- 焦点环可见，不 `outline:none`。
- 抽屉打开时仍可操作主时间轴；面板不抢主轴快捷键。

## 错误隔离

- 面板内部错误只影响当前详情，树和其他面板继续工作。
- 单条记录解析失败：树行标 `!`，详情显示原文与错误，不阻止其他记录。
- 文档级 block：面板可打开，工具条新增/应用禁用，顶部显示原因。
- 断连：只影响读取/推送，不影响本地编辑；状态条显示“未连接模组”。

## 验收标准

1. 打开 `behavior`：根节点是当前脚本，显示触发器/规则/绑定/事件四组，不出现跨脚本总表。
2. 选中触发器：详情显示身份、条件、前置、时序、诊断；不显示片段目标字段。
3. 选中规则：显示定义字段和它的全部绑定；未绑定规则可见。
4. 选中绑定：显示目标片段、局部时间门、control、schedule、exit。
5. 选中事件：显示记录详情；点“定位片段”才改主选择。
6. 切换记录有未应用草稿：出现“应用/放弃/取消”，取消留在原记录。
7. 应用一条触发器：一次撤销恢复整条记录；不产生逐字段撤销。
8. 删除被绑定引用的规则：删除前列出绑定，不静默制造悬空绑定。
9. 触发器排序且存在缺省 id：先提示身份变化，再允许排序。
10. 关闭再打开抽屉：树展开和当前选择保留；文档未保存草稿走 04 守卫。
11. 面板内部抛错：其他面板和主轴仍可用，诊断有记录。
12. 检查：没有第二个 `behavior` 面板注册，没有第二套抽屉高度状态，没有 `localStorage` 直写。
