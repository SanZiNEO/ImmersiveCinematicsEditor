# 11-12 EVENT 事件记录

## 目标

把 `EVENT` 轨的 `objects.event` 做成离散事件记录编辑器：每条记录有片段局部时间、命令、可选移动目标。它不是采样曲线，不插值，不建第二时间轴。

EVENT 有两条消费路径：

- 服务端：按记录触发命令，对每个观看者执行；
- 客户端：带 `position` 的记录组成玩家移动路径。

编辑器只写记录，不执行命令、不驱动移动。

## 对象结构

```text
clip.objects.event:
{
  "value": { ... },              // 可选：对象级 event_type 等
  "keyframes": [
    { "time": 0.0, "value": { "command": "say start" } },
    { "time": 2.0, "value": { "position": { "dx": 3, "dz": 0 } } }
  ]
}
```

- `event` 是 `mode=event`、`type=event_record`，必须有 `keyframes`。
- 每条 keyframe：`time` 非负有限，严格递增；`value` 是事件记录对象。
- 一个片段只能有一个 `event` 对象；多条 EVENT 轨只给“建议最多 1 条”警告，不是硬错误；编辑器不新建第二条轨。
- `time` 是片段局部秒；全局事件时间 = 片段 `startTime` + `time`。
- `time > duration` 的记录在运行时编译期丢弃；编辑器对新建记录限制在时长内，对旧记录显示“超出时长，运行时丢弃”。
- 事件记录未知成员直接拒绝；不能塞任意键。

## 记录字段

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `command` | 否 | string | 命令原文；空串 = 占位，标记已触发但不执行 |
| `event_type` | 否 | string | 只接受 `command`；缺省取对象级，再缺省 `command` |
| `position` | 否 | object | 玩家移动目标；绝对 `{x,z}` 或相对 `{dx,dz}` |
| `id` | 否 | string | 运行时忽略；编辑器可作稳定键，保留原值 |

- `event_type` 不是枚举选择器的扩展点：当前只接受 `command`。其他值报错，运行期也会跳过。
- `command` 为空串是合法占位；不是“删除记录”。界面显示“占位：已触发，不执行”。
- `command` 不带前导 `/`；多条命令用 `&&` 分隔，由服务端逐段执行；单段失败不影响后续段。
- `id` 不参与运行时身份；不要用它做去重。运行时身份是 `(播放实例, 片段, 对象路径, 事件下标)`。
- `data` 不属于 EVENT；写 `data` 报错。

## 移动目标 position

```text
{ "x": 100, "z": 200 }     // 世界绝对坐标
{ "dx": 3, "dz": 0 }       // 相对脚本激活位置
```

- 必须恰好两个键，且只能是 `x`+`z` 或 `dx`+`dz`；两套混写、缺一个、多个键都报错。
- 只有水平 x/z，没有 y；纵向由玩家物理/地形决定。
- 绝对和相对不能同时写；运行时先看 `x`+`z`，但校验层拒绝混写，编辑器按模式二选一。
- 多个带 position 的记录 = 折线航点，按全局时间排序，相邻两点直线行走；不足两个目标不驱动移动。
- 相对坐标的基准是脚本激活位置（触发点），不是片段起点。
- 被方块挡住会停在挡住处；播完/停止停在最后目标；游戏暂停/编辑器预览不驱动。
- 宏观循环回到起点会复位航点索引；不清目标表。
- 移动是客户端行为；命令是服务端行为；同一条记录可以同时有 command 和 position。

## 时间与触发

- 首次推进从 `-inf` 开始，`time=0` 的记录在第一次推进时触发。
- 触发区间是 `(上次推进到的局部时间, 本次局部时间]`；每条最多触发一次。
- 片段循环、宏观循环、多入口不重放服务端 EVENT。
- `pingpong` 在 EVENT 上拒绝：事件没有反向时间语义。
- 显式 seek 前跳不补触发；后跳回退可重新触发目标之后的事件；目标及更早的记录不补触发。
- 片段循环若回到 0，不会重新触发已经 fired 的记录；需要重新触发必须显式 seek 或新实例。
- 事件命令按观看者集合执行；空 command 只标记 fired，不发命令。

## 行为页事件详情

```text
EVENT · intro · 3 条
├ 事件 1  t=0.0s   command: say start
├ 事件 2  t=1.5s   position: 绝对 (100, 200)
├ 事件 3  t=3.0s   占位（空 command）
└ 事件 4  t=4.0s   command: weather clear && time set day
```

每条记录编辑：

- 时间：秒，片段局部；显示全局时间换算。
- 命令：多行文本；空 = 占位；`&&` 提示；前导 `/` 警告。
- 移动目标：无 / 绝对 / 相对；绝对填 x/z，相对填 dx/dz；只显示两个输入。
- `event_type`：只读显示 `command`，不提供扩展下拉。
- `id`：可选高级字段；保留原值，不自动生成。
- 删除、复制、上下移动；复制保留时间和字段，需手动改时间避免相同。
- 排序：按 time 升序；不允许相同 time；插入时自动找空位或提示。
- 时间超出片段时长：阻止新建；旧记录红框“运行时丢弃”。

### 同一时刻多条命令

格式不允许相同 `time`，所以同一时刻多条命令必须合并成一条 `command`，用 `&&` 分隔。界面在时间冲突时给这个提示，不自动拆成多条。

## 事件列表与时间轴

- 行为页按片段分组显示 EVENT 记录；规则绑定、触发器不挂在事件上。
- 时间轴只放事件标记：位置 = 片段 startTime + event.time；标记不展开命令正文。
- 点击标记选中行为页对应记录；不自动 seek、不播放。
- 事件标记不新增第二时间轴，不改 02/05 的时间轴数据契约。
- 事件记录多时列表内部滚动；时间轴标记可重叠，悬停显示摘要。

## 摘要

- 纯命令：`t=1.5s · command say start`
- 纯移动：`t=2.0s · 移动到 (dx 3, dz 0)`
- 命令 + 移动：`t=2.0s · command … · 移动到 …`
- 占位：`t=3.0s · 占位`
- 超时长：`t=5.0s · 超出时长（运行时丢弃）`
- 前导 `/`：`command /say` 加警告标记。

## 校验

| 检查 | 级别 | 处理 |
|---|---|---|
| `event` 对象不是 mode=event / 无 keyframes | block | 对象红框 |
| 一个片段多个 `event` 对象 | block | 只允许一个 |
| 多条 EVENT 轨 | warn | “建议最多 1 条”，不阻止 |
| keyframe 缺 time/value | block | 帧红框 |
| `time` 负数/非有限/非递增 | block | 时间红框 |
| `time > duration` | warn | “运行时丢弃”；新建阻止 |
| 未知记录成员 | block | 只读报错 |
| `event_type` 非 command | block | 只读报错 |
| `command` 非字符串 | block | 命令框红框 |
| `command` 前导 `/` | warn | 提示去掉 |
| `position` 非对象/键不成对/混写 | block | 目标红框 |
| `position` 坐标非有限 | block | 目标红框 |
| `data` 出现在 EVENT | block | 报错 |
| `id` 非字符串 | block | 高级字段红框 |
| 删除唯一 EVENT 对象 | info | 片段变为无事件 |

## 验收标准

1. 新建 EVENT 记录：time=0、command 空占位；摘要显示“占位”。
2. `time=0` 记录在第一次推进触发；不是“等播放到 1 帧”。
3. `time=5` 超过 duration=3：新建被阻止；旧记录显示“运行时丢弃”。
4. 两条记录 time 相同：阻止；提示用 `&&` 合并命令。
5. `event_type` 选择器只有 `command`；写其他值报错。
6. 空 command 保存成功，显示占位；不删除记录。
7. `command` 前导 `/`：警告；保存保留原文。
8. `position {x:1,z:2}`：绝对目标；摘要“移动到 (1,2)”。
9. `position {dx:1,dz:2}`：相对激活位置；不按片段起点算。
10. `position {x:1,dz:2}` / 三个键 / 只有一个键：block。
11. 只有一条 position 记录：允许保存，但提示“不足两个航点，不驱动移动”。
12. 多条 position 记录：按全局时间排序成折线；时间轴标记可重叠。
13. 片段循环回到 0：已 fired 的 EVENT 不重放；界面不承诺“循环重播”。
14. `pingpong` 用在 EVENT：block。
15. 显式 seek 前跳：目标及更早事件不补触发；后跳回退：目标之后可再触发。
16. 多条 EVENT 轨：warn，不自动合并、不新建第二轨。
17. 保存重开：time/command/position/id 原样恢复。
