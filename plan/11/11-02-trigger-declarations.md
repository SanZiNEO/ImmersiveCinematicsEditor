# 11-02 触发器声明、身份与脚本图摘要

## 目标

把 `meta.triggers` 作为“当前脚本的触发器”完整接进行为页，并让 05 脚本图节点的悬停摘要显示全部触发器和全部条件，包括跨脚本前置。

不新增触发器类型、动作数组或目标字段；不改图数据契约；不另开脚本图页。

## 字段面

`meta.triggers[]` 每条触发器：

| 字段 | 必填 | 类型/范围 | 缺省 | 行为页位置 |
|---|---|---|---|---|
| `id` | 否 | `[A-Za-z0-9_]{1,64}`，脚本内唯一 | 无 | 身份 |
| `type` | 是 | 27 种触发器类型之一 | 无 | 身份 |
| `conditions` | 否 | 条件对象，结构随类型 | `{}` | 条件 |
| `requires` | 否 | 前置数组；字符串或对象 | `[]` | 前置 |
| `repeatable` | 否 | bool | false | 时序 |
| `delay` | 否 | 秒，>=0 | 0 | 时序 |
| `on_enter` | 否 | bool | false | 时序 |
| `exit_buffer` | 否 | 秒，>=0 | 0 | 时序 |
| `poll_interval` | 否 | tick，1–600；仅轮询类 | 继承 | 时序 |
| `continuity` | 否 | `sweep` / `dwell` / `window` 对象 | 关闭 | 时序 |

触发器没有 `actions` 字段，也没有 `target` 字段。当前脚本解析后固定生成一个 `play_script` 动作：把本脚本播放给触发者本人。

## 身份

- 显式 `id` 优先；合法字符集为字母、数字、下划线，1–64 位。
- 未写 `id` 时，运行时身份为 `type#声明下标`。
- 列表显示：
  - 有 id：`location · gate_taiga`
  - 无 id：`location · location#2`，并标“身份随声明下标”。
- 同一脚本内重复 id 直接报错，阻止保存/推送。
- 改 `id` 会改变非重复触发器的去重身份；应用前提示“已触发记录不会迁移”。
- 触发器排序会改数组下标；存在无 id 触发器时，排序前必须确认。

## 声明详情

### 身份区

- `id` 输入框；可清空，清空后显示生成身份。
- `type` 下拉：27 种按代码顺序，不用中文分组重排；可搜索。
- 类型改变时不静默丢旧条件：
  - 旧条件里不适用于新类型的键保留在“旧字段”只读块；
  - 用户可确认“清理不适用字段”或继续保留；
  - 应用时必须通过当前类型校验。
- 显示声明下标、重复 id 状态、未知类型状态。

### 触发后

一张只读卡：

```text
触发后：播放本脚本给触发者本人
```

- 不提供动作选择器；
- 不提供目标选择器；
- 不提供“all / all_except_trigger”；
- 不显示可编辑的 `play_script` 对象。

这是当前脚本格式的固定行为，不是本轮的配置项。

### 条件与前置

- 条件树编辑见 `11-04`；
- 前置编辑见 `11-05`；
- 详情里条件和前置分开，不能把 `requires` 渲染成 `conditions` 的子节点。

### 诊断

- 未知类型；
- 重复 id；
- 空条件且前置也为空：info“只靠事件/轮询类型本身触发”；
- 条件字段不适用于当前类型；
- 前置缺失、自引用、自定义只读；
- 时序字段不适用于当前类型。

## 触发器列表摘要

每行固定显示：

```text
[类型] [id 或 type#index] [可重复/单次] [条件 N] [前置 N] [最高问题级别]
```

- 条件 N 是条件树叶子数量，不把组合器算成叶子。
- 前置 N 是 `requires` 条目数量。
- 有 `delay` 时加“延迟 x.xs”；有 `continuity` 时加“连续”徽标。
- 不显示运行态“已触发/未触发”。

## 脚本图悬停摘要

### 位置

接在 05 的脚本图节点悬停卡里，不新开图页，不改节点、边、布局、图数据契约。

悬停卡新增/替换“触发器”区：显示当前脚本**全部**触发器，而不是只显示数量或类型。

### 数据来源

- 节点卡片仍用 `script.graph` 的摘要（名称、路径、时长、轨道、触发器数量、前置边）。
- 悬停 250ms 后，按需通过现有只读读脚本通道取当前脚本的 `meta.triggers`，缓存触发器摘要。
- 只读，不进入文档页、不建脏文档、不触发未保存保护。
- 缓存按 `path + 文件版本/刷新版本` 失效；`script.graph.invalidated` 后丢弃。
- 读取失败时退回节点已有摘要：显示类型、可重复、前置；条件区显示“读取失败，条件暂不可用”，不伪造。

### 内容

```text
触发器（2）

1. location · 可重复 · delay 1.5s
   条件：
     全部满足
       ├ 位于 主世界 · 球形 (10,64,20) r=5
       └ 生物群系 = minecraft:taiga
   前置：
       ├ script_played → chapter1（已解析）
       └ script_started → chapter2（缺失）

2. any · 单次
   条件：
     任一满足
       ├ advancement = story/enter
       └ 玩家登录
   前置：
       无
```

规则：

- 全部触发器都列出，不按数量截断、不只显示前三个。
- 每个触发器都展开完整条件树；`all_of` = “全部满足”，`any` = “任一满足”，递归缩进。
- 叶子条件用固定中文摘要，和 `11-04` 共用同一套格式化规则。
- `requires` 挂在对应触发器下面，显示 `type → 目标脚本`。
- 前置状态：
  - `已解析`：目标脚本存在且唯一；
  - `缺失`：目标不存在；
  - `自引用`：目标等于当前脚本；
  - `重复 id`：目标 id 不唯一，无法确定；
  - `自定义前置，只读`：不是内置三种脚本前置。
- 没有条件：显示“无场景条件”。
- 没有前置：显示“无前置”。
- 未知条件类型：显示 `未知条件 type` + 原始字段，只读，不猜。
- 内容多时卡片内部滚动；不把触发器或条件折叠成“+N”。
- 卡片不出现输入框、下拉、删除按钮。

### 入口

悬停卡底部提供：

- `定位到触发器`：先在悬停卡里选中一个触发器块；未选时按钮 disabled。打开当前脚本，切到 `document` 页，行为页选中该触发器；不自动播放、不 seek。
- `打开脚本`：沿用 05-03 的打开流程，不额外选触发器。

### 诊断模式

- 默认不显示触发器内部身份细节，只显示类型 + id/生成身份。
- 诊断模式可显示声明下标、条件叶子数、`requires` 下标。
- 诊断模式不改变卡片布局，不把内部 id 铺到普通作者视图。

## 与 05-03 的关系

本文件落地时同步修订 `05-03` 的“悬停摘要”一节：

- 原“触发器只显示 type / repeatable / requires”改为“显示全部触发器与全部条件”；
- 原“requires 明细”保留，但明确挂在对应触发器下；
- 增加“全部条件树、未知类型只读、无截断滚动、定位到触发器”；
- 不改 05-03 的节点卡尺寸、打开流程、上下游高亮与键盘合同。

## 本地校验

| 检查 | 级别 | 处理 |
|---|---|---|
| `type` 缺失/未知 | block | 类型行红框；不允许应用 |
| `id` 非法字符/超长 | block | 身份行红框 |
| `id` 重复 | block | 两个触发器都标；不允许应用 |
| `id` 清空且排序 | warn | 身份随下标变化，排序前确认 |
| 条件字段不适用于当前类型 | warn/error | 旧字段只读块；“清理/保留” |
| `requires` 空字符串 | block | 前置行红框 |
| `requires` 目标缺失 | warn | 前置行“缺失”，不阻止保存 |
| `requires` 自引用 | warn | 前置行“自引用” |
| `requires` 目标重复 id | warn | “重复 id，无法确定” |
| 触发器动作被写成可配置 | block | 面板不提供该入口；发现旧字段不显示为可编辑 |

## 验收标准

1. 新建触发器默认 `login`，生成可读 id；清空 id 后列表显示 `login#0`。
2. 27 种类型都能在下拉中找到；顺序与代码一致，不按中文分组重排。
3. 重复 id 两个触发器：列表都标重复，应用被阻止。
4. 触发器没有动作/目标字段：详情只有只读“播放本脚本给触发者本人”，没有下拉。
5. 改变类型：旧条件不静默丢；出现“旧字段”只读块和清理入口。
6. 列表行显示类型、id、可重复、条件数、前置数、最高问题级别。
7. 脚本图悬停：全部触发器可见；每个触发器完整条件树与前置可见；不截断。
8. 悬停卡里 `all_of` 嵌套 `any`：缩进正确，叶子摘要可读。
9. 缺失/自引用/自定义前置：分别显示“缺失 / 自引用 / 自定义前置，只读”，不画假边。
10. 读取脚本失败：悬停仍显示节点摘要，条件区显示读取失败，不编默认条件。
11. 点“定位到触发器”：打开脚本并选中该触发器，不播放。
12. 检查：05 图数据契约未新增字段；没有新增消息；没有新增脚本字段。
