# 11-06 规则定义与策略

## 目标

把脚本级 `rules[]` 做成规则定义表：每条规则 = 条件树 + 动作集 + 策略。规则定义本身不绑定片段；同一规则可以被多条 `rule_bindings` 复用，每条绑定各自独立运行。

11-06 只定义规则定义与策略字段；条件树见 `11-07`，动作见 `11-08`，绑定见 `11-09`。

## 字段面

```text
rules[]:
  id          必填，字符串，脚本内唯一
  condition   必填，条件对象
  actions     必填，非空数组
  policy      可省，对象
```

`policy` 字段：

| 字段 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `once` | bool | true | 成功后不再触发 |
| `cooldown` | float 秒 | 0 | 触发后静默时长，>=0 |
| `mode` | enum `enter` / `dwell` | `enter` | 瞬时边沿 / 驻留成立 |
| `dwell` | float 秒 | 0 | 驻留阈值，>=0 |
| `timeout` | float 秒 | -1 | 等待上限；>0 或 -1 |
| `on_timeout` | 动作数组 | 空 | 超时动作，可为空 |

- `id` 合法形态 `[A-Za-z0-9_]{1,64}`，与片段 id 同字符集。
- `policy` 是键白名单；未知键报错。
- `condition` 保留原始对象，不在定义层解析；条件树校验见 `11-07`。
- `actions` 至少一个动作；空数组不能应用。
- `on_timeout` 可以为空，不受“至少一个”限制。

## 规则定义详情

右侧详情按顺序：

```text
规则定义
├ 身份：id / 绑定数 / 复用状态
├ 条件：条件树（11-07）
├ 动作：动作列表（11-08）
├ 策略：once / cooldown / mode / dwell / timeout / on_timeout
├ 绑定：该规则下的绑定（11-09）
└ 诊断
```

### 身份

- 显示规则 id、被多少条绑定引用、是否未绑定。
- 改 id 是事务性重命名：
  - 新 id 必须合法且脚本内唯一；
  - 同时更新所有 `rule_bindings[].rule`；
  - 一次撤销回到旧 id 和旧引用；
  - 任一绑定更新失败则整体不应用。
- 删除被引用的规则：
  - 默认禁用删除；
  - 列出引用它的绑定；
  - 要求先删除或迁移绑定；
  - 不静默制造悬空绑定。

### 条件

- `condition` 必填对象；不能为空 `null`、字符串、数组。
- 条件树根可以是叶子，也可以是 `all_of` / `any`。
- 条件树为空对象时，按“永不满足”处理并显示错误；不自动改成恒真。
- 规则条件树的时间/事实语义见 `11-07`。

### 动作

- `actions` 至少一个；列表为空时“应用”禁用。
- 动作顺序 = 执行顺序；可上下移动。
- 动作类型九种，见 `11-08`；不放触发器动作，不放 `hold`。
- 单条动作异常不阻止后续动作；编辑器不显示“全部成功”。

### 策略

#### once

- 缺省 true；成功后该激活不再触发。
- 与 `cooldown` 同时存在时：`once` 成功即终态，`cooldown` 只对未成功的重复触发有意义；界面给 info，不删字段。
- 关掉 `once` 后，规则可重复触发，仍受 `cooldown` 和条件边沿/驻留约束。

#### cooldown

- 单位秒，>=0；触发后静默时长。
- 不影响已经成功的 `once` 终态。
- 0 表示不静默。

#### mode

- `enter`：条件从不成立到成立瞬间触发；缺省。
- `dwell`：条件连续成立达到 `dwell` 秒才触发。
- 切到 `dwell` 时显示驻留秒数；切回 `enter` 时保留 `dwell` 值但禁用，不静默清零。
- `dwell=0` 时仍按驻留模式，实际等同立即；给 hint，不自动改成 `enter`。

#### timeout

- `timeout>0`：从过了 `gate.at` 开始计时，到点仍未成功，执行 `on_timeout` 一次。
- `timeout=-1`：无限等待；`on_timeout` 禁用但保留已有内容，提示“不会执行”。
- 0 非法；不允许用 0 表示“立即超时”。
- 超时与“条件成功”是两件事：超时后仍可能被后续条件成功？按运行时终态处理；编辑器只说明“超时动作执行一次”。

#### on_timeout

- 动作数组，可为空；动作类型同 `actions`。
- 无超时时不可新增，已有内容保留只读。
- 超时动作执行后，规则进入终态；不再重复执行。

## 规则列表

每行：

```text
[规则 id] [动作 N] [once/可重复] [enter/dwell] [timeout 有/无] [绑定 N] [最高问题]
```

- 未绑定规则显示“未绑定”，不隐藏。
- 规则按声明顺序；不按绑定数量或名称排序。
- 规则行可展开其绑定子节点；展开状态只存面板会话。

## 新增 / 复制 / 删除

### 新增

- 默认 id `rule_1`、`rule_2`…，冲突时递增；允许手改。
- 默认 `condition={}`，但空条件在应用时是错误；新建后先引导加条件。
- 默认 `actions=[]`；应用前必须至少一个动作。
- 默认 `once=true`、`cooldown=0`、`mode=enter`、`dwell=0`、`timeout=-1`、`on_timeout=[]`。
- 新增规则不自动建绑定。

### 复制

- 复制规则定义，新 id 加 `_copy` / 递增后缀。
- 不复制绑定；绑定是“规则 × 片段”的关系，复制规则不等于复制入口。
- 复制后原规则和副本独立。

### 删除

- 无绑定时可直接删。
- 有绑定时禁用，列出绑定；支持“迁移绑定到另一规则”后再删。
- 删除规则不删其条件/动作以外的任何片段字段。

## 校验

| 检查 | 级别 | 处理 |
|---|---|---|
| `rules` 不是数组 | block | 规则区红框 |
| `id` 缺失/空/非法/重复 | block | 身份行红框 |
| `condition` 缺失/非对象/空对象 | block | 条件区红框 |
| `actions` 缺失/非数组/空数组 | block | 动作区红框；应用禁用 |
| `policy` 非对象 | block | 策略区红框 |
| `policy` 未知键 | block | 未知键只读错误 |
| `once` 非 bool | block | 策略行红框 |
| `cooldown<0` / 非有限 | block | 策略行红框 |
| `mode` 非 `enter/dwell` | block | 策略行红框 |
| `dwell<0` / 非有限 | block | 策略行红框 |
| `timeout` 非 `-1` 且不 `>0` | block | 策略行红框 |
| `on_timeout` 非数组 | block | 超时动作区红框 |
| `timeout=-1` 且有 `on_timeout` | info | “不会执行”，保留 |
| 规则 id 重命名冲突 | block | 整体不应用 |
| 删除被绑定规则 | block | 列出绑定，要求先迁移/删除 |
| 未绑定规则 | info | 显示“未被任何绑定使用” |

## 验收标准

1. 新建规则：默认 id、once、cooldown、mode、dwell、timeout 正确；actions 为空时不能应用。
2. 规则 `condition` 为空对象：显示错误，不自动变成恒真。
3. 规则编辑 id：所有绑定 `rule` 同步更新；一次撤销恢复旧 id 和引用。
4. 规则 id 重复：阻止应用，两个规则都标。
5. 删除被两条绑定引用的规则：默认禁用，列出两条绑定。
6. `once=false`：显示“可重复”；与 cooldown 同时可见，不合并。
7. `mode=dwell`、`dwell=2`：显示驻留 2s；切回 enter 保留值但禁用。
8. `timeout=-1`：显示“无限等待”；on_timeout 禁用，已有动作只读。
9. `timeout=3` + on_timeout：显示“过 gate 后 3s 执行一次”。
10. `actions=[]`：应用禁用；`on_timeout=[]` 允许。
11. 未绑定规则可见，不自动删除、不自动建绑定。
12. 保存重开：规则字段和绑定引用原样恢复。
