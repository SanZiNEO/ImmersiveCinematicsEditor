# 11-03 触发器时序与连续语义

## 目标

把触发器的 `delay`、`repeatable`、`on_enter`、`exit_buffer`、`poll_interval`、`continuity` 六个时序/连续字段接进行为页，并明确它们分别在什么类型上有效。

这些字段改变“什么时候触发”，不改变条件本身；编辑器只写字段和提示，不替作者推断运行时状态。

## 字段表

| 字段 | 类型 | 范围/缺省 | 说明 | 落点 |
|---|---|---|---|---|
| `delay` | float 秒 | >=0，缺省 0 | 命中后延迟执行动作 | 时序“延迟” |
| `repeatable` | bool | 缺省 false | 是否可重复触发 | 时序“重复” |
| `on_enter` | bool | 缺省 false | 只在进入瞬间触发 | 时序“进入边沿” |
| `exit_buffer` | float 格 | >=0，缺省 0 | 离开判定区域外扩 | 时序“离开外扩” |
| `poll_interval` | int tick | 1–600，缺省继承 | 轮询类生效间隔 | 时序“轮询” |
| `continuity` | object | 缺省关闭 | 扫掠 / 停留 / 事件窗口 | 时序“连续语义” |

## 延迟

- `delay` 单位秒，写入时转成运行时毫秒；0 = 立即执行。
- 同一触发器已有延迟项时，不重复排队；界面提示“已有待执行，本次命中只记录事实，不再排队”。
- `delay` 不影响条件求值，只影响动作执行时点。
- 延迟期间脚本被结束、实例被暂停或播放切换，队列按运行时处理；编辑器不显示“必然执行”。

## 重复

- `repeatable=false`：按“玩家 + 脚本 + 触发器”只触发一次；已触发事实持久，换会话不自动清。
- `repeatable=true`：允许再次触发；仍受 `on_enter` 的离开复位和 `delay` 的排队去重约束。
- `repeatable=false` 时列表加“单次”徽标；`repeatable=true` 加“可重复”。
- 改 `repeatable` 不迁移已触发事实；应用前提示“历史已触发记录不重置”。

## 进入边沿

- `on_enter=true`：只在 false→true 的进入瞬间触发；离开并复位后才能再次进入。
- 事件驱动触发器没有离开事件，进入态不会复位；写 `on_enter` 实际等价于“只触发一次”。
- 对 `death`，校验器明确报“on_enter 无效，事件驱动没有进入/离开语义”，界面不显示可编辑开关，只保留旧值只读块。
- 对轮询类，`on_enter` 可用；是否真的需要由作者决定，界面给“进入边沿”说明，不自动改成 `repeatable=false`。
- `on_enter` 与 `repeatable` 可以同时存在；两者叠加时以运行时为准，界面不擅自简化。

## 离开外扩

`exit_buffer` 只在同时满足下面条件时可编辑：

1. `on_enter=true`；
2. 触发器是轮询类；
3. 条件根对象有可外扩的空间区域：
   - `position` + `radius`（球形）；
   - `corner1` + `corner2`（方体）。

不满足时：

- 控件禁用，显示原因；
- 已有非零值保留在“旧字段”只读块，不静默清零；
- 校验器已经报无效的，按 error/warn 展示。

运行时用原条件外扩一份退出条件，脚本里没有独立的 `exit_conditions` 字段；编辑器不新增这个字段。对 `facing` / `all_of` / `any` / `death` 明确不可用。

## 轮询间隔

- `poll_interval` 是触发器级 tick 值，1–600。
- 只对轮询类触发器有效；事件驱动类写这个字段会被校验器报“无效，将被忽略”。
- 继承链：触发器 `poll_interval` → 脚本 `meta.trigger_poll_interval` → 类型默认。
- 行为页显示“生效：20 tick（1.0s）· 来源：触发器/脚本/类型”，只读；要改脚本缺省去 Script Properties 的“触发器缺省”卡。
- 事件驱动类显示“事件驱动，不轮询”，不显示可编辑输入。
- 组合器按子条件的轮询需求运行；界面只显示生效值，不让作者手算。

## 连续语义

`continuity` 是对象，三个字段都可省：

```text
{
  "sweep": true,
  "dwell": 20,
  "window": 40
}
```

### sweep

- 把相邻两次采样之间的运动近似成线段/最短弧，判断这段运动是否碰到条件区域。
- 只对 `location` / `structure` / `facing` / `observation` 有几何语义。
- 其他类型显示“无几何语义，将被忽略”，禁用开关；已有值保留只读。
- `sweep=true` 不改变点判定结果；点命中仍优先为真。

### dwell

- 停留门槛，单位 tick，0–1200；0 = 无门槛。
- 只对轮询类有效；事件驱动类显示“不参与轮询，将被忽略”。
- 界面同时显示秒数换算（20 tick = 1s），落盘仍是整数 tick。
- `dwell>0` 时，条件中途断掉会清零累计；编辑器不画“停留进度条”，只写字段。

### window

- 事件类子条件的回看窗口，单位 tick，0–1200；0 = 不启用。
- 只对 `all_of` / `any` 生效；其他类型显示“只对组合器生效”。
- 只作用于组合器内的事件类子条件；不把普通轮询叶子变成窗口判定。
- 界面在组合器节点上显示“事件窗口 W tick”，叶子节点不重复显示。

### 关闭与保留

- 三个字段全为 0/false 等价于未声明；应用时可省略整个 `continuity`，不写空对象。
- 已有未知键保留在只读高级块，不静默删除；已知键按上面规则编辑。
- 超过 1200 tick、非整数、非数字：就地报错，不夹取。

## 求值顺序提示

行为页时序区固定显示一条只读说明：

```text
前置全部满足 → 检查是否跳过（同脚本播放中 / 单次已触发）→ 条件求值 → 记录事实 → 延迟排队 → 执行动作
```

- 事件驱动入口没有离开事件，`on_enter` 只推进进入态，不复位。
- 同脚本正在播放时，本触发器跳过；跨脚本不阻塞。
- 单条动作失败只跳过该动作，不中断后续动作；编辑器不显示“动作全部成功”。

## 校验

| 检查 | 级别 | 处理 |
|---|---|---|
| `delay` 负数/非有限 | block | 延迟行红框 |
| `poll_interval` 非整数/越界 | block | 轮询行红框 |
| 事件驱动写 `poll_interval` | warn | 显示“无效，将被忽略” |
| `on_enter=true` 且 `death` | warn | 显示“只触发一次，建议用 repeatable” |
| `exit_buffer>0` 但无 `on_enter` | warn | 显示“不参与离开判定” |
| `exit_buffer>0` 但条件无球/方体 | warn | 显示“没有可外扩区域” |
| `continuity.sweep` 非几何类型 | warn | 显示支持类型 |
| `continuity.dwell>0` 事件驱动 | warn | 显示“不参与轮询” |
| `continuity.window>0` 非组合器 | warn | 显示“只对 all_of/any” |
| `continuity` tick 非整数/越界 | block | 连续语义行红框 |
| 未知 `continuity` 键 | info | 只读高级块，不删除 |

## 验收标准

1. `delay=1.5`：保存为 1500ms 语义；同触发器连续命中，界面提示已有待执行，不重复排队。
2. `repeatable=false`：列表显示“单次”；改 true 后提示历史记录不重置。
3. 轮询类 `on_enter=true`：显示进入边沿；离开并复位后可再次进入。
4. `death` + `on_enter`：显示“事件驱动无进入/离开语义，等于只触发一次”，不提供编辑开关。
5. `location` + 球形区域 + `on_enter`：`exit_buffer` 可编辑；填 2 格后显示外扩提示。
6. `facing` / `all_of` / `any` 填 `exit_buffer`：显示无效，值保留只读。
7. 事件驱动写 `poll_interval`：显示“事件驱动，不轮询”，输入禁用。
8. `continuity.sweep` 在 `advancement`：显示“无几何语义”，不写新值。
9. `continuity.dwell=20`：显示 1.0s，落盘仍是 20 tick。
10. `continuity.window=40` 在 `all_of`：组合器显示事件窗口；叶子不重复显示。
11. `continuity.dwell` 非整数/1300：就地报错，不夹取。
12. 保存重开：六个字段原样恢复；未知 `continuity` 键保留。
