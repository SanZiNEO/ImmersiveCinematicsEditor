# 14-08 Forge 真实游戏垂直切片

> 前置：14-01～14-07 宿主链可运行
> 后续：14-09 全功能迁移（本文件是门禁）
> 状态：设计合同；真实游戏未执行时不填 PASS

## 1. 职责

在真实 Forge 1.20.1 客户端里跑通一条最小但完整的 AUI 编辑器链路，证明宿主链不是纸面设计：

加载器 → F6 → AUI Screen → GPU 画面 → 进程内信号 → 读取/编辑/保存 → 播放 → 飞控 → 关闭/世界退出。

本文件不证明 02～12 所有面板都迁移完成；那是 14-09。但没有本文件的 PASS，14-09 不能开始。

## 5. 记录格式

```text
步骤：
结果：NOT RUN / PASS / FAIL / BLOCKED
证据：
失败归属：14-0N / 01–12 原轮 / 13
备注：
```

规则：

- 未跑 = `NOT RUN`，不写 `PASS`。
- 构建成功 ≠ 真游戏通过。
- 菜单存在 ≠ 功能通过。
- 静态截图 ≠ 连续帧/GPU 零拷贝通过。
- 失败必须回原任务修，不能在 14-09 里“顺手补”。
