# 06-09 片段属性面板

## 目标

把 05 的 `selection.properties` 从选择摘要面板改成完整的 `ClipPropertiesPanel`：显示当前片段的全部可编辑属性，按效果组排列；静态值、未设置值和片段基础参数都在这里。效果面板只显示已有关键帧的属性，属性面板不重复显示这些行。

## 面板定位

- panelId 保持 `selection.properties`，manifest 标题改为“属性”。
- 槽位保持 `document.right`，`minWidth=280`、`maxWidth=560`、`singleton=true`、`keepAlive=true`。
- 面板是片段级，不是单个节点的检查器；选中叶子/节点只影响展开、高亮和滚动，不切成单属性页。
- 没有局部标尺、没有节点轴、没有关键帧组、没有“添加属性”选择器。
- 面板从片段摘要开始，覆盖 `clip.objects` 属性；不存在只编辑 `meta` 的独立属性路径。

## 四态

| 态 | 条件 | 显示 |
|---|---|---|
| `none` | 无 `clipKey` | “在时间轴选择一个片段” |
| `multi` | `clipKeys.length>1` | “N 个片段”；主选片段名；不展开第一个 |
| `clip` | 唯一有效 `clipKey` | 完整属性面板 |
| `invalid` | `clipKey` 失效 | 失效原因 + 撤销恢复 + 回到时间轴 |

`clip` 态且轨道无任何适用属性：显示“该轨道没有可编辑字段”，不发“添加属性”按钮。

- 头部和工具栏固定；组列表纵向滚动。
- 组头 28px；普通行 32px；未设置行 32px；错误展开 +24px。
- 面板宽 `<360px` 时标签在上、控件在下；`≥360px` 时两列：标签 `minmax(88px,42%)`，控件剩余。
- 组头吸顶；100+ 行纵向虚拟化，上下各留 6 行缓冲。
- 面板不横向滚动；STRUCT/JSON 详情在行内展开，超长文本自身换行。

## 片段摘要

`ClipPropertiesHeader`：

- 片段名：`label/name/id`，双击进入行内改名（走片段元数据命令，不改 `objects`）。
- 片段 ID：只读；无 id 显示“无 id”。
- 轨道：`track.label` + `track.type`。
- 起点/时长：有限 `start_time–start_time+duration`；无限 `∞`；循环 `×N`。
- 起点/时长后显示“在时间轴编辑”，点击聚焦 05 时间轴对应片段；本面板不直接改时间几何。
- 校验徽标：block/error/warn/info；点击滚到 06-10 诊断。
- 脏标记：`docRevision` 与保存回执不一致时显示“未保存”。

## 属性行集合

```ts
buildPropertyRows({ clip, trackDef, playheadLocal }): PropertyRow[]
groupPropertyRows(rows, trackDef): EffectGroup[]
partition(groups, panelMembership): {
  effectGroups: EffectGroup[]
  propertyGroups: EffectGroup[]
}
```

属性面板显示 `propertyGroups`：

- `leaf`（默认）：组内 `keyframes.length>0` 的叶子已被 `partition` 移入效果组；属性组只剩无帧叶子。若整组叶子都有帧，组头不显示。
- `group`：组内任一叶子有帧，整组进效果组；属性面板不显示该组。
- 组内还剩静态叶子时，组头显示“N 项在效果面板”徽标；点击徽标定位效果面板对应组。
- 属性面板不显示已有关键帧的叶子行；它们只在效果面板出现，避免同一属性两个值控件。
- 未知路径：`未知/扩展`组只读；无帧时留在属性面板，有关键帧时按策略进效果面板。
- 未设置叶子：`present=false` 仍显示；不因未设置隐藏。

### 行类型

| 行状态 | 值控件 | 右侧 | 说明 |
|---|---|---|---|
| `VALUE`，已设置 | 静态值 | `值` 徽标 | 没有时钟 |
| `VALUE`，未设置 | “未设置”占位 | `未设置` 徽标 | 编辑即创建对象 |
| `ANIMATED`，`keyframes=[]` | 静态值 | 时钟“添加首帧” | 显示“动画轨道无帧” |
| `ANIMATED`，有帧 | 不显示行 | `在效果面板` | 只在效果面板 |
| `EVENT`，`keyframes=[]` | 不显示值 | “添加首条记录” | 首条记录后进效果面板 |
| `EVENT`，有记录 | 不显示行 | `在效果面板` | 只在效果面板 |
| `STRUCT` | 专用/JSON 编辑器 | `静态` 徽标 | 没有时钟 |
| 未知路径 | 只读 JSON 摘要 | `未知` 徽标 | 不能编辑 |

## 静态值编辑

- `VALUE`：`object.setValue`；提交后行仍留在属性面板。
- 未设置叶子：输入 → `object.add` + `setValue` 一次完成；初始值来自输入，不用默认值冒充作者输入。
- `ANIMATED` 且 `keyframes=[]`：`object.setValue` 写静态 `value`；不自动建帧、不自动改 `mode`。
- `STRUCT`：原样透传；不重排键、不补默认、不删空数组。
- 类型/范围校验同 06-03；失败不写文档、不增加撤销项。
- 连续输入 600ms 合并撤销；失焦/回车结束。
- 静态值编辑不改变面板归属；只有出现关键帧才迁移。

## 开启动画

属性面板中 `ANIMATED` 叶子显示时钟：

```text
[时钟] 开 → object.enableAnimation
  首帧初值：同属性播放头最近节点 → 当前 value → schema default
  都没有 → 内联 default_missing，要求先输入静态值
```

- 首帧创建在播放头局部时间；创建成功后：
  - 叶子进入效果面板；
  - 属性面板该行消失；
  - 若同组还有静态叶子，组头保留并显示“1 项在效果面板”；
  - 焦点移到效果面板对应行，属性面板保留滚动位置；
  - 一次撤销恢复属性和焦点。
- `ANIMATED` 且 `keyframes=[]` 的时钟显示“添加首帧”，不是“关闭动画”。
- `VALUE` / `STRUCT` 不显示时钟。
- `EVENT` 显示“记录”入口，不显示时钟。

## 关闭动画后的回流

关闭动画只从效果面板发起（行菜单 `object.disableAnimation`）。成功后：

- 叶子 `keyframes=[]`，保留确定 `value`；
- 叶子回到属性面板，显示静态值和“动画轨道无帧”；
- 属性面板按原组顺序插入，滚到该行并聚焦；
- 组头“在效果面板”计数减一；
- 一次撤销恢复效果面板行、节点和焦点。

删最后一帧同样回流；属性面板不主动删对象，不把 `keyframes=[]` 变成未设置。

## 未设置与缺失字段

- 未设置叶子始终在属性面板；不进入效果面板。
- 必填叶子缺失：行显示 `必填未设置` + 错误边框；不弹“添加属性”对话框。
- 编辑未设置叶子：创建 `clip.objects[path]`，按 03-02 形态写 `value`。
- `requires` 未满足：行显示依赖路径与“去设置”；控件禁用；不改 schema。
- 未知路径：只读；不提供“删除未知字段”快捷操作。

## 选择联动

- 选中片段：展开全部组，滚到上次位置。
- 选中叶子：展开所在组，滚到该行并高亮；若该叶子在效果面板，显示顶部 `在效果面板` 条 + 定位按钮，不重复行。
- 选中节点（`{path,time}`）：属性面板高亮对应叶子；若叶子在效果面板，条上显示“节点 2.35s”；不显示节点值。
- 选中图节点/规则/绑定：属性面板显示“当前选择不是片段属性”，提供回到片段选择的入口。
- 选择只改高亮/滚动/展开，不切单属性页，不重建文档。

## 过滤

| 控件 | 行为 |
|---|---|
| 搜索 | 按路径/标签/组名过滤；匹配组展开；无匹配显示“没有匹配字段” |
| 只看未设置 | 只显示 `present=false` 或必填缺失行 |
| 折叠全部 | 折叠所有组；当前选中叶子组保持展开 |
| 清除 | 恢复默认展开和过滤 |

过滤不改行集合、不删对象、不影响效果面板。

## 性能

- 100+ 组/500+ 行：只渲染可见行；组头计数仍按全量。
- 搜索/过滤后重算可见窗口，不重建 `PropertyRow` 文档视图。
- 展开 STRUCT 详情只渲染当前行；不展开全部 JSON。
- 面板宽度变化时重排行布局，不改变滚动锚点行。

## 验收

1. 选择片段：属性面板显示全部适用组/叶子；已有关键帧的叶子不在属性面板，显示“在效果面板”计数。
2. 未设置 `position.y`：显示“未设置”；输入 2 后创建对象并写值；一次撤销恢复未设置。
3. `VALUE` 的 `opacity` 改值：仍在属性面板；不出现时钟。
4. `ANIMATED` 的 `yaw` 无帧：显示值 + “添加首帧”；点时钟后进入效果面板，属性面板行消失。
5. 效果面板关闭 `yaw` 动画：yaw 回到属性面板，显示静态值；组头计数减一；一次撤销恢复。
6. `EVENT` 空记录：显示“添加首条记录”；创建后进入效果面板；属性面板不再显示该行。
7. `STRUCT` 的 `modifier`：专用编辑器可用；没有时钟；原样保存。
8. 未知路径 `foo.bar` 无帧：只读“未知”组；不能改值；不影响其他行。
9. 搜索 `position`：展开位置组；匹配行高亮；效果面板行不被当成属性行。
10. 100+ 行滚动：只渲染可见行；组头吸顶；滚动不卡顿。
11. 面板宽 280px：标签/控件上下排列；无横向滚动；值控件可用。
12. 选中效果面板节点：属性面板显示“在效果面板 / 节点 2.35s”条；不复制节点轴。
13. 片段无属性：显示“该轨道没有可编辑字段”；无添加器。
14. 多选片段：显示多选摘要；不把第一个片段当唯一片段展开。
