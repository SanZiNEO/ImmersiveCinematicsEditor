# 片段属性面板

> 状态：已实现（偏差见 §六）
> 范围：`selection.properties` 从选择摘要改为片段属性面板：全部适用属性、静态值与未设置值、时钟、关闭动画后的回流、选择联动、过滤与虚拟化
> 关联：06-01 效果面板外壳、06-02 组与行、06-03 值控件、06-05 迁移、06-10 诊断

## 一、摘要

属性面板是片段属性的完整清单：当前轨道所有适用叶子都在这里，包括从未设置过的、等于默认值的、以及动画轨道暂时没有帧的。它同时承担开启动画的入口——作者在这里找到属性、改静态值或点时钟，属性第一次出现关键帧后才搬去效果面板。本文定义这个面板该列什么、不列什么，以及关闭动画后属性如何回到这里。

## 二、为什么做

### 2.1 问题

05 的 `selection.properties` 只显示"当前选中的东西"，选中片段时看到的是摘要，想改一个没设过的字段必须先想办法把它变成已存在。这与作者的直觉相反：schema 已经声明了这个轨道有哪些字段，面板就应该把它们列出来，未设置的显示为未设置，而不是藏起来。另一个问题是，如果效果面板成了唯一的属性入口，作者在关闭动画后就找不到那个属性了。

### 2.2 目标

- 选中片段即可看到该轨道的全部适用属性，未设置的也在列表里。
- 未设置属性可以直接输入值，输入即创建对象，一次撤销可回退到未设置。
- 动画属性的开关在属性面板：点时钟建首帧并把行送去效果面板。
- 已在效果面板的属性不在属性面板重复出现值控件，只给一个定位入口。
- 结构类型、必填缺失、依赖未满足、未知路径都有明确且不误导的呈现。

### 2.3 非目标

- 不做单节点检查器：面板是片段级，不随节点切换成单属性页。
- 不提供"添加属性"弹层或字段选择器。
- 不显示关键帧组、节点轴、局部标尺。
- 不编辑片段的时间几何（起止与时长属于主时间轴）。

## 三、方案

面板沿用既有身份与停靠位置（panelId `selection.properties`、槽位 `document.right`），标题改为"属性"，单例、切页保活。它与效果面板是两个独立宿主，可同时可见，各自缩放。

面板有四种状态，与效果面板对称：没有选中片段时给空态；选中多个片段时给摘要——片段数量、主选片段名，不擅自展开第一个；唯一片段有效时给完整面板；片段键失效时说明原因并提供撤销恢复与回到时间轴的出路。轨道没有任何适用属性时明确写出"该轨道没有可编辑字段"，不给添加按钮。

面板自上而下是片段摘要与工具栏、属性组列表。摘要回答"这是哪个片段"：可改名、只读的片段身份、轨道名、起止与时长形态、校验徽标、未保存标记；起止与时长旁边给一个"在时间轴编辑"的跳转，因为几何不在这里改。工具栏是搜索、只看未设置、折叠全部、清除。

组列表按 schema 的 section/group 归类，组头显示已设置数与总数，并提示该组有几项已经去了效果面板，点击可跳到效果面板对应组。组头吸顶，行按顺序排列。

行分几类，呈现各不相同。已设置的非动画属性显示值控件和"值"标记，没有时钟。未设置的属性显示"未设置"占位，编辑即创建对象。动画轨道为空帧的属性显示静态值加"添加首帧"的时钟，并标注"动画轨道无帧"。已经有帧的动画属性不显示行，只保留组头计数和一个定位入口。事件为空记录时显示"添加首条记录"，有记录后不再显示行。结构类型显示专用或 JSON 编辑器，标注静态且没有时钟。未知路径归入"未知/扩展"组，只读。

静态值编辑不改变归属：改值只写值，不建帧、不迁移。只有出现关键帧才迁移。连续输入在短时间窗内合并为一个撤销项，失焦或回车结束合并。校验规则与值控件一致，失败不写文档、不加撤销项。

开启动画是这一层的核心动作：点时钟在播放头创建首帧，初值依次取同属性播放头最近的节点、当前静态值、schema 默认值，都没有则内联提示需要先输入静态值。创建成功后叶子进入效果面板，属性面板该行消失，若同组还有静态叶子则组头保留并更新计数，焦点移到效果面板对应行，属性面板保留滚动位置，一次撤销全部恢复。空帧属性的时钟文案是"添加首帧"而不是"关闭动画"。

关闭动画只能从效果面板发起，成功后叶子回到属性面板，显示静态值与"动画轨道无帧"，按原组顺序插回并滚动聚焦，组头计数减一，一次撤销恢复。删最后一帧同样回流。属性面板不主动删除对象，也不把空关键帧变成未设置。

未设置与缺失字段的处理原则是"显式而不打扰"：未设置叶子始终在属性面板，不进入效果面板；必填缺失的行显示"必填未设置"与错误边框，但不弹任何对话框；编辑未设置叶子会创建对象并写入值；依赖未满足时显示依赖路径与"去设置"，控件禁用但不改 schema；未知路径只读，不提供删除快捷操作。

选择联动只改展开、高亮与滚动，不切页、不重建文档。选中片段时展开全部组并回到上次位置；选中叶子时展开其组并滚到该行；若该叶子在效果面板，顶部给一条"在效果面板"的提示与定位按钮，不重复行；选中节点时高亮对应叶子并在提示条上标出节点时间，不显示节点值；选中图节点、规则或绑定时说明"当前选择不是片段属性"并给回到片段选择的入口。

过滤只改显示：搜索按路径、标签、组名匹配并展开命中组；只看未设置只留未设置或必填缺失的行；折叠全部折叠所有组但保留当前选中叶子所在组；清除恢复默认。过滤不改行集合、不删对象、不影响效果面板。

## 四、技术细节

### 4.1 核心模型

- 属性行：片段键、路径、定义视图、是否存在、模式、值、关键帧。属性面板与效果面板共用这一份行集合。
- 属性组：组键、标签、顺序、行、已设置数、总数、若干项在效果面板。
- 面板会话：折叠组、过滤条件、滚动位置。

行集合由"当前轨道全部适用叶子"生成，包括不存在的叶子；再由归属策略分区，属性面板只渲染留在自己这一侧的行。

### 4.2 契约

- 输入是面板上下文：只读选择与批选、文档修订号、写入命令、脚本文档与 schema 服务、定位回调。
- 文档修订号变化即重取片段与轨道定义，不缓存文档对象。
- 面板不写文档；开启动画、改静态值、创建对象都走命令层，失败由命令层回滚。
- 归属不写在文档或会话里，每次渲染按当前文档重算。

### 4.3 数据形态

存在性由对象表里是否显式存在该路径决定：静态值、等于默认值的显式值、空关键帧数组都算存在。未设置就是不存在，显示为占位而不是零或默认值。

模式区分四种：静态值、动画、事件、未知。静态值没有时钟；动画有时钟，帧数为零时是"添加首帧"；事件给记录入口；未知只读。

### 4.4 边界

- 面板不显示节点，也不画时间轴。
- 面板不发起节点级编辑，只发起开启动画与静态值写入。
- 面板不修改片段起止与时长，只提供跳转。
- 面板不创建 schema 未声明的字段，未知路径只读展示。

## 五、为什么不选别的

| 备选方案 | 做法 | 代价 | 为什么没选 |
|---|---|---|---|
| 只显示已存在属性 | 沿用 05 的摘要式面板 | 未设置字段无从下手；作者要先去别处造对象 | schema 已声明字段，应全部可见 |
| 属性面板也显示已动画属性 | 两处都放值控件 | 同一属性两个值控件，改哪个不明确 | 已在效果面板的属性只给定位入口 |
| 用弹层添加属性 | 提供字段选择器 | 与"列全部适用属性"重复；易产生空动画对象 | 未设置行本身就是入口 |
| 面板随选择切成单属性页 | 选中节点就只显示该属性 | 失去全貌；切换成本高 | 片段级清单 + 高亮更稳 |

**本方案的缺点**：

- 属性多的轨道列表很长，依赖折叠、搜索与虚拟化。
- 未设置行与已设置行外观接近，容易误以为有值。
- 组可能同时出现在两个面板，作者需要在两处之间来回看。

## 六、实现结果

状态：已实现

`ClipPropertiesPanel.vue` + `ClipPropertiesHeader/Toolbar/Group/Row/AnimationClock` + `rowLayout.ts`。
行集合来自 `propertyRowsFor` → `separateUnknownGroup` → `withAvailability`，
再 `partitionGroups(..., 'leaf', timing).propertyGroups`。

| 原设计 | 实际实现 | 偏离原因 |
|---|---|---|
| 列当前轨道全部适用叶子 | 剔除 `playControl` 五字段（`CLIP_GEOMETRY_PATHS`） | 片段时间几何由主轴编辑；属性面板给了值控件会误导（06-09 §4.4 已声明"不修改起止与时长"） |
| 未设置叶子编辑即创建对象 | `object.setValue` 创建并写入，一次撤销回到未设置 | 与设计一致 |
| 组头提示"N 项已去效果面板" | `effectCountByGroup` + `requestRevealInEffectControls` | 与设计一致 |
| 100+ 叶子纵向虚拟化、组头吸顶 | `rowLayout.ts` 固定行高 + 绝对定位 | 与设计一致 |
| 面板压窄时标签与控件上下排列 | 行布局本就是 `flex-direction: column`（标签在上、控件在下），无横向滚动 | 与设计一致 |

### 验收要点

- 选中片段后显示全部适用组与叶子；已在效果面板的叶子不显示行，组头给出计数。
- 未设置属性显示占位，输入值后创建对象并写入，一次撤销回到未设置。
- 纯静态属性改值后仍在属性面板，不出现时钟。
- 空帧动画属性显示值与"添加首帧"，点时钟后进入效果面板且该行消失。
- 效果面板关闭动画后属性回到属性面板并显示静态值，组头计数减一，一次撤销恢复。
- 空事件显示"添加首条记录"，创建后进入效果面板，属性面板不再显示该行。
- 结构属性用专用编辑器，没有时钟，原样保存。
- 未知路径无帧时只读显示，不能改值，不影响其他行。
- 搜索命中时展开对应组并高亮，效果面板的行不被当成属性行。
- 上百行时只渲染可见行，组头吸顶，滚动不卡。
- 面板压到最窄时标签与控件上下排列，无横向滚动，控件可用。
- 选中效果面板节点时属性面板显示提示条并标出节点时间，不复制节点轴。
- 轨道无适用属性时显示明确文案，没有添加入口。
- 多选片段时显示摘要，不展开第一个片段。
