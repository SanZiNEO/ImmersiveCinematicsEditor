# 06-11 06 验收

## 验收范围

06 交付后，`clip.effects` 只显示已有关键帧的属性，`selection.properties` 显示片段全部静态/未设置属性；两个面板通过 `panelMembership` 分区，没有任何“添加属性”选择器。主时间轴仍不显示对象节点或整帧菱形。

## 验收环境

- 编辑器：`E:\Documents\GitHub\ImmersiveCinematicsEditor`。
- 模组 schema：真实 `schema.snapshot.json` 与 `ObjectDef`，不使用手写假字段。
- 文档：至少 3 个片段：有限、无限、循环；至少 1 个含 `EVENT`、1 个含 `STRUCT`、1 个含未知路径。
- 性能：一个片段 100+ 属性叶子、500+ 关键帧节点；另一个 3 个片段各 50 节点。
- 保存：本地保存 + 服务端 `script.validate`；重开同一文件。

## 验收矩阵

### A. 双面板职责

| # | 操作 | 期望 |
|---|---|---|
| A1 | 选择无动画片段 | 效果面板空态“在属性面板开启动画”；属性面板显示全部适用属性 |
| A2 | 选择有动画片段 | 效果面板只显示有帧叶子；属性面板不显示这些叶子，组头显示“N 项在效果面板” |
| A3 | `VALUE` 叶子（默认 `leaf`） | 只在属性面板；效果面板无该行、无空组 |
| A4 | `STRUCT` 叶子（默认 `leaf`） | 只在属性面板；没有时钟；效果面板不出现 |
| A5 | `ANIMATED` 且 `keyframes=[]` | 属性面板显示静态值 + “添加首帧”；效果面板不出现 |
| A6 | `EVENT` 且 `keyframes=[]` | 属性面板“添加首条记录”；效果面板不出现 |
| A7 | `EVENT` 有记录 | 效果面板记录条；属性面板不显示重复行 |
| A8 | 未知路径无帧 | 属性面板“未知/扩展”只读 |
| A9 | 未知路径有帧 | 效果面板未知组只读 |
