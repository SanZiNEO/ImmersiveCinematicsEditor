## 1. 职责

提供底部可切换抽屉：**曲线/路径、行为（触发/规则/事件）、资源、诊断、模板**五个面板的容器、注册、懒挂载、尺寸、焦点与错误隔离。容器只决定「谁显示、在哪显示、加载/错误怎么呈现」，不实现面板内容。

## 4. 输入 / 输出 / 字段约束

**输入**：面板注册表；选区（只读）；文档修订号；诊断 issue 列表；`resource.list` 结果；05-21 的布局树（当前 group/高度）。

**输出**：`openDrawer(tabId)` / `closeDrawer()`（委托 21 更新布局与可见性）；面板内的命令调用委托 02/03。**不提供** `resizeDrawer(h)` 的第二套实现——拖高由 22 的分隔条交互完成并写入 21。

**注册表条目约束**

| 字段 | 约束 |
|---|---|
| `id` | 稳定字符串：`curves` / `behavior` / `resources` / `diagnostics` / `templates` |
| `titleKey` | i18n key；中文标签 ≤ 6 字（长标签规则见 art-direction §4） |
| `order` | 决定 tab 顺序：曲线/路径 → 行为 → 资源 → 诊断 → 模板 |
| `minHeight` | 面板最小高（诊断 160，模板 240，行为 240，曲线 240，资源 160） |
| `available(ctx)` | 按能力裁剪：无 `paths` 能力时隐藏曲线页；无 ADJUST 轨时资源页仍显示（资源是全局的） |
| `keepAlive` | 诊断 true（保留滚动/筛选）；模板 true（保留参数草稿）；曲线/行为 false（随选区重建） |

**行为约束**

- 同一时刻同一 group 只显示一个面板；再次点同一 tab 折叠该 group（可见性归布局）。
- 抽屉与主轴可同时显示；窗口高 < 720 时，打开抽屉自动把主轴压到 160px 并提示「抽屉与主轴二选一」。资源/模板抽屉默认关闭，按需打开。
- 抽屉是布局树里的一个 **dock group**：面板可被 22 拖出到效果控件/快捷属性/其他区域，也可把别的面板拖进来成组；抽屉本身可被移动或隐藏，但默认位置在主轴上方。
- 面板懒加载；加载中显示骨架；失败显示「加载失败 + 原因 + 重试」，不吞错误。
- 诊断面板是全局问题的唯一聚合入口；字段原位错误提示仍保留，顶栏显示计数并可跳转，不能让唯一聚合变成禁止必要的字段提示。
- 资源面板只读（`resource.list` 无写通道）；需要写文件的工具（LUT 见 12）不得从本容器偷偷写。
- 面板内容与容器解耦：`PanelSlot` 只认 `panelId`，不认「第几个 tab」；未知 `panelId` 显示「面板不可用」并可从布局中移除。

## 6. 禁止修改

- 不在容器里实现任何字段/规则/曲线/模板控件。
- 不把抽屉做成模态弹窗或全屏浮层（必须能同时看主轴）。
- 不让面板直接读全局 `state`；统一经 `PanelContext`（与 `05-07` 同构）。
- 不新增文件写入通道；资源面板严格只读。

## 9. 验收

**正例**

1. 打开诊断：列出 3 条 issue，点「定位」→ 主轴选中对应片段，属性/节点由效果控件定位，并把播放头移到问题时间。
2. 打开模板：显示 12 的面板；关闭再开，参数草稿保留（keepAlive）。
3. 尚无真实曲线组件时，注册器报告该能力未交付且不展示可操作空页；07接入真实组件后同接口打开，不使用占位数据通过验收。
4. 窗口 700px 高时打开抽屉：主轴压到 160px 并出现提示；关闭抽屉恢复。
5. 面板组件抛错：只该面板显示错误，主轴/预览正常。
6. 把「诊断」从抽屉拖到右侧与「快捷属性」成组：抽屉原位置只剩其余 tab，右侧出现新标签；重启后位置保持（21/23）。
7. 隐藏抽屉后从「视图 → 面板 → 抽屉」恢复：恢复到最后一次的分组与选中 tab。

**反例**

1. 抽屉覆盖主轴导致无法插入到播放头 → 不通过。
2. 诊断只显示第一条（旧横幅行为） → 不通过。
3. 面板加载失败时静默显示空表 → 不通过。
4. 资源面板出现「上传/删除」按钮 → 不通过（无写通道）。
5. 抽屉自己维护高度并写本地存储 → 不通过（与 21/23 重复）。
6. 面板只能待在抽屉里、不能拖到别的区域 → 不通过（退化为固定布局）。

**真实冒烟**：WebUI 打开真实脚本，按 1–5 操作（本轮出口）；游戏内 Forge 复测 3–5 属 14 迁移参考，不构成本轮出口。

## 10. 完成定义

- 五个槽位注册完毕，内容归属明确，无「临时假表单」。
- 诊断唯一聚合、字段原位错误与顶栏计数一致；无整脚本源码子页或复活的旧常驻导航。
- 抽屉与主轴可共存，低窗口有明确降级；资源/模板抽屉默认关闭、按需打开，不变成常驻素材/脚本栏。
- 面板错误隔离与重试可用。
