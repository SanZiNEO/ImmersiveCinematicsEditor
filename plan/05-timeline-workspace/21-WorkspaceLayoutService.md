# 05.21 — WorkspaceLayoutService（拟新增）

> **本轮范围**：只实现/验收 WebUI（主模组 Forge/Fabric 正常）；文中游戏内/Forge+AUI 承载与 Java 实现段仅 14 迁移参考，不阻塞本轮；13 验收通过后才进入 14。

## 目标／前置／依据

正式必做：可持久化的组件位置、分隔比例、停靠组、可见性和恢复默认。前置02会话状态/05容器。现有依据 EDITOR:src/App.vue — jsonColWidth/leftPanelWidth/rightPanelWidth/timelineHeight（22–27）、initSizes（50–62）、onMouseMove（73–84）、onResize（289–294）；这些只是固定列尺寸，不能称为已支持组件位置变动。

参考[工作台/偏好/宿主适配](../references/03-workspace-preferences-host.md)的Olive布局持久化与面板身份。只取稳定身份、布局/面板局部状态分离和错误恢复思想，不照搬项目内XML、指针身份、序列化字节替换或Qt类型。继续用本任务split/group/panel和唯一panelId，布局不进入标准脚本。

## 输入输出与结构

建议 src/core/application/WorkspaceLayoutService.ts。输入稳定 panelId 注册表、宿主可用矩形、已保存布局；输出经校验的布局树和布局命令。结构分 split/group/panel 三类节点，尺寸用比例及最小尺寸；标签组保存有序panelId和当前标签；数据有编辑器布局版本，**不是meta.version**。

可移动对象包括预览、主时间轴、`clip.effects` 片段效果控件、`selection.properties` 快捷属性、曲线/路径、行为、资源、模板和诊断；不把旧常驻脚本列表列为合法面板。默认布局按用户截图定制职责：效果控件在预览左上、快捷属性在右侧、主时间轴横贯下方；效果控件与快捷属性是两个独立 panel，可同时可见、可分别停靠，不是同一个 tab 的二选一，效果控件不受旧检查器 280–560px 宽度限制。默认工作区、字幕、镜头、行为布局可存为预设，并可恢复默认。允许移动的具体能力不能写成仅以后考虑。

## 实施步骤

1. 先从App/TabbedPanel/PanelTabs提取稳定panelId，唯一注册；未知旧面板忽略且保留恢复提示。
2. 实现移动/分组/拆分/缩放/隐藏/重新打开/切换预设的纯布局事务，与脚本撤销历史分离。
3. 限制每个必需面板至多一个实例；隐藏预览不关闭文档，恢复后沿用同一画面通道，不创建重复流。
4. 启动校验布局无环、panel引用存在、尺寸有限正数；坏数据只恢复布局，不重置脚本/全部偏好。
5. 窗口缩小、DPI变化、多屏转单屏时校正最小尺寸/可达区域；不足时标签/抽屉折叠，不让控件负宽或丢出窗口。
6. 保存/恢复经PreferencesStore持久化；配置不可用仍能使用默认布局，不能阻止编辑。

## 两分支承载与禁止

本轮只实现/验收 WebUI 侧；游戏内 Forge+AUI 侧同语义是 14 迁移要求，不阻塞本轮。

WebUI完整停靠/重排；Forge沿相同panelId和布局语义做视口内停靠，系统级浮动窗口不强求。不能将布局坐标写入脚本，不能把元数据版本当运行时版本，也不能用移动面板改变真实游戏摄像机。

## 验收／完成定义

把效果控件与快捷属性分别停靠、把预览移到另一侧、把行为面板与曲线组分组、缩放主轴、隐藏并恢复资源、保存字幕布局后重启；位置尺寸可恢复且脚本JSON不变。效果控件可拉宽到容纳参数列与节点列，不被 280–560 旧范围夹住；快捷属性可独立折叠而不影响效果控件。损坏布局/未知panelId/零宽窗口/更换DPI均可恢复。拖动取消不改变旧布局；切布局不清选区/未保存修改。05必须完成全部操作和恢复路径才关闭。
