# 09-04 视频层

## 目标

把视频覆盖层接进 09。

视频没有独立的 `layer_type`。它仍然是 `layer_type=image`：只要 `path` 的扩展名是 `mp4` / `webm` / `mkv`，`OverlayTrackPlayer` 就创建 `VideoLayer`，而不是 `ImageLayer`。

编辑器不为视频新增字段：位置、锚点、缩放、取材、透明度、层级全部复用图片层字段。

## 识别

- `VideoFiles.isVideo(path)` 只看扩展名，大小写不敏感；
- 支持 `mp4`、`webm`、`mkv`；
- 不访问磁盘；不存在的 `.mp4` 仍会被识别为视频；
- `ObjectValidator.checkOverlay()` 允许 `layer_type=image` 的 `path` 使用 `png/gif/mp4/webm/mkv`；
- `path` 为空或非视频扩展名时，走 `ImageLayer`；
- 没有 `layer_type=video`，没有 `video_*` 字段。

## 生命周期与失败状态

`VideoLayer` 是懒启动：第一次 `render()` 才探测元数据并拉起解码进程；脚本没播到这一层就不付代价。

失败分两类，行为不同：

| 状态 | 条件 | 游戏表现 | 编辑器 |
|---|---|---|---|
| 缺工具链 | 缺 `ffmpeg` 或 `ffprobe` | `unavailable=true`；不显示、不占位、不画错误纹理 | 不显示“ffmpeg 缺失”状态；没有宿主回执 |
| 探测失败 | 文件缺失、损坏、ffprobe 超时、解析不出分辨率 | 画共享 `ErrorTexture` | 不伪造探测结果 |
| 解码失败 | 有工具链、元数据正常，但解码未产出任何帧 | 画共享 `ErrorTexture` | 不伪造解码结果 |

关键区别：

- 缺 ffmpeg/ffprobe 不是素材的问题，所以不显示、不占位；
- 有工具链但素材坏，才画 `ErrorTexture`；
- `ErrorTexture` 是黑/洋红 16×9 棋盘格，虚拟素材尺寸 1920×1080；
- 错误纹理参与几何解算：位置、锚点、缩放、取材照常作用在 1920×1080 的虚拟素材上；
- 错误纹理全工程共享，不随层关闭释放；
- 编辑器没有“视频加载成功/失败”消息，不能假装知道运行状态。

## 几何与取材

视频与图片共用 `ImageGeometry`：

```text
k = min(播放宽 / W基, 播放高 / H基)
B = (素材宽 × k, 素材高 × k)
中心 = (x × 播放宽, y × 播放高)
TL = 中心 - B/2 + (anchor - 0.5) × (B - B × scale)
S = B × scale
```

- 素材尺寸：正常路径用视频源分辨率 `meta.width/height`；错误路径用 `ErrorTexture` 的 1920×1080；
- `x/y` 是未缩放基准矩形中心，窗口归一化；
- `anchor` 是缩放不动点；
- `scale` 相对素材原始像素；
- `source` 是素材归一化取材；运行时钳制到素材内；
- 素材恒按元素框铺满，没有独立“适应/填充”字段；
- `opacity` ≤ 0.001 不绘制；
- 解码分辨率与显示尺寸分离：解码可能被 4K 上限缩小，但几何仍按源分辨率算。

## 解码尺寸

- 上限 4096×2160；
- 源不超过上限：按源分辨率解码；
- 源超过上限：等比缩到上限内；
- 不放大；
- 显示大小、位置、裁切、缩放全部由图层字段决定，不按屏幕自动适配。

## 时间与 seek

- `VideoLayer.setTime(localTime)` 每帧接收片段局部时间；
- 时间不变 = 暂停，画面停帧；
- 时间倒退超过 0.05 秒，或向前跳超过 1.0 秒：重开解码并 seek；
- 正常推进与解码抖动不 seek；
- 目标帧 = `floor(localTime × fps + 1e-6)`，并钳到最后一帧；
- `fps` 由 ffprobe 探测；探测不出回落 25；
- 时长未知为 0；片尾之后没有帧可出不算坏文件。

## 音轨

当前代码的视频音轨跟随画面时间轴：

- 视频含音轨时自动随画面播放；
- 固定 `SoundSource.MASTER`；
- 相对听者、无衰减、音量 1.0、pitch 1.0；
- 不参与脚本音量、淡入、空间化；
- 画面暂停超过 100ms：停掉音频实例；
- 音画漂移超过 0.25 秒，或画面时间倒退超过 0.05 秒：停旧实例并按画面时间重建；
- seek / 循环由 `VideoAudioTrack` 重建实例，不做进程内跳读。

编辑器不提供视频音量、淡入、空间化、音频偏移字段；这些字段不存在。

## 编辑面

视频层与图片层共用属性面板：

1. `layer_type=image`；
2. 素材路径（`OverlayMediaField`，视频模式）；
3. 位置 / 锚点 / 缩放；
4. 取材；
5. 透明度；
6. 层级。

不显示：`font_scale`、`text`、`color`、`color.r/g/b`、`gradient`、`gradient_*`、`mask_shape`、`mask_*`、`blend_mode`。

### `OverlayMediaField` 视频模式

- 路径输入；
- 文件选择使用既有 `resource.list(kind=all)`，客户端按 `mp4/webm/mkv` 过滤；
- 不用 `kind=image` 找视频：`kind=image` 只列 `png/gif`；
- 选择后写 `path`；
- 显示扩展名标记 `MP4` / `WEBM` / `MKV`；
- 显示“资源列表中存在 / 未找到”；
- 不显示 ffmpeg 是否可用、探测是否成功、解码是否失败；
- 不显示“视频缩略图”或“时长/帧率”；这些不是编辑器能可靠拿到的数据；
- 空路径不创建视频层；如果作者把视频路径清空，层按图片层处理，通常不绘制。

### 运行状态说明

属性面板可以显示一段静态说明，而不是状态灯：

- “缺 ffmpeg/ffprobe：游戏不显示该视频，也不占位”；
- “有工具链但文件损坏/编码不支持：游戏显示黑洋红棋盘格”；
- “视频音轨随画面播放，固定 MASTER，无音量字段”。

这段说明只解释代码行为，不伪装成实时状态。

## 本地校验

| 检查 | 处理 |
|---|---|
| `path` 扩展名 `mp4/webm/mkv` | 识别为视频；UI 显示视频模式 |
| `path` 扩展名 `png/gif` | 图片模式，走 09-03 |
| `path` 为空 | 不创建视频层；不报视频错误 |
| `path` 不在 `resource.list(kind=all)` | warning“未在资源列表中找到”；不阻止保存 |
| `source.w/h < 0` | block |
| `source.x+w` / `source.y+h` 超出 0–1 | warning；运行时钳制 |
| `scale <= 0` | warning“运行时不绘制” |
| `opacity` 超出 0–1 | block |
| `z_index` 非整数 | block |
| `layer_type` 不是 image 却存在视频路径字段 | block；由 09-01 清理 |

## 验收

| # | 场景 | 通过条件 |
|---|---|---|
| D1 | 选择 mp4 | `layer_type=image`、`path` 指向 mp4；游戏创建 VideoLayer；无视频专属字段 |
| D2 | 大写 `.MP4` | 仍识别为视频；扩展名判断大小写不敏感 |
| D3 | 缺 ffmpeg | 游戏不显示、不占位；不画棋盘格；编辑器无假状态 |
| D4 | 坏文件 | 游戏画 1920×1080 黑洋红棋盘格；按图层几何缩放/裁切 |
| D5 | 空路径 | 不创建视频层；不报视频错误 |
| D6 | 位置/锚点/缩放 | 与图片层同一套公式；视频按源分辨率参与几何 |
| D7 | 取材 | `source` 裁切视频；越界钳制；负宽高 block |
| D8 | 4K 上限 | 源 8K 等比缩到 4096×2160 内；显示几何仍按源分辨率；不放大 |
| D9 | 暂停 | 时间不变时停帧；恢复后从当前局部时间继续 |
| D10 | seek 回退 | 回退超过 0.05 秒重开解码；小抖动不重开 |
| D11 | seek 前进 | 前进超过 1.0 秒重开解码；正常帧推进不重开 |
| D12 | 音轨 | 含音轨自动播放；固定 MASTER；无音量/淡入/空间化字段 |
| D13 | 错误纹理 | 错误路径使用 1920×1080 虚拟素材；`source` 仍作用于错误纹理 |
| D14 | 保存重开 | 路径、几何关键帧、source、opacity、z 原样保留；无视频专属字段写盘 |

## 完成定义

- 视频只通过 `layer_type=image` + 视频扩展名表达；
- 缺工具链、坏素材、错误纹理三种状态与代码一致；
- 视频音轨行为与当前 `VideoAudioTrack` 一致；
- 编辑器不新增字段、不新增消息、不伪造宿主状态；
- 视频几何、取材、透明度、层级与图片层共用同一套合同。
