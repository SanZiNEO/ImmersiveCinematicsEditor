# 右侧属性面板设计稿

目标是让用户选中一个对象后，首先知道**正在改谁、哪些值能改、改的是静态值还是这一帧**。字段数量由脚本格式决定，首屏展示量由编辑任务决定。图 1 和图 5 中，面板标签、坐标规则和调色目录都抢占了首屏。这里借用图 2–4 的交互顺序，并用 Editor 自身的功能命名。

[现有编辑入口盘点](inspector-editing-inventory.md) · [字段目录逐项附录](inspector-field-catalog.md) · [交互原型](../src/plugins/core.selection-properties/inspector-prototype.html)

## 选择决定面板内容

| 工作台操作 | 右栏显示 | 第一眼看到什么 |
| --- | --- | --- |
| 打开脚本或点时间轴空白 | 脚本参数，一页内分组，无页签 | 名称、标识、作者、说明。播放、输入和 HUD 置于可展开的分组 |
| 点击轨道头 | 轨道参数，一页内分组，无页签 | 类型、名称、片段数。可见、锁定、静音集中在「编辑会话」。把轨道头提升为检查对象是这轮设计选择 |
| 选中单个片段 | 片段标题、时间摘要、适用功能 | 常用组先打开。只显示当前片段类型和分支适用的入口 |
| 从专用面板选中字段或帧 | 保持其所属片段，定位功能组与字段 | 字段及当前时间。可见提示说明编辑目标 |
| 多选片段 | 数量与选中项摘要 | 保留用户选区，属性暂按单片段编辑 |
| 选区失效、未打开文档、第三方未知字段 | 原因及可执行入口 | 无可编辑对象时给提示。未知字段保留原值查看入口 |

右栏固定显示片段范围和播放头在片段内的时间，并提供定位到片段开头的操作。拖动、裁切和切换循环在主时间轴完成。循环次数、循环方式和片段默认出口已有目录声明，加入编辑入口前需要单独核对。规则绑定里的出口覆盖由行为编辑器管理。拖动标尺保持原有定位行为，点轨道空白可清空选区。完整关键帧轨迹、路径几何、曲线和资源列表保留专用编辑空间。

## 脚本参数的字段归属

| 分组 | 字段 | 入口 |
| --- | --- | --- |
| 基本信息 | `name`, `id`, `author`, `description` | 名称、作者、说明直接编辑。ID 提供引用安全的重命名入口 |
| 播放行为 | `play_mode`, `priority`, `interruptible`, `skippable`, `skip_vote_ratio`, `hold_at_end`, `macro_loop`, `macro_loop_count`, `macro_loop_mode` | 循环开启后再显示次数和方式。跳过投票使用百分比 |
| 输入与监听 | `listener`, `block_keyboard`, `block_mouse`, `block_mob_ai`, `pause_when_game_paused` | 监听点和四项游戏运行设置 |
| 画布与游戏界面 | `dimension`, `base_resolution`, `screen_layers` | 基准分辨率用宽和高，沿用几何工具的校验。逐层可见性需要专用字段控件，目前只有目录定义 |
| 行为 | `triggers`, `trigger_poll_interval` | 保留触发器编辑入口，可带脚本级轮询间隔 |

## 按任务组织片段字段

一级入口仅在确实有多组任务时出现。内部使用可折叠的小组，以值控件为主体。路径名供提示、搜索和定位使用。

| 片段类型 | 一级入口与二级组 | 条件与专用入口 |
| --- | --- | --- |
| 相机 `CAMERA` | **镜头**包含位置、朝向、视野和变焦。**运动**包含运动模型、呼吸、修饰与选择器策略。**构图**包含画面区域、取样裁切、遮罩、维度与透明度。**调色**包含明暗、色彩、白平衡、通道、色带、曲线和风格。**转场**呈现切换方式、混合时长与参数 | 基准原点和方向放在「建立基准轴」内，注视目标跟着朝向组。选择器覆盖项按调用点收起。专用交界编辑器查看成对镜头的转场 |
| 遮幅 `LETTERBOX` | 单页「画幅」。画幅比例与不透明度均可编辑 | 两项均支持关键帧 |
| 音频 `AUDIO` | **声音**包含音源、文件或声音 ID、音量、音高、淡入淡出、文件循环。**空间**包含声音类别、定位与衰减 | 文件分支显示文件循环。环境声显示定位和衰减。脚本监听点回脚本参数 |
| 事件 `EVENT` | 单页「事件记录」。片段内时间、命令、可选 ID 与位置 | 记录是时间点触发，完整编辑在行为记录面板。位置绝对 X/Z 与相对 dX/dZ 互斥 |
| 模组事件 `MOD_EVENT` | 单页「事件记录」。对象级默认事件名和数据、每条记录的覆盖值 | 数据使用对象编辑器。省略值与显式空对象有区别 |
| 叠加 `OVERLAY` | **图层**包含内容、透明度、层级。色块有 **遮罩**，图片和字幕有 **布局** | 色块提供颜色或渐变、混合和遮罩。图片提供素材、位置、缩放、锚点与裁切。字幕提供文本、字号、位置与锚点 |
| 调整层 `ADJUST` | **调色**与相机复用调色分组。**LUT 与混合**包含资源、输入伽马、LUT 强度、混合模式和强度 | 曲线定义用专用编辑器，曲线强度仍是可动画的数值 |

## 相机位置与朝向的依赖

「镜头」默认仅展开「位置」。先选位置模式。相对位置下，选择沿世界轴偏移或建立基准轴，再编辑同一排数值。

| 位置基准 | 数值输入 | 在游戏中的含义 |
| --- | --- | --- |
| 绝对位置 | X / Y / Z | 直接指定世界坐标 |
| 相对位置 · 世界轴 | dX / dY / dZ | 方向由世界轴给定。偏移默认从玩家激活脚本时的位置算起 |
| 相对位置 · 基准轴 | 前后 / 上下 / 左右 | 用原点和方向建立一组轴，再沿这组轴偏移。默认原点跟随玩家脚底，自动方向跟随玩家身体的水平朝向，上轴恒为世界 +Y |

世界轴分支只编辑偏移分量。主模组会沿世界轴从脚本指定的起点计算偏移。原型保留已有点源，世界轴分支只提示起点是否沿用。「基准原点」与方向的编辑入口集中在「建立基准轴」区域。

三种分支共用位置分量。原型切换时保留输入值，立即更新标签与适用字段。位置模式和坐标轴可设关键帧，在播放头经过切换点时更新面板。正式接入需按主模组校验规则处理切换点的位置帧对齐。点源的空值语义与方向规则见[主模组源码调查](position-coordinate-runtime-research.md)。

基准轴朝向决定位置偏移的方向。「朝向」卡片另管相机看向哪里。注视目标跟随所选类型展开。目标不可用时使用的朝向设置放在可展开的小组里，横滚始终适用。

「运动」中的镜头呼吸单独处理三个状态。添加或移除改变配置是否存在，卡片标题控制展开，标题旁的开关控制是否启用。停用保留参数与展开状态。两段相机样例分别演示已配置但停用、尚未配置。选择「冲击衰减」才显示初始冲击与衰减速度。

## 给实现者的行控件参考

以约 480 px 的右栏为基准。正文与控件 14 px，主标题 19 px，组标题 15 px。编辑行至少 44 px，小组之间留 16 px。标题、激活页签、当前帧使用不同的字重、底色或边线。默认只展开本类常用组。帮助文字和错误贴着所属字段，字段路径放在提示和搜索结果里。窄栏里数值输入优先于滑杆，标签和值区均可收缩。焦点、缺失与禁用要能从形状或文本辨认。

```html
<section class="group" aria-label="镜头参数">
  <div class="property-row" data-field="fov">
    <label for="fov">视野角</label>
    <div class="value-control">
      <input type="range" aria-label="视野角滑杆" min="20" max="120" value="70">
      <div class="number"><input id="fov" type="number" value="70"><span>°</span></div>
    </div>
    <div class="frame-controls" aria-label="视野角关键帧">
      <button type="button" aria-label="恢复视野角默认值">↺</button>
      <button type="button" aria-label="视野角上一帧" disabled>‹</button>
      <button type="button" aria-label="添加视野角关键帧" aria-pressed="false">◇</button>
      <button type="button" aria-label="视野角下一帧" disabled>›</button>
    </div>
  </div>
</section>
```

```css
.group + .group { margin-block-start: 16px; }
.property-row {
  display: grid;
  grid-template-columns: minmax(78px, 1fr) minmax(0, 2fr) auto;
  align-items: center;
  gap: 8px;
  min-block-size: 44px;
  font-size: 14px;
}
.value-control { display: flex; align-items: center; gap: 8px; min-inline-size: 0; }
.frame-controls { display: flex; }
```

- 数值可在输入框精确输入。在有实用调节范围的行提供同步滑杆，滑杆的工作区间不自动成为脚本的合法值域。复位只影响当前编辑的静态值或帧值。
- 可动画字段在右边显示上一帧、菱形、下一帧。空心表示当前时间没有帧，实心表示有帧。点击菱形显式添加或删除这一帧。两帧之间可以查看采样值，先添加帧再改值。分组中的 X/Y/Z 分别显示其帧状态，避免把某一轴的帧误认成整组。
- 静态字段使用明确的输入、开关、下拉或专用编辑入口。事件类型显示记录数量和时间，结构定义显示摘要。两者不使用数值关键帧菱形。
- 日常界面用「世界坐标」「相对位置」「视野角」等操作词。选中字段或查看帮助时再展示 `position_mode`、`fov` 等路径。诊断可定位到指定行，避免一段全局说明挡在每个功能页最上方。

原型支持七轨样例、叠加的三种分支、选区切换，以及代表性的静态值、滑杆和时间点关键帧操作。值与关键帧保存在本次网页的内存中，刷新恢复样例。代码片段和原型用于下一轮截图确认布局、密度及交互，正式接入由实际命令与字段约束决定。
